# Listen/start–keep 校准验证

更新：2026-10-24。XTX-010 的 Listen 阶段已完成真实远端验证，退出码 0；Speak 校准后置，未训练或替换现役控制器。规则与数据在模型打分前按[实验协议](../../../docs/dev/XTurnix/listen_calibration.md)冻结。

## 结论

**单纯校准可以减少误抢话，但本次代价是明显降低接话召回，留出集也未达到预设 5% 误抢话预算。不能据此认定校准已经解决 Listen 控制问题，暂不采用该阈值上线。** 未使用留出结果重新选择阈值，也未因结果不佳自动转入训练。

开发集在误抢话≤5% 下选择 `p_start >= 0.6057546734809875`，比默认 `0.5` 更保守。当前真实多轮输入下，问题不是单一的“默认阈值过高”；降低阈值会进一步增加误抢话。论文支持先验证校准，但不保证任一领域的排序能力足以满足任意工作点。

## 默认与校准对照

同一输入、精度与权重，只改变阈值。误抢话按原用户话轮归并：任一句中停顿 start 就记该话轮一次错误，分母包含全部计划话轮；风险话轮分母另列。末端召回先独立于提前 start 计算，“安全末端命中”额外要求本轮此前没有误抢话。

| 数据与指标 | 默认 0.5 | 开发集选定阈值 0.605755 |
| --- | ---: | ---: |
| dev 话轮级误抢话 | 32/225，14.22% | 10/225，4.44% |
| dev 末端接话召回 | 109/225，48.44% | 77/225，34.22% |
| test 话轮级误抢话 | 18/167，10.78% | 9/167，5.39% |
| test 风险话轮条件误抢话 | 18/83，21.69% | 9/83，10.84% |
| test 末端接话召回 | 74/167，44.31% | 48/167，28.74% |
| test 安全末端命中 | 68/167，40.72% | 45/167，26.95% |

留出集误抢话减少 9 次，同时末端接话命中减少 26 次。5% 预算在 167 话轮上最多允许 8 次，本次 9 次，因此 `test_empirical_budget_met=false`；也不能凭接近 5% 宣称满足约束。

按 41 个原会话做固定种子 1,000 次配对 bootstrap，校准减默认的差值区间为：误抢话率 −9.04 至 −2.38 个百分点；末端召回 −22.16 至 −9.82 个百分点；安全末端命中 −19.61 至 −8.14 个百分点。这支持“错误下降伴随覆盖下降”，不支持在同等覆盖下改善了模型区分能力。

快照 ROC-AUC 为 dev 0.8224、test 0.8014。阈值不会改变这些分数的排序；单个 AUC 也不保证低误抢话工作点有足够召回。dev 全阈值曲线和 PR 指标已保存，test 没有重新校准。

## 数据与覆盖

来源为 `livekit/eot-bench-data@ca9d98a9686b920a2d8c9eb984224ba9be74e4dd` 英文 validation 的 400 个用户话轮，提取参考词前缀、原生 hold/eot 停顿与历史，未下载音频。按来源 ID 的原会话前缀隔离：dev 53 会话、225 话轮、728 观察点；test 41 会话、167 话轮、504 观察点。两个已作格式检查的会话共 8 个话轮在打分前排除，归一化后的完整输入无跨集合完全重复。

总计 1,232 个计划观察点，其中 1,228 次模型推理成功、0 次推理失败；dev/test 各 2 个空当前文本观察保持 Listen、分数 null，不计入模型混淆矩阵。所有 392 个话轮的末端观察都成功打分。官方输入去尾标点、关闭 thinking；统一移除独立开场问候后，由官方管线处理长度，实际仅 1 个观察发生历史对移除。

输入与标签未取自此前 48 会话条件候选，也未使用 FLEURS/FDB。这是本项目对公开 validation 的重新分组实验，不能称为官方完整 benchmark 成绩。原始词对齐不等于 Nemotron 在线 ASR 到达；本次没有 VAD 时间输入、语调、实时回放或真实播放，不能推出部署时接话/停播延迟。来源接近英语任务型语音助手，仍不代表 ParaThink 所有目标任务；跨会话的说话人隔离及模型既有数据重叠未获证明。
