## 如何理解对照

160ms有37条录音在最后一次ASR更新前已输出过start，更新后仍观察到Speak、但未再次start；480ms对应23条。因此，更新后start为18%不能单独解读为总体接话率只有18%，也不能用Speak比例替代新start比例。两项必须分开报告。

两次均在最后更新后输出start的共同样本为9条：其平均等待从480ms的835.80ms变为160ms的303.45ms。这个比较仅描述同一9条条件样本，不外推为50条录音的总体平均开口延迟。

连续3周期门槛的名义时间不同：480ms为1440ms，160ms为480ms。因此66%与92%并非等时长指标，不能直接据此判断停顿处理变差或变好；它统计持续Speak行为，也不自动等于语义错误。全部62个Pause标注区间的观察次数、当前ASR前缀及动作保留在逐区间证据中，没有添加自动语义错误标签。
