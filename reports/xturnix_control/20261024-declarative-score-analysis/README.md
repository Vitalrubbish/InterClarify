# 陈述式输入的话中与话末 start 分数分析

2026-10-24。依据用户要求，先检查陈述式输入的话中、话末分数变化，再讨论短延迟下的控制策略。复用 XTX-010 已有分数和冻结 dev 输入；没有新增模型推理、训练、作业、阈值部署或工作单。

## 结论

**选定陈述式信息回答在话末通常升分，但话中与话末分布仍重叠。结果支持进一步检查短等待内的可区分性，尚不证明随静默时间降低阈值能提高在线效果。**

45 个完整陈述式信息回答中，36 个话末分数高于最后一次话中观察，27 个高于该轮所有话中观察。默认 0.5 阈值只命中 7 个话末，提示该切片存在保守漏接；简单降低阈值又会明显增加话中误触发。

这批样本主要是英语客服中的信息回答，不足以代表 FDB 中的开放叙述。42 个是带谓语的信息或选项回答，只有 3 个是较一般的状态、经历描述。单独保留这 3 个案例，不将合并结果解释成开放陈述场景的准确率。

## 数据与筛选

- 输入：XTX-010 的冻结 dev，225 话轮、53 个原会话、728 个观察；模型为冻结 XTurnix-PT，官方 Listen pipeline，FP32，无文本 pause。
- 从中取至少有一个非空话中观察的 131 话轮。每轮的 `keep` 是源标注的话中停顿，`start` 是末端观察；它们不是按模型分数命名。
- 本轮先阅读完整末端文本，再写入 [cohort_labels.csv](cohort_labels.csv)，然后关联已有分数。单次助手辅助分类，无第二审核者；部分案例此前已经在诊断中出现，因此不宣称盲审或独立测试。
- `slot_answer`：42 个带谓语的陈述式信息、偏好或选项回答，可以含简短确认或自我修正；主要作用是提供或纠正信息。
- `status_description`：3 个对设备状态或物品损坏经历的描述。语气词或修辞性的口头附加语不单独算实质提问。
- `slot_fragment`：另 7 个主要为号码、地址或简略选项的片段，只进入宽口径敏感性统计，不进入 45 话轮主表。
- 其余 79 个记为 `excluded_other`，包括实质问题、请求、混合请求、结束致谢、仅确认及不明确或未完输入。这里的类别是当前话轮的话语形式，不是正式语言学标注。

本地冻结输入为 `artifacts/xturnix_listen_calibration/20261023-listen-r2/`；分数为 [XTX-010 scores.csv](../../xturnix_training/20261023-listen-calibration/scores.csv)。已验证 dev 压缩文件、源元数据的 SHA256 与原报告一致，逐观察核对 `sample_id`、目标和 `messages_sha256`。完整摘要见 [summary.json](summary.json)，不复制原始对话正文。

## 成对分数

主切片为 45 话轮、32 个原会话，包含 140 个非空话中观察。`p_start` 是合法 start/keep 两动作归一化分数，不是校准后的真实让轮概率。

| 观察位置 | 均值 | 中位数 | P25—P75 |
| --- | ---: | ---: | ---: |
| 全部话中观察，140 点 | 0.1241 | 0.0522 | 0.0069—0.1682 |
| 每轮最后一次话中观察，45 点 | 0.1486 | 0.0634 | 0.0068—0.2151 |
| 每轮话中最高分，45 点 | 0.2457 | 0.1521 | 0.0352—0.4292 |
| 每轮话末，45 点 | 0.3141 | 0.2957 | 0.1803—0.4207 |

- 话末高于最后一次话中：36/45（80.0%）；低于：9/45。平均配对差为 +0.1655，中位配对差为 +0.1539。
- 话末高于话中最高分：27/45（60.0%）；其余 18 轮存在至少一个更高的话中分数。
- 全部话中观察对话末的快照 ROC-AUC 为 0.8200；每轮只取最后一次话中时为 0.7709。快照相关，观察数不同的长话轮权重也不同，不能把 AUC 当作话轮级低误抢话工作点。
- 按 32 个原会话做 2,000 次 bootstrap，种子 20261024。平均配对差的百分位 95% 区间为 +0.0837 至 +0.2309；话末高于话中最高分的比例区间为 42.5%—76.6%。这些区间不包含人工分类不确定性。

宽口径加入 7 个简略片段后为 52 轮：最后话中/话末中位数为 0.0592/0.2951，42/52 话末升分，33/52 话末超过话中最高分；方向相近。

## 分数上升本身是否足够

按每轮时间顺序，对相邻的非空观察作差。95 次话中到话中变化的均值为 −0.0010，中位数为 +0.0030；45 次最后话中到话末变化的均值为 +0.1655，中位数为 +0.1539。

话末确有较强的上升趋势，但话中也会出现上升。例如增量至少 +0.1 时，30/45 个话末满足，同时 16/45 轮曾在话中出现同等上升。它只能作为后续候选特征，不能据此直接启动。

“最后话中”与“话末”均为事后分组名称；在线时不知道当前观察属于哪一组。不能把 `p_end - p_mid_last` 这一事后选定的差值直接当作已验证的在线特征。若检验分数增量，必须在每个实际到达的前缀上使用相同因果规则。

## 固定阈值诊断

以下阈值仅为开发集上的固定刻度描述，不选择新工作点。每轮任意话中观察越阈值记一次话中误触发；话末命中独立计数，安全话末命中额外要求本轮此前没有误触发。未执行真实播放或状态切换。

| 阈值 | 话末命中 | 话中误触发的话轮 | 安全话末命中 |
| --- | ---: | ---: | ---: |
| 0.1 | 40/45 | 28/45 | 15/45 |
| 0.2 | 30/45 | 20/45 | 16/45 |
| 0.3 | 22/45 | 17/45 | 12/45 |
| 0.4 | 15/45 | 15/45 | 9/45 |
| 0.5 | 7/45 | 8/45 | 6/45 |

这说明存在低于 0.5 的话末信号，同时存在高分话中前缀。降低全局阈值会增加覆盖，但当前记录不能证明其误抢话代价可接受。

## 3 个状态描述案例

仅作例示，不能据 3 轮推断总体性能。

| 场景概述 | 最后话中 | 话中最高 | 话末 |
| --- | ---: | ---: | ---: |
| 描述两盏指示灯的不同状态 | 0.1502 | 0.1502 | 0.6375 |
| 描述重启后灯色来回变化 | 0.4019 | 0.4019 | 0.2654 |
| 描述物品到货即损坏 | 0.0247 | 0.4292 | 0.4207 |

第二例话末降分；第三例虽然相对最后话中大幅升分，仍低于更早的一个话中峰值。逐轮结果见 [paired_scores.csv](paired_scores.csv)。

## 时间与延迟限制

原实验在参考静默起点后 100ms 取当时参考词前缀，并非等待完整静默后才计算。因此这里观察到的分离不是靠额外等待 1.5 秒得到的。

但 100ms 是参考标注坐标上的取样偏移，不是 Nemotron 在线结果到达时延，也不是最后真实发声到首个可听输出的延迟。当前没有音频回放、在线 ASR 到达或 TTS 播放数据。

另外，主切片 45 个末端参考静默区间长度全部恰好为 1.5 秒；最后话中区间的长度中位数约 0.4 秒。**末端长度固定，不能把两者差异解释为自然停顿时长分布，不能据此选等待时长或宣称长等待有收益。** 原始 `duration`、`silence_spans` 和末词时间的关系仍需在真实因果回放中分别核实。

在文本与模型状态不变时，这个文本模型的分数不会自行随静默时长增长；当前升分来自前缀内容变化。随时间变化阈值还需要独立证据：在预先冻结的短延迟预算内，额外可观测时间能否过滤话中高分，同时保留话末低分。

下一步有依据验证短等待与语义分数/因果增量的联合策略，但本报告不设新的时间阈值、不修改控制策略；FLEURS/FDB 不参与选参。若时间与语义观察在该短预算内仍不能区分，就应报告信息不足，而不是以延长等待掩盖漏接。
