# SoulX 前端写入 SharedContext：实现与音频检查

2026-10-29。独立前端实现及六个音频视图的实时回放已完成，最终 r5 退出码0。**写入与读取一致性通过；识别内容和正文完整覆盖尚未全面通过。** 两个视图关闭时仍有明确拼合缺口，原幅度低音量录音的识别明显较差，不能把退出码0解释为转写或五状态语义准确率达标。

## 实现范围

依据[前端设计](../../../docs/dev/SoulX-Duplug/asr_frontend_design.md)，实现[来源解析与话轮整理](../../../docs/scripts/runtime/sensevoice_transcript.md)、[通用 SharedContext](../../../docs/scripts/runtime/shared_context.md)、[SoulX 采集适配](../../../docs/scripts/runtime/soulx_frontend.md)及[受限回放](../../../docs/scripts/remote/soulx_frontend_replay.md)。SharedContext保存原始ASR与标签、可修订正文、控制视图、原生状态及版本依据，各消费者有独立游标；正文发布不等待complete。

上游四个方法经完整文件摘要校验后在内存中插入采集点，不修改共用源码或权重。实现同时修复三项接入问题：控制器reset保留已收到而未处理的输入；ASR实参统一float32，避免默认float64缓存带来的提升；相邻且有明确词句界的音频片段可在reset后继续接入，临时滑窗缺口可在重新找到可靠锚点时恢复。不能可靠拼合时仍保留原始观察并标gap，不猜正文。

本次仅打通模型到Context和只读消费者。下游LLM、CoT、真实TTS及播放尚未接入；直接nonidle停止路径用活动输出替身验证，不宣称实际停播完成。没有训练或恢复历史benchmark。
