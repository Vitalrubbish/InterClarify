## 后续补充：内部句读的可见时机

2026-10-21用户检查疑问/插话场景后指出：当前ASR常在下一句开始时才输出上一句的句末标点。本报告的内部/末尾统计描述累计文本形式，不能据此把内部句读放到原文句末的同一时刻。读取已有合成探针，确有`Don't stop` → `Don't stop.` → `Don't stop. I`的更新顺序；点号可作为独立增量出现，但探针缺少逐更新声学位置，不能精确验证补点相对下一句发声的延迟。

因此上文“处理长轮末尾后再分拍”的建议须结合标点到达映射理解：后续输入到达才可交付的标点不能提前放进已见前缀，也不应回填模型已消费的旧用户拍。074已增加延后补点、跨用户再次开口的上下文生命周期及600ms落窗约束；尚未实施。原统计、机器通过与人工pending状态保持原始口径。
