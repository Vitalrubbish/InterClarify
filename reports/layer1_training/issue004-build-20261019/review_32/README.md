你可以逐条点开，也可以阅读[32条合并版](../completed/review/minimum_32.md)。不必手工检查token ID，重点检查：

- 用户续说或句中停顿时，系统是否继续等待。
- 接话是否发生在请求结束后，回答是否对应当前请求。
- 有效插话是否停止旧回答，用户附和是否继续旧回答。
- 用户去句读是否保留时间、小数、撇号/连字符，assistant内容是否保持一致。

| 控制 | 含义 |
| --- | --- |
| speaking | 等待用户继续说 |
| finish | 用户轮结束，开始回答 |
| interruption | 有效插话，停止旧回答 |
| backchannel | 用户附和，继续当前回答 |
| thinking | 回答结束后等待 |
| None | 正文续写，不新增控制标记 |
