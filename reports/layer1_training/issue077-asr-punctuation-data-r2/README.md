## 数据与生成规则

原train/dev/test仍1000/200/300对话，selected SHA256仍`98fe4d085a8258566f3e08eeee119f324b5708eb68b4a31f5f4de2d82a75f401`。每条原始计划、随机事件、用户跨度、控制和assistant目标与040a完全一致；只追加ASR可见文本及来源映射，原数据不覆盖。

遇到句读先暂存，后续字母/数字到达后才释放；同拍内可释放，no-voice拍不释放，不回填历史。暂存可跨同一合成对话的系统回答，下一用户正文或附和到达时释放，跨用户轮必要空格单列为合成字符；对话结束仍未释放的标点保留残留记录。没有新建补点专用拍或控制动作。

这是600ms窗口级近似，未通过真实音频标定补点延迟；所有句读类型均按同一因果规则处理，问号/感叹号保留源字符，不宣称真实ASR逐句会生成相同符号。源文本中的文献、网址、格式字符仍可能与ASR不同，少量真实EOF补点未纳入该条件，均为本轮限制。
