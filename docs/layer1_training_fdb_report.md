## 同口径行为结果

“新回复播放”使用现有客户端按response ID关联的标注后新响应，要求在原始输入音频窗口内启动播放。它是播放代理指标，不是物理首非静音时刻，也不自动代表回答相关或问题已听全。每个子集只有5个历史开发样本。

| 条件 | 自然接话后新回复 | 合成插话后新回复 |
| --- | ---: | ---: |
| 官方B0 | 1/5 | 1/5 |
| 首轮T1 | 0/5 | 0/5 |
| 首轮T2 | 1/5 | 2/5 |
| 首轮T3 | 0/5 | 1/5 |
| 第二轮T2 | 1/5 | 4/5 |
| 第三轮T2（本轮） | **3/5** | **5/5** |

本轮自然接话成功样本为1、10、100，101和102仍无新回复。合成插话5例全部达到该播放指标。来源为[首轮分析](../reports/layer1_training/issue034-waiting-asr-20261020/analysis/analysis.json)、[第二轮结果](../reports/layer1_training/issue037-t2-round2-20261020/results.md)和[本轮逐例结果](../reports/layer1_training/issue040-delayed-fdb-20261020/completed/results.json)。

### 时序、漏答与时延代价

本轮39次finish全部发生在无新增ASR文字拍，文字拍finish为0，finish无正文为0。核对25例前缀均无rewrite，按request ID关联相邻micro-turn前缀恢复该拍是否有新增文字。该结果说明本轮观测符合延后启动监督的finish分布，不是运行时静音保证，也不覆盖上述无finish正文启动。

自然接话成功3例的标注后播放代理时延为1.589、1.759、1.150秒，均值1.499秒；另2例无回复，未当作0秒参与平均。合成插话成功5例为1.781、1.222、2.367、2.289、1.580秒，均值1.848秒。

与第二轮共同成功样本比较：自然接话仅1例，增加0.593秒；合成插话共同成功4例，平均增加0.719秒。自然接话覆盖改善伴随等待增加，合成插话平均时延超过原1.5秒目标，按用户本次阶段收口决定如实接受并记录。该差值包含实际推理和ASR到达波动，不能全部归因为严格固定的600ms。

25例最终ASR与旧T2逐字相同，最终模型前缀与ASR一致；20例有完整参考，952词/70处编辑，参考差异7.35%，另5例无完整参考。最终文本相同不代表逐拍交付时间完全相同。
