# `tests/test_datagen_pilot.py`

整体功能：针对数据导出的因果和监督边界提供正例与破坏性反例，防止未来信息、重复回答或取消后续播混入数据。

`PilotTests` 使用固定人工场景的独立副本。核心方法覆盖：三视图计数与训练阻断、晚到分析在本次生成中不可见、共享前缀一致、不确定标签零损失、固定错误仅作为条件、装箱穷举核验。

17 项测试包含破坏性反例，分别破坏未来事件、隐藏剧本、complete 边界、回答去重、分析依据、共享前缀、未来澄清所需控制输入、取消历史、生成账本、原生状态集合与活动任务合并，要求导出器明确拒绝。测试不调用模型、TTS 或远端调度；远端验证使用受限运行入口另行记录。
