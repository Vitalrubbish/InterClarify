# TextTurn 共享转写测试

对应 `tests/test_textturn_context.py`，以三个契约测试覆盖版本幂等／乱序／回写拒绝与关闭、三步聚合及EOF短尾窗、一个在途加一个待处理时的累计文本合并。通过线程事件控制顺序，避免依赖固定睡眠猜测竞争状态。不加载模型或GPU，不代替远端Nemotron验证。

TT-007增加一项160ms单步合同验证：每次真实解码均产生完整控制周期，重复文本形成no-voice，结束后没有待凑齐的残窗；连同原三项共4项，保留480ms回归覆盖。

TT-010重建后，160ms用默认构造验证，三步聚合及EOF回归显式传480；仍为4项测试。这样同时检查新默认与旧配置兼容，不因改默认值使历史测试悄悄换周期。
