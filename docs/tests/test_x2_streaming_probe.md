# X2 探针本地用例

对应 `tests/test_x2_streaming_probe.py`。用例只加载 `scripts/remote/x2_streaming_probe.py` 的纯 Python 合同，不加载 4B 权重。

覆盖：

- `[W]…[P]` 与 `[W]…下一个[W]` 才闭合；结尾未闭合组单独保存，没有 `[W]` 的文本记入 `unbound`；
- 组闭合后累计解码文本必须保持前缀，违反时给出位置、闭合文本和后续文本；
- 全局累计文本回改检测；
- 分位数与门槛计算，包括任一条超限即整体失败；
- 最长用例与指定用例选择。

真实特征形状、padding cache 和实时性能由远端合成音合同自检与 FDB 回放验证，本地用例不替代这些证据。
