# 教师文字同步契约测试

对应 `tests/test_nemotron_teacher.py`。用轻量生成循环替身检查 AST 调整后最后 token 交付、完成回调、屏障释放和下一特征读取的实际顺序；检查无字步骤、越序释放、取消唤醒及教师字符游标。SharedContext 的独立用例检查来源固定与关闭后拒绝更新。

测试只证明协议和代码顺序，真实权重的文字及状态质量在远端 FDB 实验验证。本地使用既有 conda 环境，不创建模型或下载权重。

NTF-003 增加实际采样进度配对用例：92.5ms首块不产生状态，259ms窗口配对160ms主块，启动文字不丢失，后续原生步号与教师步号独立，覆盖不足／越序／不连续窗口拒绝。有限真实音频回放替身检查EOF不等待不可满足窗口、在线正文与排空分离、启动及正常释放顺序；旧空增量规则测试继续通过。

NTF-004增加两次前向的实际输入检查、关门积压后再开门、未知状态不反馈、词内扩展重分词、独立可变KV检查点、跨多片段有界重建、历史实际状态保留、reset不重复消费、原始正文与控制格式分离、EOF不补消费，以及序列/重放上限失败。普通门控预测只能决定消费，不能出现在输入账本。

补充检查关门期间已消费token发生修订但不提前改KV，以及规范化前缀缩短到空时完整移除对应文字、保留EOS和真实历史状态。

真实模型与替身统一使用冻结ASR结束符ID151674；与五类状态token独立核查，结束符不能作为普通正文或状态反馈。
