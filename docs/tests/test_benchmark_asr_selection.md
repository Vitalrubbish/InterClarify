# test_benchmark_asr_selection.py

验证评测基础契约，不加载模型。覆盖重复词编辑对齐、替换／插入／删除、空输出分母、标点边界，以及独立时钟在规定音频时刻之前不能返回未来样本。`EventSink` 的原始文本回写须被记录，不能被前缀冻结隐藏。

测试使用本地 conda，重型推理依赖仅在实际入口加载，避免为了这些契约测试安装 GPU 框架。

独立 CTC 对齐覆盖重复字符必须经过 blank，以及不足音频帧时必须拒绝伪造对齐。

延迟测试覆盖正确词的测量覆盖率、负值不能被裁零，以及超时空输出须以全删除计入 WER。重复词编辑代价相同时，优先保留更多正确匹配词，减少任意对齐对延迟覆盖率的影响。

标点回归区分内部逗号与累计文本末尾句号，并检查 EOF 才出现的句末符号单列。

并行汇总覆盖同一配置／轮次出现两个分片结果时必须拒绝静默选取，以及五分片三轮的配置分配每轮恰好覆盖五配置。

没有逐字参考的 FDB 接话样本不应制造 WER；空参考和空输出／失败参考两个情况分别验证。
