# InterClarify 流式 ASR 技术选型报告

编制日期：2026-10-20。主要测量依据为 2026-10-16 选型报告，并纳入 2026-10-18 官方输入对齐复测及 2026-10-19 文本形式核验。本文整理已有证据，不启动新测试，不变更组件或研究范围。

## 1. 选型结论

英文开发主线采用 **NVIDIA Nemotron Speech Streaming EN 0.6B，160ms 配置**。在固定 FLEURS 英文子集上，其 WER 为 **7.68%**，正确且可对齐词的估计交付延迟 P50/P95 为 **414/1,033ms**，在本轮候选中逐词交付中位数最低。保留 Kyutai STT 1B EN/FR 500ms 作为官方 DuplexCascade 权重的对照；Nemotron 3.5 多语言配置不进入当前英文主线。

该结论遵循 2026-10-18 已确定的开发路线，取舍是优先保证识别质量和典型增量交付速度，并承担 Layer 1 适配成本。Nemotron 几乎不在在线文本末尾输出句末标点，且未经适配的官方控制权重接话不足。组件选定不代表端到端双工能力或全链路延迟已验收；如果限定完全不调整官方控制权重，现有五例证据更支持 Kyutai 的接话兼容性。

决策依据见[原始选型报告](../reports/asr_selection/20261016-results/summary.md)与[官方输入对齐复测](asr_official_input_retest.md)。原决策文档已按用户要求由本文取代；英文主线与兼容性限制汇总于下文。

## 2. 选型要求

| 要求 | 项目需要与评价方式 |
| --- | --- |
| 真正在线交付 | 持续接收音频并交付当时可见的增量，不等待完整录音；模型分块、传输包和 600ms micro-turn 分别记账。 |
| 转写准确性 | 使用相同英文录音、参考文本和标准化规则计算 WER，兼顾实体、数字与尾词；朗读集结果仅作为组件比较依据。 |
| 低延迟与稳定性 | 同时报告逐词交付、长尾、输入发送迟到及预热失败；不以模型标称分块替代实测。 |
| 可追踪的前缀 | 记录原始文本、实际到达时间、回写与 EOF 排空；不能靠冻结冲突前缀掩盖回写，造成后续文本停滞。 |
| 控制权重兼容 | 在同一官方权重、输入规则与生成预算下检查用户结束后的新正文启动；分别评估句读、发布粒度和时钟差异。 |
| 句读形式透明 | 统计在线与 EOF 后的句末标点，避免将内部逗号、最终补点或标点 F1 当作在线结束信号。 |
| 可部署、可复核 | 远端独立 conda 环境、固定源码和模型来源，保存退出状态与资源证据；暂停恢复、连续会话、取消和短尾另行验收。 |
| 保持 MVP 边界 | ASR 只提供转写及生命周期信息，不承担让轮仲裁；不补造句号、人工结束边界或未来转写，沿用单一控制及播放路径。 |

已有资料没有给出本轮通用的 WER 或延迟硬门槛，因此本文按同集比较及系统兼容性做取舍，不补写事后合格线。英文是当前范围，多语言能力不作为额外加分项。

## 3. 候选范围与测试口径

### 3.1 正式同集候选

| 模型来源标识 | 配置 | 测试精度 | 本轮定位 |
| --- | --- | --- | --- |
| `nvidia/nemotron-speech-streaming-en-0.6b` | 160ms、560ms | FP32 | 英文准确性与低延迟候选 |
| `nvidia/nemotron-3.5-asr-streaming-0.6b` | 320ms、560ms | FP32 | 多语言模型的英文对照 |
| `kyutai/stt-1b-en_fr` | 500ms | BF16 | 官方控制权重的 ASR 对照 |

Nemotron 3.5 的发布 processor 不支持此次尝试的 160ms，实际使用支持的 320ms 档，未修改权重配置。表中的毫秒是配置标识，不能直接视为逐词或端到端延迟。模型标识及计分规则另核对了历史脚本快照 `6c75f38d659998d6f149923085d82c0d7db267c5` 的 `prepare_asr_selection.py` 和 `benchmark_asr_selection.py`。

### 3.2 数据、运行与指标

各配置共用 FLEURS `en_us/test` 按音频文件名哈希确定性选取的 **100 条独立录音**，总长 **969.26 秒**，标准化参考共 **2,162 词**；另用 dev 音频预热。五个配置在五张独占 RTX 4090 上并行，每轮后轮换配置，计划重复三轮。15 次配置运行中 14 次成功；EN 160ms 一轮预热失败，只有两轮有效结果，其余各三轮。重复不增加独立音频数量，不构成 200 或 300 条独立样本。

- **WER**：参考和假设均经 `whisper-normalizer==0.1.12` 的 `EnglishTextNormalizer` 标准化，再按 `(替换 + 删除 + 插入) / 参考词数` 汇总。句读质量单独评价；WER 不是原始字符错误率，也不宜简单改写为“识别准确率 = 1 − WER”。
- **估计逐词交付延迟**：文本首次交付时间减去独立 CTC 强制对齐估计的参考词结束时间。仅统计识别正确且能对齐的词，错误词及不可用对齐不填造延迟，须同时报告覆盖量。
- **回写**：本轮可见累计文本没有观测到回写；这一结果不证明任意长会话始终稳定。

主表采用[重复轮次汇总 JSON](../reports/asr_selection/20261016-results/component_repeated.json)及其[可读表](../reports/asr_selection/20261016-results/component_repeated.md)。[首轮结果](../reports/asr_selection/20261016-results/component_100_round1.md)是其中一轮，不能与重复汇总混拼。

## 4. 延迟与转写 WER

| ASR 配置 | 有效轮次／样本次 | WER | 估计逐词交付 P50/P95，ms | 可测正确词／参考词 |
| --- | --- | --- | --- | --- |
| Nemotron EN 160ms | 2／200 | 7.68% | 414 / 1,033 | 3,068 / 4,324（70.95%） |
| Nemotron EN 560ms | 3／300 | 7.59% | 583 / 1,234 | 4,614 / 6,486（71.14%） |
| Nemotron 3.5 320ms | 3／300 | 9.71% | 537 / 969 | 4,494 / 6,486（69.29%） |
| Nemotron 3.5 560ms | 3／300 | 9.67% | 642 / 1,373 | 4,485 / 6,486（69.15%） |
| Kyutai 500ms | 3／300 | 21.97% | 713 / 953 | 4,074 / 6,486（62.81%） |

所有有效测量回写数为零。框架峰值 allocated 显存约为 EN 2.35GiB、Nemotron 3.5 2.43GiB、Kyutai 2.43GiB，该数值不等于完整服务显存预算。Nemotron 与 Kyutai 精度、实现不同，本表比较实际冻结配置，不是相同精度下的架构性能实验。

EN 560ms 相对 EN 160ms 的 WER 只低约 **0.09 个百分点**，逐词中位数增加约 **169ms**；在当前增量交互目标下选择 160ms。Kyutai 相对 EN 160ms 的 WER 高 **14.29 个百分点**，逐词中位数慢约 **299ms**，但其 P95 略低，不能写成所有分位数都更慢。不同配置的可测正确词集合不同，这些差异是描述性结果，未做显著性检验。

## 5. 句末标点输出习惯

“在线句末标点”检查 **EOF 前最后一份在线累计文本**是否以 `.`、`!` 或 `?` 结尾，允许后跟引号等闭合符号；不是统计全程任意时刻出现过句号。“最终”检查 EOF 排空后的文本。“仅 EOF 补齐”指在线末尾无句末标点、最终末尾有句末标点。以下均为样本次，重复录音不增加独立样本。

| 配置 | 在线末尾有句末标点 | 最终末尾有句末标点 | 仅 EOF 补齐 | 在线含任意诊断句读 | 标点 F1 |
| --- | --- | --- | --- | --- | --- |
| Nemotron EN 160ms | 1/200（0.50%） | 2/200（1.00%） | 1/200 | 123/200 | 0.494 |
| Nemotron EN 560ms | 2/300（0.67%） | 3/300（1.00%） | 1/300 | 193/300 | 0.506 |
| Nemotron 3.5 320ms | 6/300（2.00%） | 6/300（2.00%） | 0/300 | 180/300 | 0.472 |
| Nemotron 3.5 560ms | 3/300（1.00%） | 9/300（3.00%） | 6/300 | 183/300 | 0.465 |
| Kyutai 500ms | 191/300（63.67%） | 282/300（94.00%） | 91/300 | 250/300 | 0.615 |

数据来自[同一汇总 JSON](../reports/asr_selection/20261016-results/component_repeated.json)。诊断句读集合为 `.,!?;:`；标点 F1 按表面词边界匹配这些符号，不是句末标点正确率。在线或最终末尾出现比例也不是标点准确率，更不是用户结束检测率。本轮没有有效的句末标点生成延迟测量，不能从出现次数反推补点耗时。

Nemotron 的特点是**会输出内部句读，但极少以句末句读结束在线累计文本**，不应描述为“完全无标点”。Kyutai 更常以句末标点结束，但 91/300 样本次直到 EOF 后才获得末尾标点，不能把最终 94% 当成在线可用率。实时持续会话中的声学停顿不等于真实 EOF。

2026-10-19 的[文本形式核验](../reports/asr_text_surface/20261019/README.md)进一步确认 EN160 保留大小写、能输出内部句号和逗号，且存在 `D → Don → Don' → Don't` 等词内增量。数字、时间在所检样本中常以英文数词表达，不能据此声称永不输出阿拉伯数字。该核验使用六条合成音频，不是新的流式延迟或 WER 基准。

## 6. 句读与官方控制权重的兼容性

2026-10-16 用 FDB Candor 接话五例（1、10、100、101、102）保存的真实 ASR 到达轨迹回放官方 DuplexCascade 权重，固定 600ms、64-token 贪心及原始生成 ID 历史；比较原样与去句读文本。后续发现旧 prompt 留有拍首空白，改变实际 token，因此 **2026-10-18 官方输入对齐复测优先于旧接话统计**，既有 ASR WER 不受此修复影响。

| 配置 | 10-16 原样／去句读：2s 内新正文 | 10-18 official 原样／去句读：2s 内新正文 |
| --- | --- | --- |
| Nemotron EN 160ms | 1/5 ／ 1/5 | 0/5 ／ 0/5 |
| Nemotron EN 560ms | 0/5 ／ 0/5 | 1/5 ／ 0/5 |
| Nemotron 3.5 320ms | 0/5 ／ 0/5 | 0/5 ／ 0/4，分片异常 |
| Nemotron 3.5 560ms | 1/5 ／ 1/5 | 1/5 ／ 1/5 |
| Kyutai 500ms | 5/5 ／ 2/5 | 5/5 ／ 3/5 |

official 已保存的 1,275 次请求全部通过 prompt token 级审计；正常退出分片占 1,050 次。两臂原计划 100 条，实际保存 98 条；320ms 两臂均只保存 9 条且退出码为 1，缺失末例不能视为普通未接话或成功。其他四配置共 80 条属于正常完成配对分片。

official 将观察窗延长至 12 秒没有增加新回复。Kyutai 原样五例的新正文启动约为用户标注结束后 0.215–1.504 秒，尚未包含 TTS 与播放。这里“新正文”排除仅 finish token 和跨边界旧正文续写；统计未回复的完整样本时保留分母。五例不足以估计一般接话成功率，也不是正式 FDB TOR 或有声验收。

Kyutai 去句读后从 5/5 降至 3/5，支持控制权重存在句读依赖；EN160 去句读仍为 0/5，说明删标点不能解决兼容性问题。官方 Kyutai Word 事件与 Nemotron 原始字符／词内增量、起拍时钟仍有差异，因此不能把全部接话差异唯一归因于句号。来源：[原始接话报告](../reports/asr_selection/20261016-results/summary.md)、[官方输入对齐复测](asr_official_input_retest.md)。

## 7. 历史方案及最终取舍

Qwen3-ASR-1.7B 和 X2Streaming-ASR-4B 是此前的部署与诊断方案，没有参加上述三模型、五配置的 FLEURS 同集比较，不能填入可比的 WER、逐词延迟或句末比例。

| 方案 | 已有证据与处理 |
| --- | --- |
| Qwen3-ASR-1.7B | 历史回写与前缀冻结造成交付停滞，已退役；同口径 WER、ASR 交付延迟和句末比例缺测。 |
| X2Streaming-ASR-4B | 已退役并从仓库移除（2026-10-20 用户确认彻底放弃诊断路线）；历史存在首会话预热、异步末次读取及 EOF 排空问题；同口径三项指标缺测，实现可按固定 Git 提交追溯。 |
| Nemotron EN 160ms | 采用为英文主线：本轮 WER 较低、逐词中位数最低；需处理控制迁移，并保留长尾与预热风险。 |
| Nemotron EN 560ms | 当前不采用：WER 收益很小，典型交付更慢。 |
| Nemotron 3.5 320/560ms | 当前不采用：本轮英文 WER 高于 EN，未呈现足以改变当前路线的综合优势；320ms 控制复测还存在未完整退出问题。 |
| Kyutai 500ms | 保留官方权重对照：句末输出与五例接话兼容性较好，本轮 WER 明显偏高。 |

Qwen/X2 的历史 FDB 数秒延迟含控制和播放链，不能当成 ASR 延迟与上表比较。历史来源见[底座证据索引](baseline_evidence.md)，过时文档可按索引中的固定 Git 提交追溯。

最终按 **Nemotron EN160 + 有限 Layer 1 适配**继续推进，不重开组件比较。固定真实增量、大小写、句读及到达时间，不用人工补点改善接话成绩；对照保持相同 ASR/TTS。尚需由实际对话与全链路验收证明接话、误抢话、附和、有效插话、内容质量和播放延迟达到项目需要。现有证据不支持“Nemotron 已解决双工接话”或“Kyutai 总体最好”的结论。
