# 边听边想：主动介入 benchmark 与训练数据

更新：2026-10-29。[研究方案](../research_design.md) · [架构设计](architecture.md) · [边说边想](speaking.md)。

当前采用 SoulX-Duplug，五类状态输入、普通回答生成及直接打断遵循[架构第 2.2 节](architecture.md#22-前端状态与系统附和)。后续音频、转写与 CoT 联合控制尚未实现；主动澄清的独立生成边界仍待设计，见[第 2.5 节](architecture.md#25-soulx-的-cot-条件化控制)。

本文检验倾听期间的 thinking 流能否带来更合理、及时的主动澄清，并设计相应的大规模训练数据。运行合同与训练对象采用架构文档，Layer 3 定位待统一；Layer 2 只向共享上下文发布 CoT，不提供话轮建议或候选问句；后续经适配和训练的 SoulX 提供介入相关判断，Layer 1 读取控制器输出与分析结果决定自身行为并组织实际表达，经统一仲裁和单一播放路径发声。普通回答的 `user_complete` 边界不等于未来主动澄清的全部生成规则，后者需单独设计。

## 1. 任务与在线决策

本文将主动插话定义为：用户尚未明确让出话轮时，系统主动发起一个要求用户暂停、让出话轮或改变当前表达方向的介入行为。

- 附和不一定要求用户停下，不能仅凭语音重叠认定为主动插话。
- 用户短暂停顿时仍可能持有话轮，因此没有语音重叠也可能构成插话。
- 系统尝试介入但用户继续说，仍属于插话尝试；取得话轮不等于介入合理。
- 用户已明确让出话轮后的询问属于轮后介入，是重要对照。

“是否插话”和“何时插话”采用统一视角，后续由 SoulX 在合法输入边界联合利用当时可见的音频、转写文本和 CoT，并结合真实运行状态判断继续听或介入；连续选择继续听，直到某一时刻介入，就形成了宏观插话时机。用户话轮结束前始终不介入，也是一种合法结果。CoT 更新是否独立触发控制请求待设计，不直接沿用旧文本控制器的事件调度。Layer 2 只提供任务分析，不输出介入动作，也不要求在每个 micro-turn 内完成一次推理；其异步调度见[架构文档的分步推理](architecture.md#31-持续输入与分步推理)。

设截至当前的信息为 H_t，每次决策比较：

> 现在介入的预期价值，与继续倾听、并在后续重新决策的预期价值。

继续听不等于承诺等到话轮结束。它保留下一时刻介入的机会，也可能带来补充信息、更自然的边界，或不断增加的无效表达与返工成本。

决策只能依赖当时可获得的信息，不能读取尚未发生的后续表达。评测可分别分析误插话、过早、过晚和合理等待，但这些是同一策略的结果，不预设“是否插话”与“何时插话”必须由两个独立模块判断。[架构文档的模块分工](architecture.md#2-模块与动作边界)的思考与表达分工属于系统职责划分，与这一统一决策视角兼容。

## 2. 主动介入的合理性条件

系统主动介入可以服务于澄清、纠错、引导或提醒等不同目的。判断其合理性，需要说明为什么值得在当前时刻打断用户，并与继续倾听、允许随后重新决策进行比较。本文从以下四个方面分析：

1. **任务相关性**：介入针对的问题是否实质影响当前任务的理解、推理或行动，值得占用用户的话轮。仅发现表述不精确、存在遗漏或可以补充的内容，不足以支持打断。
2. **证据充分性**：截至当前的信息是否足以支持拟采取的介入。不同目的需要不同证据：澄清需要有依据的信息缺口，纠错需要支持用户确实有误的依据。判断还需考虑用户是否正在自行解决问题，不能将系统尚未理解直接视为用户有误。
3. **提前介入的增量价值**：相较于继续倾听，现在介入能额外避免什么损失或保留什么机会。应考虑用户可能自行补充或调整、后续内容对当前问题的依赖程度，以及稍后仍可介入的机会。问题重要，不代表立即介入比稍后处理更有价值。
4. **介入成本与方式**：介入是否会截断关键补充、打乱思路、要求重复或增加恢复负担；能否通过选择临近的自然边界、缩短表达和明确目标来降低成本。合理性判断针对具体内容、表达方式和开口位置，不能只判断抽象的介入意图。

这四点构成待验证的分析框架，尚不是已经验证的充分必要条件，也不作为四项独立评分或机械相减的量表。介入应有支持其任务价值和当前时机的依据，并结合表达成本判断；低成本本身不能证明值得介入。第 3 节进一步展开增量收益与负面影响的定性分析。

本文讨论倾听 benchmark 中的主动澄清；其他面向用户的主动介入目的留作后续扩展。表达期间的回答递进与自我修正见[表达文档](speaking.md)，不套用主动澄清的事件标签。

### 2.1 四个条件在主动澄清中的表现

主动澄清通过询问获取影响当前任务的缺失信息。四个条件在这一行为中的具体表现如下：

1. **任务相关性**：未解决的信息缺口是否会改变任务理解、推理或后续行动。例如，报考类别会决定应阅读哪部分专属要求；不影响任务的措辞细节则未必值得追问。
2. **证据充分性**：当前对话和可用任务信息是否表明相关信息确实尚未获得，以及用户是否已经给出即将解释的迹象。“就是那个……”或“我看一下报名信息”等表达可能支持短暂等待；未发现自行澄清的迹象，也不能单独证明应当立即询问。系统不知道用户类别时，可以询问类别，但不能据此断言用户正在阅读错误资料。
3. **提前介入的增量价值**：现在获取答案，是否可能避免用户沿不适用方向继续展开，且短期等待不太可能获得同样信息。预计剩余表达较长是一种线索，还需考虑后续内容是否依赖该答案。长篇共同要求仍然相关，未必需要打断；即将自然结束时，提前询问的额外价值也可能很低。
4. **介入成本与方式**：问题是否简短、具体、易于回答，开口位置是否便于用户恢复表达。例如，在逐条阅读前确认类别，可能比在关键条款中间追问更容易恢复。用户正在解释类别时插话，既可能截断答案，也可能增加重复和恢复负担。

原先的三个初始条件在这里得到保留和展开：“内容重要”对应任务相关性；“没有正在自行澄清的迹象”同时影响证据判断与提前询问的增量价值；“预计还会说很久”作为等待代价的线索；介入成本与方式则补充了对具体问句和开口位置的考虑。

将“预计还会说很久”推广为“继续等待的预期代价较高”，仍是待检验的研究假设。本方案同时保留剩余时长及其他等待代价线索，不将推广后的条件视为已确定结论。

### 2.2 剩余表达时长的使用方式

当前将预计剩余表达时长作为隐式决策线索，不要求额外标注或输出剩余秒数、时长类别。Layer 2 的 CoT 分析任务事实、缺口和依赖影响；等待与介入的价值及交互成本由后续适配的 SoulX 结合当前信息判断，不再由 Layer 2 的 system prompt 输出动作建议。训练数据覆盖相关线索及其反例，具体监督模块见[第 7 节](#7-倾听训练数据与训练目标)。不预设现成模型或训练后的模型已经能正确利用这些线索，具体表现由评测检验。

数据采用混合线索：既覆盖“还有十几条”“最后一句”等明确提示，也覆盖由任务规模、枚举结构和表达进度推断剩余时长的自然线索。围绕相近的信息缺口构造预计较长、预计较短的对照，同时保留“虽长但内容相关”等反例，避免将表达较长直接等同于应该插话。具体混合比例与训练方法尚未确定。

这里的剩余时长指系统继续倾听条件下的预计剩余表达。训练监督针对当前可用证据，不能仅凭完整后续实际较长就判定当前应当介入；共同前缀在尚未出现区别时应保持一致的监督。上述决定不意味着已确认剩余时长是插话的必要条件，也不意味着已确认等待代价的推广假设。

## 3. 收益与负面影响的场景分析

每个分析针对明确观察位置、明确介入内容，并与“继续听且允许随后重新决策”比较。以下收益与负面影响是解释倾听任务决策依据的定性框架，不作为两项相减的评分，也不新增人工收益或成本等级标签。倾听 benchmark 的行为评分与思考收益对照见[第 5 节](#5-benchmark-评分与优势判定)；首版不实测确认耗时、重复表达或恢复负担。

### 3.1 主动插话获取信息的正向收益

这里评估的是现在主动获取信息的增量收益，而非该信息本身的重要程度。即使报考类别很重要，如果用户正在解释，立即追问的增量收益也可能很低。

| 等级 | 暂定含义 |
| --- | --- |
| 高 | 能及时解决关键理解障碍，明显避免后续错误、无效表达或返工；短期等待不太可能获得同样信息 |
| 中 | 能减少有意义的不确定性，但暂不阻碍后续理解，或稍后询问的损失有限 |
| 低 | 信息已经获得、与任务关系弱、正在由用户补充，或即将自然到达轮后询问机会，提前获取的额外价值很小 |

### 3.2 主动插话的负面影响

评价现在介入本身可能带来的表达与交互成本，包括截断关键补充、打乱思路、要求重复、增加恢复负担，以及削弱用户对表达进程的控制。

| 等级 | 暂定含义 |
| --- | --- |
| 高 | 截断正在发生的解释或关键表达，明显破坏连续性，容易迫使用户重述或失去思路 |
| 中 | 打断正常表达，需要一定恢复，或引入可避免的额外问答，但较容易接回原话题 |
| 低 | 在较自然的边界提出简短、具体且相关的确认，预计用户容易回答并恢复表达 |

两个分析维度分别讨论，不机械相减。高收益不自动意味着应该立即开口；低负面影响也不足以证明一次低收益插话有必要。措辞、长度、语气和实际开口位置都会改变成本，因此同一场景可以有多种不同质量的介入。

## 4. 共享前缀与分支案例

### 4.1 设计依据

核心场景应体现：当前缺少的信息，会决定用户接下来哪些话值得说；如果不及时确认，用户可能沿不适用的分支持续展开。

仅有关键指代歧义不足以说明现在应当介入。系统有时可以完整记住用户的话，最后确认指代，再统一处理，而无需用户重述。这里用资料适用性和诊断方向两个日常例子，说明哪些当前证据可能支持等待或提前澄清；潜在节省不是首版实测结果。

`｜` 表示当前观察位置。各分支描述可能的续说行为，不是系统能够预知的未来。同一前缀下，系统只能采用相同的信息条件和决策规则；不能因未来分支不同而要求不同反应。以下等级针对各分支新增信息后的指定位置，不给共同前缀强加唯一动作或不同评级。文中的候选问句和假设回答只帮助解释场景，不构成待标注的参考问句或必须采集的后续交互。

### 4.2 案例一

设通知明确区分学术学位与专业学位，包含共同要求及各自专属条款。用户只想了解自己报考类别的要求；系统尚不知道该类别，也无法直接读取通知，需要用户口述相关内容。

共同前缀：

> 用户：“帮我看看这个复试要求，我把通知念给你。这里先分学术学位和专业学位两部分，我先从学术学位这部分开始，里面说考核分成……”

关键确认问题是：“先确认一下，你报的是学硕还是专硕？”这个问题可能改变接下来应阅读的部分，但此时不能断言用户一定读错。

#### 分支一：用户立即自行调整

> 用户继续：“不过我报的是专硕，我直接看后面的专硕部分。｜”

理想反应：继续听，更新用户类别和阅读方向。

此时再询问报考类别，正向收益为低：信息已经给出，用户也在调整。负面影响为中：打断正在发生的调整，并可能要求重复。

#### 分支二：用户明确当前资料适用

> 用户继续：“我报的就是学硕，先说考核方式，后面还有材料和成绩计算。｜”

理想反应：继续听，收集适用条款。

再次确认类别的正向收益为低，负面影响为中：没有新增信息收益，却会打断相关内容。用户还会说很久，本身不构成插话理由。

#### 分支三：用户准备长篇展开，类别仍未明确

> 用户继续：“这一部分有十几条，我从考核方式开始，再把材料要求和成绩计算逐条念一下。｜”

理想反应倾向：在逐条展开前简短确认：“先确认一下，你报的是学硕还是专硕？”

正向收益暂定为高：一个短问答可能避免较长的不适用口述；负面影响为低至中：在枚举前的边界确认，通常比在具体条款中间开口更容易恢复。收益大小仍取决于读错类别的可能性、两类条款差异及预计口述长度，不能无条件认定每次询问都有高收益。

若用户回答“专硕”，系统可说：“那先念专硕对应的部分吧；前面如果有共同适用的要求，也一起看。”若回答“学硕”，则继续当前部分，不应断言用户原先读错。

在确实读错专属部分的情况下，轮后策略即使完整记住所有条款，仍需要用户补充适用部分；记忆与重命名不能把学硕专属条款变成专硕要求。提前确认可以避免其中尚未发生的无效口述。但这只是条件下的结果优势，在线决策仍须依据当时的信息与风险，不能用未来回答倒推系统必然应当插话。

#### 分支四：当前部分很短，即将转到另一部分

> 用户继续：“学硕部分就这一句，下面马上就是专硕要求。｜”

理想反应：继续听，不必为了提前确认而打断当前转换。

正向收益为低：很快就会进入另一部分，避免的口述有限。负面影响为低至中：虽容易恢复，但会增加一次可能不必要的问答。后续若继续展开不适用内容，应重新决策。

#### 分支五：用户正在解释自己属于哪一类

> 用户继续：“我报的类别是……我看一下报名信息，｜叫专业学位，那应该看后面那部分。”

理想反应：在用户检索、解释类别时短暂继续听；听到“专业学位”后更新理解。

在标记位置，用户已表示正在检索类别，短暂继续听可能获得答案；此时追问类别的增量收益低，负面影响可为高。标记后“专业学位”尚未到达，不能用于当前判断；实际听到后才更新类别。这里不把所有停顿都判为不能介入；若用户长时间无法确定，帮助查找类别可能更合适。

#### 分支六：长篇内容共同适用，不确定性暂不阻碍理解

> 用户继续：“前面这十几条是两类都适用的通用要求，我先念这些，分开考核的部分在后面。｜”

理想反应：继续听共同要求，在进入分类条款前或轮后再确认类别。

现在确认类别的正向收益为低：虽能补充类别信息，却不能省去本来就相关的通用内容。负面影响为中：会打断适用资料的阅读。不能把用户说得久直接算成无效表达。

#### 核心例子对照

| 已观察到的续说行为 | 候选插话 | 正向收益 | 负面影响 | 理想反应倾向 |
| --- | --- | --- | --- | --- |
| 已说明报专硕并自行切换 | 再次确认类别 | 低 | 中 | 继续听 |
| 已说明报学硕，当前部分适用 | 再次确认类别 | 低 | 中 | 继续听 |
| 类别未明，准备长篇念专属条款 | 先确认类别 | 高，需满足上述风险与长度条件 | 低至中 | 在展开前确认 |
| 当前部分很短，即将切换 | 提前确认类别 | 低 | 低至中 | 继续听 |
| 正在检索并解释类别 | 中途追问类别 | 低 | 高 | 观察解释完成 |
| 接下来是两类共同要求 | 立即确认类别 | 低 | 中 | 暂存问题，继续听 |

这些评级是待验证的定性假设，未严格控制各分支的表达成本，不作为标注真值。构造对照时可以保持信息需求接近，改变续说证据和插入位置；首版按[第 5 节](#5-benchmark-评分与优势判定)评价决策与模型实际提出的问题，不要求人工编写标准问句。

### 4.3 案例二

共同前缀：

> 用户：“打印机一直没反应。我把电脑里的打印设置都跟你说一下：首先纸张选的是 A4，方向是纵向，接下来还有页边距、缩放比例、打印范围……”

系统尚不清楚“没反应”的具体表现。候选插话是：“先确认一下，打印机屏幕或电脑上有没有错误提示？”

| 已观察到的续说行为 | 此时询问错误提示的正向收益 | 负面影响 | 理想反应倾向 |
| --- | --- | --- | --- |
| “这些设置还有很多，我逐项念给你。” | 高，提示可能改变诊断方向，避免当前不必要的设置说明 | 低至中，在设置项目边界询问较易恢复 | 优先获取关键诊断信息 |
| “对了，屏幕上写着‘缺纸’。” | 低，关键提示已经主动给出 | 中，会重复已知问题 | 继续接收提示，再决定后续问题 |
| “我先看看屏幕提示，写的是……” | 低，用户正在提供答案 | 高，可能截断关键提示 | 短暂继续听 |
| “就这两项设置，其他没改，说完了。” | 低，轮后询问已很近 | 低 | 等待轮后询问 |

在第一个分支中，若用户回答“显示缺纸”，系统可以先围绕这一提示处理，而不必让用户立即念完所有版式设置。与轮后询问相比，潜在收益是减少尚未必要的口述；并非保证这些设置永远无关。

最后一个分支若已明确以“说完了”让出话轮，其后的询问属于普通轮后询问，不计作主动打断。该分支用于对照，不能把轮后接话标为必须在轮内介入。

该例的证明力度弱于明确分开的资料条款：错误提示可能没有解释全部问题，某些打印设置随后仍需确认。因此不能把全部未念内容都计为节省，也不能预先假定每个用户都会出现足以改变诊断方向的提示。

### 4.4 后续交互验证的条件

若后续研究提前介入是否优于轮后询问，需要验证：在相同任务与完成质量下，及时澄清能避免用户沿不适用方向继续口述，而且这份收益超过插话产生的成本。以下条件保留为后续研究参考，不属于首版倾听 benchmark 的执行或验收要求。

- 两种策略拥有相同背景信息。轮后策略允许完整记忆与推理，不能靠遗忘前文制造返工。
- 用户可以自然解释、自行调整，也可能原先就在说适用内容，不能预设其必然一路说错。
- 记录实际避免的无效口述、仍需补充的有效信息，以及确认、恢复和重复的时间；不能把所有缩短的表达都算作收益。
- 最终任务质量需相同或可比较，不能靠丢弃必要条款让提前介入显得更快。
- 同时比较在下一个自然边界介入。证明轮内介入有价值，不等于证明词语中间开口或越早开口越好。

首版倾听 benchmark 检验模型能否根据已到达的分支证据区分等待与介入，并通过计算预算与启动阶段的对照检验 thinking 流收益；它不执行上述交互结果验证。

### 4.5 扩展示例：边测量边口述

可保留一个较夸张的边说边做场景：用户检查柜子能否通过搬运路线上的几道门，一边测量一边报数，却量的是门框外侧宽度，而任务需要实际可通行宽度。系统若在下一次测量前确认口径，可能避免后续无效测量；等全部报完后再问，则可能需要重测。

在确认用户将持续采用不适用口径的分支，正向收益为高；若在报完一道门、转向下一道门的边界简短确认，负面影响为低至中。收益包含实际测量劳动，不能直接等同于节省口述时间。

这是语音协作任务的扩展示例，不作为当前纯口头对话的核心论据，也不据此扩展工程范围。

## 5. Benchmark 评分与优势判定

行为评分覆盖以下方面，并按[架构文档的共同实验协议](architecture.md#6-共同实验协议)比较 thinking 流带来的增量：

| 方面 | 评价内容 |
| --- | --- |
| 决策合理性 | 依据截至当前的可用信息，检查思考请求位置与介入时机；介入事件按必须介入、可选介入和不得介入评价，分别识别遗漏、合理等待及误介入 |
| 澄清内容 | 实际提出的问题是否针对影响当前任务且尚未解决的信息缺口，表达是否清楚、具体，是否重复询问已知或正在解释的信息，是否包含无依据的断言 |

主要报告必要机会覆盖率、误介入率、有效窗口内实际发声的比例与窗口内延迟，以及有效澄清内容的覆盖情况。思考启动位置用于调用策略诊断，不要求所有架构采用相同的请求动作；核心结论依据实际介入及其内容。以语义机会归并事件，报告各项分母；可选介入不计遗漏，同一机会不因跨窗口而重复计数。具体归并规则、误介入的事件分母及延迟统计口径在试标后冻结，失败与超时保留在总体覆盖统计中。

支持优势的结果应表现为：在可比较预算下，持续思考更及时地覆盖合理澄清机会，同时控制误介入和内容错误；或在相近行为质量下缩短从证据出现到有效问题被听到的时间。仅更早启动推理、发布更多 CoT 或比一律等到轮后的策略多插话，不足以支持结论。

模型仍需自主发现信息缺口和确定澄清目标，不以外部给定目标作为主要设定。为减轻标注负担，数据不要求标注者编写参考问句；澄清内容采用 LLM judge 按当前上下文评价，并由人工抽样复核 judge 的判定。继续倾听不要求生成澄清问题，也不能因没有问句而计为内容错误。内容评价的覆盖范围与决策表现分别报告，避免一律沉默获得虚高评价。

评测不需要用户在插话后回答或恢复表达，不计任务成功率、实际节省时间、确认问答耗时、用户恢复性重复或主观负担。样本中假设的后续回答可以解释场景，但不作为已发生的交互结果或当前决策可用证据。

评价依据当前可见前缀，不用未发生的后续倒推正确动作；相同可见前缀保持一致的信息条件。不预设每个位置只有一个正确动作或唯一最佳时刻。事件标注见[第 6 节](#6-事件标注与内容审核)，整体数据构造与训练见[第 7 节](#7-倾听训练数据与训练目标)。

## 6. 事件标注与内容审核

计数单位为背景对话及用户续说分支，并另报独立场景数；micro-turn、重叠窗口和增强视图不计作独立场景。原先主动澄清试标 200 条、训练 2,000—5,000 条、测试 300 条是旧专项方案的预算参考，不再作为整体研究的数据规模承诺。本项训练语料见[第 7 节](#7-倾听训练数据与训练目标)，表达任务的数据另见[表达文档](speaking.md#4-表达训练数据与训练目标)，两组 benchmark 与训练语料分别统计。

时序标注保留以下两类内容，不预先标注理想的计算完成或结果返回时刻：

| 内容 | 含义 |
| --- | --- |
| Layer 1 启动思考的位置 | 根据当前证据，适合生成请求 special token 并启动 Layer 2 的观察位置；请求不表示必须打断 |
| 实际打断事件窗口及类别 | 在用户尚持有话轮的语义事件区间，标注必须介入、可选介入或不得介入；标签只依据当时可用证据 |

介入类别按事件窗口定义，不要求每个 micro-turn 都执行一次动作：

| 类别 | 动作含义与评价原则 |
| --- | --- |
| 必须介入 | 根据当前证据，应在该机会的有效窗口内实际开口发起一次澄清；窗口内可继续等待更合适的位置，错过该机会仍未介入记为遗漏 |
| 可选介入 | 当前证据同时允许澄清与继续倾听，两者均可接受；未介入不记为遗漏 |
| 不得介入 | 当前证据不足以支持主动澄清，应继续倾听；此时发起澄清记为误介入 |

同一机会可能跨多个窗口；机会的归并和截止规则仍待细化，不能把连续窗口各算一次遗漏或要求重复插话。实际介入后的行为另行处理，不把固定回放中用户未被打断时的后续标签机械用于已发生插话的历史。首版不要求采集插话后的回答。思考请求位置独立判断，不从实际介入窗口机械反推一个固定提前量；不得介入时仍可能合理请求 Layer 2 分析任务。

上述为语义与观察位置标注，不将思考启动、CoT 发布、控制决策和实际开口视为同一时刻。无需打断的场景仍可能合理请求思考；Layer 2 可以发布 CoT 或结束任务，但不返回“继续倾听”决策，后续适配的 SoulX 独立判断等待或介入。实际使用的观察位置、计算完成、CoT 发布、对 Layer 1 和 SoulX 可见、控制返回和可听发声时间由运行时分别记录，作为诊断信息，不作为人工标注或金标监督。位置与音频时间、ASR 可见输入及 micro-turn 的映射规则仍待确定。

不设置人工参考问句标签。LLM judge 根据模型实际开口前可用的对话信息和输出问句，评价其任务相关性、是否针对未解决的信息缺口、是否重复询问，以及是否清楚、具体或包含无依据断言；不读取未来续说或隐藏答案。问句内容评价与时机评价分别报告。

人工抽样复核 judge 时，先独立判断问句，再对照 judge 的结论与依据；随机样本应覆盖判为合理和不合理的输出，疑难样本另列，避免仅查看一种判定。记录抽样方式、数量及人工与 judge 的分歧，不能将模型一致视为人工确认。judge 的具体模型、提示词、评分等级及抽检比例待试标后确定；校准使用试标数据，正式测试不用于反复调整 judge。

时序标注不等同于完整的自回归训练目标。不设置人工参考问句和采用 LLM judge 只规定标注与评价方式；训练中的结果上下文和表达目标见[第 7 节](#7-倾听训练数据与训练目标)。在线评测中的结果由被测系统实际产生，不能用预先算好的答案或理想返回位置伪造结果到达时序。

## 7. 倾听训练数据与训练目标

### 7.1 数据组成与记录单位

共同训练对象、字段、损失边界和数据隔离采用[架构约定](architecture.md#7-共同训练与数据约定)。本项构造大规模倾听对话轨迹，与表达数据配合训练，不以旧专项预算作为规模上限。

一个场景包含任务背景、当时可用的任务资料、已有对话及一个或多个用户续说分支；每条分支按因果顺序展开为训练轨迹。独立场景数与分支轨迹数分别统计，语义窗口不是独立对话。

| 数据类型 | 应覆盖的行为 |
| --- | --- |
| 值得提前澄清 | 自主识别关键缺口，在合理机会内询问 |
| 等待更合适位置 | 可以先请求思考，但暂不打断，在后续证据或边界重新判断 |
| 用户自行消解 | 观察用户补充，更新任务状态，避免重复询问 |
| 长篇但仍然相关 | 不因预计剩余表达较长就认定应该打断 |
| 即将交接或无需介入 | 保留合理沉默、轮后询问及无需额外思考的对照 |
| 已有介入与过期判断 | 根据已发生交互更新后续分析与表达，避免重复澄清 |

组合训练对话可在系统问题之后包含用户真实到达的回答，再衔接表达任务；这不改变首版倾听 benchmark 只评首次介入前历史的范围。

### 7.2 轨迹生成与审核

1. 生成背景与用户分支，围绕相近信息缺口变化自行消解、表达进度和后续依赖，避免只靠固定口头提示区分类别。
2. 按当前可见前缀标注请求思考的位置和介入机会；共享前缀没有出现区别前采用相同信息条件，不用最终用户类别反推当时必须介入。
3. 教师或原型按架构运行合同生成请求、Layer 2 的 CoT、SoulX 控制目标及 Layer 1 表达。CoT 描述事实、缺口、条件依赖与影响，不包含动作建议或候选问句；控制目标依据当时实际可见的音频、转写、CoT 和运行状态独立审核，保留实际注入顺序，问句由 Layer 1 或其表达教师生成。控制输出的编码后续确定。
4. 核验时序、控制动作、问题是否已解决、是否重复询问及有无无依据断言，覆盖用户自行补充、旧 CoT 尚未更新、CoT 未返回和无需介入的情形，区分合理等待、模型失败和真实无需澄清。人工抽检依架构共同规则覆盖通过与拒绝样本，不把模型一致当作人工确认。

不设置人工参考问句仅指本项评测不要求人工逐条编写标准问句；训练仍需经过审核的表达目标。judge 分数不直接作为正文目标，离线审核也不增加运行时语义复核模块。

### 7.3 模块监督与时序边界

| 对象 | 本项训练内容 |
| --- | --- |
| Layer 1 请求 | 根据当前线索产生请求 token，包含无需请求和请求后继续等待的对照 |
| Layer 1 表达 | 根据后续适配 SoulX 的控制器输出与已到达 CoT 决定自身生成行为，组织简短具体的问题并避免重复询问；运行时接收实际表达，不消费非打断状态 token |
| Layer 2 CoT（若训练） | 自主分析事实、缺口、条件依赖及变化，不监督话轮动作、状态转移建议或候选表达文本 |
| SoulX-Duplug 控制（后续） | 联合音频、转写文本与实际可见 CoT，结合 Listen 状态学习轮内澄清、合理等待及过期分析处理；具体输出编码待定，当前不训练 |

介入事件窗口是控制与行为的语义监督，不是 Layer 2 的建议标签，不能机械变成思考完成时间，也不能从实际介入反推固定提前量。思考任务生命周期与话轮状态分别记录；本项不新增人工“理想计算完成点”标签。实际发布与注入顺序由回放调度记录，模拟调度须明确标注。

CoT 输入块在 Layer 1 与 SoulX 的预测损失中屏蔽，请求、后续表达和控制目标分别监督，不要求控制器生成 CoT。若更新 Layer 2 权重，则另计 CoT 生成损失；是否更新采用共同训练约定，当前不预设已经训练或必须冻结。本轮不启动本篇数据构造、CoT 注入或训练。

### 7.4 规模与验收

试标、训练、开发和正式测试分别计数，具体规模与正负例配比待试标确定。除通过率外，还要检查独立任务覆盖、分支多样性、前缀一致性、因果时序与问句质量，不能以窗口数量或大量相同模板改写充当数据规模。

## 8. 对照实验与待定事项

运行无独立 thinking 流、延后启动、完整框架及关闭倾听期间思考的对照，并另报轮后策略。延后启动的触发规则和观察检查点须在测试前明确，不能用金标介入窗口通知系统开始思考。关闭倾听阶段思考时，明确活动任务的停止点、已有结果是否保留及后续阶段如何恢复。

按同一样本和可比较预算测行为质量与实际发声时间。报告观察证据到可听问题的延迟、误介入、必要机会覆盖、内容错误与计算开销；不把更早启动或更频繁请求作为核心收益。

训练实验按共同约定比较未专项训练、仅倾听数据、仅表达数据和联合训练，检验本项能力是否改善及是否被另一项训练损害。共享前缀家族按组统计不确定性，避免把相关分支当成独立证据。

尚待确定：生成规模与配比、标注人力、机会归并及截止规则、误介入分母、请求标签到训练目标的映射、judge 与抽检方案、观察位置到音频时间的映射。这些参数试标后冻结，不在文档拆分中自行补成既定结论。
