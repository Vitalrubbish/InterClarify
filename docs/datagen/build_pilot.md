# `datagen/build_pilot.py`

整体功能：读取五个来源的人工事件剧本，按模块实际构造输入的时刻，导出共同轨迹、SoulX-Duplug／Layer 1／Layer 2 三份语义 SFT 视图及中文审阅稿。只使用标准库，不加载模型。

本文说明既有 pilot v1 导出器。当前研究已将 Layer 2 固定为冻结推理层；旧 Layer 2 视图保留作历史诊断材料，不纳入专项训练。本轮不修改导出器或产物，后续数据升级再按当前周期协议记录思考轨迹和两个下游的监督视图。

本文件不定义类。`materialize` 合并来源共享前缀与分支；`visible_input` 只提取 `seen` 明确列出的事件，拒绝未来事件及隐藏剧本。控制器输入去掉本帧原始预测，避免把预测作为自身标签输入；Layer 1 保留含噪原始状态。精确已听文本只留在审计账本，模型常规输入使用生成历史、阶段和是否已播。

`check_events` 检查音频观察／状态处理／联合发布顺序、单活动思考任务、分析版本与实际观察依据、生成及已播历史单调追加、取消后的输出失效。`check_generation` 将模拟生成与此前完成的表达目标对应，固定错误前缀作为特例标明来源，但禁止作为正向表达目标；同时核对未来控制发布与其先前目标对应。`check_target` 检查普通回答的有效 complete 与去重、未来澄清实际读到独立控制判断、取消后不可续写、活动任务不重复请求，以及 Layer 2 仅输出分析。

`export_corpus` 汇总三份视图，核对共享前缀输入、目标及可接受动作一致。审核信息不进入 `messages`；外部条件与历史消息损失为零，目标消息损失为一，不确定控制目标损失为零。这个 `loss_weight` 是消息级说明，尚未实现模型专属模板、tokenizer、`labels=-100` 及多模态音频转换。

`render_review` 将每条派生轨迹和三模块目标写为中文审阅稿；`build` 在不存在的独立输出目录生成文件，拒绝覆盖，记录输入／实现／产物摘要与运行证据。清单分别统计分支展开样本与按输入、目标、协议范围去重的监督数，避免共享前缀复制扩大独立样本量。训练资格始终关闭；待独立审核、音频回放或未来协议接入等缺口明确列出。最大总输出为 16 MiB，运行脚本另外限制 CPU、内存和时间。

本轮只检查可程序验证的结构与时序；自然语言目标是否仅由前缀充分支持、澄清时机和附和恰当性仍待独立审核。程序检查通过不能代替该审核。
