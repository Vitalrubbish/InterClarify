# FLEURS 转写 WER 与输入末端 complete 测试

更新：2026-10-22。状态：已按用户澄清更新测试计划；X2Q-009 已完成固定输入恢复与复核，X2Q-011—013 已完成回放与独立评分逻辑、本地模拟验证；真实模型测试尚未执行。

## 范围

在历史固定 FLEURS `en_us/test` 100 条上保留原先 ASR 的基本转写 WER 与末端文本延迟，只把控制 token 测试简化为输入结束后的 complete 出现比例和延迟；dev 1 条预热不计分。[数据版本与选样规则](fleurs_subset_verification.md) 不变。取消逐位置 Judger 和强制对齐，不取消 ASR 质量测试。控制结果称为“输入末端 complete 输出率”，不称语义判断准确率。不运行 LLM/TTS 或上游控制器，不改变产品分层和播放所有权。

## 转写 WER

采用同一固定版本 FLEURS 的原始参考文本，与模型完成 EOF 排空后的最终转写比较。参考和假设均沿用历史 `whisper-normalizer==0.1.12` 的 `EnglishTextNormalizer`，汇总语料级 `WER=(S+D+I)/N_ref`，保留逐例错误数和各项分母。在线观察窗结束时的转写另存，避免把 EOF 后补词误认为在线已可用。

正常完成但转写为空时按参考词数计删除；运行失败的 WER 为 null，单列失败数与可评分覆盖率，不从计划 100 条总数中消失。标准化后的参考词数核对历史 2,162；若不一致，先查版本和文本字段，不直接与历史 WER 比较。WER 与 complete 输出率分别评分，控制未命中不导致转写样本被剔除。

## 转写末端延迟

保留最初要求的平均末端转写延迟，但为简化实现，与控制测试采用同一个文件输入结束时刻 `t_end`，不增加人工发声结束标注。截至观察窗结束、EOF 前最后一次词汇文本变化的实际接收时间减去 `t_end` 为在线末端文本延迟；该变化可以发生在输入结束前，因此保留负值。标点/空白变化不延后词汇指标。报告均值、P50/P95 和有效样本数，并关联 WER，避免把漏词造成的较早停止输出误称为完整转写更快。

空转写、运行失败时延迟为 null。若 EOF 后仍新增文字，单列 EOF 补齐及其耗时，不与 EOF 前在线延迟混合；WER 仍评价最终完整输出。这个指标以文件输入末端为参照，不能冒称真实语音末端的声学延迟。

## 计时与事件

“输入结束”按最后一个原始音频块发送完成的客户端 monotonic 时间 `t_end`，不是人工发声末端，也不是 WebSocket EOF。原始音频含有的尾部静音保留。音频按真实时钟、80 ms 一块发送，发送和接收独立运行，接收立即打时戳；另记录计划文件末端和发送迟到。

原始音频之后按同样节奏发送 5 秒静音，观察窗为 `[t_end, t_end+5s]`；直到观察窗结束才提交 EOF。每条录音独立会话、batch=1。配置固定目标 delay 480 ms。使用作者 vLLM MTP overlay 获取原始 `turn.delta`，其中 `turn_class=turn_end`、`turn_id=38` 对应论文 complete；不解析转写正文中的字符串，不计控制器合成的 accept/turn_end。单帧命中即可，不增加连续帧确认。

仅计客户端在上述观察窗内实际收到的原始状态帧，EOF 后产生的状态单列且不算成功。输入结束前已经输出 complete 的样本另计，不能移到结束后或当作 0 ms；若同一 complete 状态在结束后又输出一帧，按用户要求算结束后命中，不要求出现新的类别转换。

## 汇总

- 主比例：观察窗内出现至少一帧 complete 的输入数 / 全部计划正式输入数。部署/协议失败单列，另报成功完成回放条件下的比例，防止静默丢掉失败样本。
- 每条成功命中的延迟：`1000 * (t_first_complete_after_end - t_end)`，仅取首次；汇总条件均值、P50、P95、最大值及命中分母。
- 窗内未出现时延迟为 null，不填 0 或 5000 ms。另报仅输入结束前出现、全程未出现、仅 EOF 后出现以及运行失败的数量。
- 原始 trace 保存所有原生帧、概率、接收时刻及输入/观察/EOF 阶段，可以离线重算。比例与延迟一起给出，不因已完成样本的条件均值低就宣称模型整体更快。
