# Listen 定向训练入口与决策

2026-10-24。用户要求根据短延迟实测决定继续调阈值还是训练。[完整对照](../../../reports/xturnix_control/20261024-short-latency-comparison/README.md)已完成：500ms、提前动作≤5% 时，纯文本、纯时间、联合策略均未取得评估安全命中；连续阈值诊断也显示当前检查点的绝对分数不足以满足校准预算。

**决策是停止重复扫描这组阈值，转入小规模 Listen 训练准备。** 本页给出入口合同，不表示数据已冻结、资源探针已运行或权重已更新。原四类／VAD 扩展训练工作单继续保留其归档状态，不据本次决策自动恢复全部范围或新建工作单。

## 目标与范围

只检验 Listen 下 keep/start 的适配，起点保留冻结 XTurnix-PT、官方输入模板、既有 tokenizer 和 2,048 token 上限。模型负责动作，时间与停顿仍由同一个外部控制策略提供；不在当前末尾追加 pause 触发接话，不把尚未验证的时间字段塞入原提示词。

训练目标是拉开完整陈述让轮与未完陈述的分数，尤其纠正真实 ASR 中间前缀的高分；不能只整体提高 start 偏置。保持单一仲裁与 TTS 所有权，不扩展到 Speak、CoT、Layer 0/1/2 或真实播放，不替换现役控制器。

## 首先冻结监督数据

- 使用独立来源和新分组，覆盖一般叙述、信息回答、完整陈述后的继续持轮、列举、修正和明确等待。正负例共享上下文，采用可审核的完整／未完对照，不能把所有 keep 都做成随机截断。
- 训练与评价必须包含真实 ASR 增量；保留当时可见历史和输入版本，未来文字只参与离线核对，不进入模型输入。标注歧义与冲突，不能用后续是否续说替当前不可判定的样本强行消歧。
- 按原对话、场景、模板和派生版本分组，再切训练／开发／独立测试。现有 45 轮、旧已阅留出集及 FDB/FLEURS 继续保留为回归或外部评测，不参与训练或新选择。
- 旧 48 会话是辅助来源审核，尚不是可直接冻结的控制训练集。一般状态描述不能由大量电话号码／日期回答替代；各子类分别计数。

## 有界探针与试训

先检查动作 token 位置、因果移位、损失掩码、可训练参数与保存重载。优先少量 LoRA，冻结底座，仅监督当前动作 token，不监督历史助手正文。历史 [XTX-011 方案](../../issue/archive/XTurnix/xtx_011_lora_resource_probe.md)只能作为资源探针参考，不直接恢复其四类扩展输入。

先单卡测量实际长度下的显存、RSS、步耗时与重载一致性，再冻结一个试训配置和停止条件；不在没有可靠监督时先跑长作业，不自动扩模型、步数或配置。继续使用远端 conda 调度、单活动作业和已有资源／资产累计约束，训练不与同卡 ASR 回放并行。

## 训练是否值得继续

主比较仍是同输入、同精度、同 ASR、同时间观察下的校准前后模型，固定 500ms 主预算、300/800ms 敏感性和话轮级提前动作预算。训练后也需在开发集校准，独立测试不回选参数。报告全部失败、缺失、提前、预算内首次接话与时延，而不是只报告动作分类准确率。

ASR 首轮流式阻塞和文字无增量冒充静默的问题另行核查；若修复，必须重测未训练基线，避免把链路收益计作训练收益。新增声学观测和权重更新的贡献需分别验证。只有新数据上出现受控的正向证据才继续，失败则保留结论，不承诺训练必然满足延迟或召回目标。
