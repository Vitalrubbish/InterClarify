# 英文监督来源与首轮场景审核

更新：2026-10-23。对应 [XTX-009](../../issue/XTurnix/xtx_009_training_data_freeze.md) 的首轮来源审核。用户在阅读 XTX-007 分析建议后明确同意“启动审核”，本轮完成 48 个不同原始会话的文本前缀审查。该授权不包含环境安装、VAD 实现、校准、200 场景双人试标或训练。

## 1. 结论

**已经找到可追溯的英文多轮素材，但本轮未取得可直接冻结的四类在线控制监督。** 48 个会话中有 30 个条件性动作候选、18 个歧义项；Speak/stop 明确候选为 0。全部记录的真实系统状态、在线 ASR 和音频时间合同尚未成立，当前可直接进入正式训练的记录为 0。

这说明可以继续利用文本素材梳理接话、等待和附和的审核规范；还不能据此开始四类训练或阈值选择。最缺的是有音频、重叠时间和明确打断意图的 Speak 场景，不能通过把反对意见、问句或 wait 标签改名补齐。

| 本轮判断 | 会话数 | 含义 |
| --- | ---: | --- |
| Listen/start 条件候选 | 23 | 当前文字有较清晰的回应目标；Listen 状态和真实让轮仍是假设 |
| Listen/keep 条件候选 | 4 | 当前片段支持等待；仍需音频核实持轮和停顿 |
| Speak/keep 条件候选 | 3 | 语义类似附和；只有确认助手仍在播放后才成立 |
| Speak/stop 明确候选 | 0 | 未证实应停止正在播放的回答 |
| 歧义 | 18 | 可能续说、附和、设置用语或状态不足；保留而不强行标动作 |
| 可直接冻结的训练记录 | 0 | 上述候选均缺在线合同与独立标注，不能当金标 |

这里统计的是不同来源会话，不是 48 名独立说话人或 48 个独立统计试验；每个会话只取一个观察点。由 Codex 单次辅助审核，人工审核人数为 0，双人一致性为 null，不能称为双人试标完成。

## 2. 来源、样本选择与可访问性

### 2.1 DailyTalk：24 个会话

固定官方仓库版本 `05a0173dac8e68fb2b22190cfc5c22248538a1a6` 的 `preprocessed_data/DailyTalk/val_phone.txt`。按原会话 ID 的 SHA256 排序，取前 24 个会话，每个只取第三轮及之前的完整文字。来源中的 `val` 是 TTS 项目的划分名称，不代表本项目可以将已阅素材用于独立测试。

已读材料有英文正文、原始会话/轮次 ID 和说话人标记，包含提问、请求、完整回答、陈述和礼貌应声。本轮有 19 个 Listen/start 条件候选、5 个歧义项；没有创造截断前缀来凑 keep，也没有构造重叠来凑 stop。[所读文件](https://github.com/keonlee9420/DailyTalk/blob/05a0173dac8e68fb2b22190cfc5c22248538a1a6/preprocessed_data/DailyTalk/val_phone.txt)。

作者说明录制数据采用 CC BY-SA 4.0，而同版本仓库 `LICENSE` 为 MIT；两者分别描述数据和代码，不能把代码许可扩展到音频数据。原始音频通过作者给出的外部下载入口提供，本轮未下载或听审，也未验证可逐条取得的音频和真实录制时间。[作者说明](https://github.com/keonlee9420/DailyTalk/tree/05a0173dac8e68fb2b22190cfc5c22248538a1a6)。

这 24 个脚本对话共用 2 个来源说话人 ID，不能当作说话人独立数据；同源 DailyDialog 改写也不能跨集合充当独立测试。

### 2.2 SwDA：24 个自然对话

固定 `cgpotts/swda@3baa1fe49ebfa0fdb340eb6f69ee770836901cd9` 的 `swda.zip`，只读取中央目录、24 个会话 CSV 及会话元数据的压缩区间。按成员路径排序取前 24 个不同会话，轮换在前 60 条记录中查找附和、百分号、问句、反对/修正类标签；从第三条记录开始查找以保留历史。未命中时保留第三条记录作为回退，不以别的会话替换。

共有 8 个回退，其中 6 个反对/修正类目标没有命中，另有 2 个问句目标没有在指定位置范围内命中。这是该抽样规则下的结果，不能推断全量来源没有这些类型。来源标签仅用于定位不同材料，审核按当前内容重新判断，没有自动映射动作。[作者仓库](https://github.com/cgpotts/swda/tree/3baa1fe49ebfa0fdb340eb6f69ee770836901cd9)。

这 24 个会话共涉及 42 个原始说话人 ID，5 个 ID 跨会话重复，其中一个出现 3 次；所以按会话划分仍不等于按说话人隔离。元数据哈希、会话与说话人 ID 已记录到 manifest，后续须按说话人连接分组。

SwDA 文件有角色 A/B、话语顺序和话语行为标签，没有本项目真实的 Listen/Speak、用户音频截止点、实时 ASR 接收版本或助手播放前缀。部分正文带定性重叠标记，但不能直接计算时延；同说话人的连续子话语也不能直接充当官方要求的交替 user/assistant 消息。[作者的字段和标签说明](https://compprag.christopherpotts.net/swda.html)。

仓库有 GPL-2.0 许可文本，这不构成原始 Switchboard 音频的访问凭据。原始两路音频由 LDC 分发，项目是否已有对应授权/资产本轮未核实；本轮也没有取得这些音频。[LDC 来源说明](https://catalog.ldc.upenn.edu/LDC97S62)。ISIP 提供单独的词对齐发布，但其与所选 CSV 的逐例匹配尚未验证；探查的一个直接词文件 URL 返回 404，不能因此宣称整套对齐不存在。[ISIP 发布页](https://isip.piconepress.com/projects/switchboard/)。

## 3. 逐例审核发现

完整 48 条中文审核意见见 [reviews.csv](../../../reports/xturnix_training/20261023-source-audit/README.md)，每条均与 [manifest](../../../reports/xturnix_training/20261023-source-audit/README.md) 中的源文件摘要、观察记录序号和当前前缀摘要对应。原始文字只留在本地忽略目录，Git 不复制整批对话。

| 例子 | 从当前前缀看到什么 | 为什么不能直接贴控制标签 |
| --- | --- | --- |
| AUD-006 | 陈述句回答上一轮关于标牌的提问 | 说明“陈述句也可接话”；仍缺真实让轮时窗 |
| AUD-005 | 惊讶与赞叹 | 可能是轮后回应，也可能是播放中的附和，状态决定动作 |
| AUD-026、030 | 百分号标签落在短促应声上 | 不能将百分号一律理解为未完成表达并转为 keep |
| AUD-027 | 问句标签对应犹豫的地理位置问句片段 | 问句类别不保证观察点已完整或已让轮 |
| AUD-034、038 | 悬空的描述或条件短语 | 可作等待候选，不能凭文件片段尾部生成静音观测 |
| AUD-037 | 定性重叠标记附近有理解应声 | 支持附和候选，但没有精确重叠时间和助手播放状态 |
| AUD-039、040 | 对方话语后出现追问或复述确认 | 可能正常接话，也可能要求对方让轮；缺声学/状态时不能写成确定 stop |
| AUD-025、033、045 | 录音设置过程中的确认 | 附和标签存在，但任务语境可能不适合部署分布 |

SwDA 作者的标签表将 `%` 用于放弃/退出话轮及不可解释等情况，因此它本身不是语义未完的确定标签。本次判定保留这一多义性，而不是从来源标签继承动作。[标签表](https://compprag.christopherpotts.net/swda.html)。

目前没有计算模型分数、召回、误抢话或误停。当前候选比例来自带标签切片的审查材料，不是目标领域类别比例，更不是控制器质量指标。

## 4. 当前观察、隔离与审核限制

审核包只给出选定记录及之前的文字，没有追加后续话语；整份 CSV 在本地读取以提取指定前缀，未来记录没有进入审查包。不过原参考转写、标点、重叠符号和话语行为标签都是事后整理，**前缀截断不等于已还原在线可见输入**。标签与符号仅作来源审核证据，不作为未来模型输入合同。

manifest 的 `system_state` 和 `target_action` 全部为 null。reviews 中 `state_hypothesis` 仅说明“若该状态成立”的条件候选，不能反向填充运行状态。所有 `eligible_for_training=false`，`future_test_exclusion=true`；48 个已阅原始会话及其窗口、改写、ASR 派生视图均排除出后续独立测试。

DailyTalk 与 DailyDialog 还需按原脚本/模板族隔离；SwDA 还需按重复说话人连接分组。当前只记录候选分组，没有冻结 train/dev/test，也没有证明全量去重完成。FLEURS/FDB 未被用于本次审核、教师生成或阈值选择。

本轮没有第二名独立审核人，因此没有人工分歧率或仲裁结果。18 个歧义项是本次单次辅助审核的“不足以确定”，不能当作标注人之间的意见分歧。尚需后续双人按当前观察独立标注，允许未知；不能用同一模型重复审核冒充独立一致性。
