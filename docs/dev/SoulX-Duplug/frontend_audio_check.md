# SharedContext 当前值前端检查任务

2026-10-30，用户授权撤下 Nemotron＋SoulX，采用官方 SoulX＋SenseVoice，将每个 160ms 音频处理步骤的最新话轮全文与状态联合覆盖到 SharedContext。不新建 issue，不训练，不接入 Layer 1／2 或真实 TTS。

先在本地既有 conda 做少量契约检查，包括覆盖修订、文本／状态原子读取、无新增文本仍更新状态、controller reset 后正文和未处理音频连续、complete 分支整段识别先于本块发布、远场过滤、直接停止幂等、关闭与 EOF 排空分离。

远端使用独立冻结源码与已有 SoulX＋SenseVoice conda，只读复用权重、上游和加载器。一个活动作业、1×4090、4CPU、32GiB RAM、最长1200秒、设备显存22GiB停止线、启动空盘30GiB、结果128MiB、CPU线程≤4、单模型在途、音频积压800ms。触限失败，不丢音频或扩容。

复用先前冻结的六视图开发音频清单，总音频≤90秒；原幅度、整段RMS0.05／峰值0.9标定、截断、重复、静音和模型包英文示例分别报告。不把整段标定称为在线因果AGC，不使用 FDB 标签或额外数据。80ms真实时钟送包；合成尾部提前切换诊断阶段，不回写在线当前值。

回放在每个写入回调中分别调用两次当前值读取，比较整组正文与状态。原始来源、状态采集与逐次读取写入独立诊断文件；SharedContext 自身不保存这些历史。检查一次在线状态处理对应一次联合覆盖，重置和无新增文字不另建用户消息；关闭保留最后正文，pending真实采样与已处理截止核账。

输出来源摘要、冻结配置、当前值读取记录、ASR／状态计数、覆盖缺口、读取一致性、写入延迟、队列与内存峰值、退出码。写入成功不等于识别质量或话轮状态准确；无逐时金标不报告五状态准确率。新结果独立报告，旧六视图实测保留原解释。
