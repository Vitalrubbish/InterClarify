# Nemotron＋SoulX独立适配试验

2026-10-30 撤回说明：用户已指令停止 Nemotron＋SoulX 路线，转向官方 SoulX＋SenseVoice 的160ms当前值写入。以下为历史调研／实验记录，不再作为执行计划；专用适配器和入口已移除，源码由 Git 提交 `9fb5319` 追溯。现役独立 Nemotron ASR 服务不属于本次组合回退范围。


2026-10-30，用户明确授权尝试组合。保留SenseVoice首版和现役Agent，本轮仅增加独立英文适配探针，不训练、不恢复旧FDB评测、不自动切换线上来源、不新建issue。

Nemotron固定现有EN0.6B revision `ebe59e5a817142986528bbbee5dba8db7b38ed50`、FP32、lookahead1；SoulX及上游沿用首版冻结。两个既有conda分进程复用单张4090，不改共享环境。资源为1GPU、4CPU、32GiB、一个ParaThink活动作业、最长1800秒、设备显存22GiB停止线、结果128MiB、启动空盘30GiB；单进程模型调用串行，音频积压800ms，触限退出保留结果。

转写不受SoulX门控：Nemotron持续接收同一PCM，在独立轮询线程中将原始累计前缀和版本写入通用SharedContext；不调用SenseVoice。Context按来源锁定话轮，Nemotron拒绝已交付前缀改写。原生词内增量保留，不假设每次交付已经结束一个词，也不添加1秒等待。LLM稳定完整词视图本次不实现。

SoulX保留音频编码、ASR门控前向和原生五状态预测。门控允许时，从已发布源事件里选择音频观察上界不超过当前SoulX真实音频观察边界的最新前缀。NativeNemotron的音频读取可能预取，故将回调时已读取的最大真实采样作为保守上界，不把名义160ms步骤当精确对齐；无可用新前缀明确记pending／unchanged，不伪装为静音。状态同时保存Context最新版本与实际控制消费的源版本，明确二者可不同。

控制器将本generation已消费的文本整体按SoulX既有归一化和tokenizer编码。源字符仅追加也可能改变末词token：若新token列表并非旧列表前缀，定位受影响的旧文本位置，基于已保存的本generation音频嵌入、修订后文本和当时实际状态token重建KV。重放最多256音频块／4096文本token，不重新发布状态或重复触发打断，不回填过去在线预测。超限明确失败。此为适配设计，不宣称原生控制状态质量不变。

内部reset保留未处理PCM与ASR会话，开启新controller generation。为避免跨reset切断最后一个尚未完成的词，新控制缓存可从上次消费尾词起重新建立派生文本上下文；Context权威前缀不重复。官方完成分支读取当时已有的对应前缀，不再做整轮音频识别，不通过complete强行结束Nemotron。EOF排空结果仅作诊断，不能倒填在线Context。

首轮探针发现reset后若重注入同一未增长的源版本，可能重复解释旧尾词。因此仅在原始字符截止真正增加时消费；reset后允许从旧尾词起重建，前提是已有新字符。词内重分词重放时将修正旧词与新增加的词分开，能精确分词定位时新词仍在当前音频块之后输入；不能定位时明确记录回退，不用空delta掩盖确实新增的语义。

首轮使用已存在FLEURS开发录音的标定完整、前3.2秒、静音视图，以及SenseVoice模型包英文示例；总音频≤45秒。先预热，再80ms真实时钟送包。核对单来源、无前缀回写、词内拼接、因果观察上界、版本和状态引用、reset历史、实际消费者一致性及资源；报告原始ASR文字、状态计数、等待／消费滞后，不把小样本状态出现当语义准确率。后续是否采用取决于真实组合结果。

实施结果：`09a7d8b`四视图远端单卡复测完成，105次正文更新／124条状态／每消费者656事件一致，正文回调至可见P95约6.06ms，设备显存采样峰值7300MiB。完整来源均在线得到连续句子，截断视图存在仅排空后返回的尾部；complete时机与未消费尾部不能视为已验收。版本、两轮差异和原始产物见[实际报告](../../../reports/soulx/20261030-nemotron-integration/README.md)。
