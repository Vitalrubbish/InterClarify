# SenseVoice 与 X2 教师接入的受控调研

日期：2026-11-02。用户要求先归档当前活跃工作单，再建立调研工作单。NTF-015—020均为未实施归档，见[归档记录](../../reports/soulx/20261102-frontend-plan-archive/README.md)。当前工作为[NTF-021—025](../../issue/README.md)，本轮仅整理文档与建单，不实现或启动远端实验。

## 1. 要回答的问题

X2最终转写准确，不代表它在每个在线观察点提供的文字与SoulX原生教师协议相同。此前实验同时修改文字门控、窗口修订、提交节奏与reset，且主要比较对象是Nemotron r6，缺少同条件SenseVoice基线。已有[归因记录](../../reports/soulx/20261101-ntf012-x2-teacher-fdb30/regression_analysis.md)支持若干机制假设，尚不能确定各因素的因果贡献。

本轮依次回答：原生协议和公开训练时标要求是什么；同一音频的词在两种ASR中何时出现、修订和进入状态模型；尽量保持原生控制逻辑后替换教师有何影响；空步规则和文字提交时序各自造成多少变化。最后用固定样本复核，形成是否继续教师替换的有条件建议。原生SenseVoice只是实验基线，状态正确性仍按标注与人工核查评价。

重新克隆的官方源码仍固定为`a0b9063843df69619b087b95b74597b2176910b8`；重新下载本身不是修复。独立X2正文、SharedContext改造和complete交接同步保留为已归档候选方案，下游生成与直接停止边界保留，当前不实施这些接口。

## 2. 共同输入与实验顺序

小样本固定为原清单内6条：接话`candor_turn_taking-102`、`candor_turn_taking-3`，停顿`candor_pause_handling-127`，打断`synthetic_user_interruption-136`、`synthetic_user_interruption-20`、`synthetic_user_interruption-9`。它们用于定位历史现象，不能代表总体分布；正式复核继续使用全部原FDB30，不因结果替换样本。

## 3. 必须区分的时间与轨迹

| 记录 | 含义 |
| --- | --- |
| 声学词尾 | 人工核查或带置信度的离线对齐参考，只用于评分，不反馈给在线模型 |
| ASR首次出现 | 完整词首次出现在当时可用输出中的时刻；SenseVoice后续可能修订，需保留撤回与重现 |
| ASR提交或修订 | X2以真实EOS闭合为组提交；SenseVoice记录各窗假设与修订，不伪造在线稳定信号 |
| 教师实际消费 | 门控后采用的文字、token、所在音频块及KV修订位置；ASR已有文字不等于模型已读取 |
| 计算与返回 | 实际输入观察上界、排队、推理开始／结束和返回时刻，区分音频坐标与墙钟延迟 |
| 状态与reset | 原始五状态、规则改写、最终反馈、服务状态、reset原因与代次 |

SoulX保持原生160ms主块及实际回看／前瞻；X2保持原生80ms LISTEN／DECODE协议。观察边界按真实采样编号记录，不用相同步号冒充同一观察范围，不用默认delay参数直接扣减实测延迟。X2发射组EOS不等于SoulX的user_complete，也不证明组内每个词有独立可用时刻。

词匹配需处理重复词、识别差异和修订，报告匹配覆盖、遗漏及歧义。事后“最后一次修订”可作描述性统计，不能作为当时已知的在线稳定时刻。没有可靠声学对齐时只报告相对提交时差，不据此声称词相对音频错配了一块。

## 4. 教师替换与归因原则

从干净官方源码出发，优先保留文字门控策略、归一化、差分与KV修订、状态规则、反馈和原生reset。X2流式输出如何映射到原生ASR查询窗口、reset和完成分支，须在NTF-023实施前写清合同；无法等价的职责明确列为实验差异，不能把“只换ASR”作为未经验证的前提。原生策略相同不要求两臂得到相同门控判断或状态轨迹。

空步规则在SenseVoice和X2内分别做开／关完整重放，另一条nonidle→idle规则保持，比较规则效应是否随ASR变化。时序消融使用同一份因果可用的X2闭合组序列，仅额外延后160ms，与0ms比较；不提前提供未来词，不用最终全文替换中间假设。EOF造成的未注入尾部单列，不把缺字误作纯时序效应。改动reset、修订或门控若仍有必要，另列独立实验臂，不与前两项同时变化。

状态按音频主块、完整观察和实际返回三个坐标报告。原始预测与规则改写、检出覆盖与提前complete、参考标注与边界敏感计数分别呈现。延后发布同一个complete不能算模型判断改善；删除已发生的规则帧不能替代带反馈的重新推理。

## 5. 执行与资源边界

本轮授权仅为归档与建单。后续实现必须先满足前置工作单，代码、注释和文件名使用英文，配套中文说明放在docs同路径，说明文件功能、类设计和核心方法。真实模型只在远端conda调度作业运行，复用已有环境和权重，不依赖已删除的comparison加载器。

沿用单活动作业、1×4090、4CPU、32GiB RAM、batch=1、显存22GiB停止线；各模型worker至多1、CPU线程各≤2，不建无界任务池。每作业≤1800秒、输出≤128MiB，启动空闲磁盘≥10GiB；每路未读PCM≤800ms、总PCM≤4MiB，在线送音迟到与发布延迟按既有800ms停止线留证退出。离线因果重放单独标记，不把加速重放吞吐当作在线延迟。

预热覆盖真实语音、多长度窗口、文本修订、状态与完成分支，以及X2首块／增量、WAIT／DECODE／EOS；正式时钟在就绪后启动，重置随机种子和会话状态，保留预热日志及未覆盖分支。每阶段先冻结有限实验臂、作业数、总GPU时长和结果预算，再实施；旧NTF-018／019的作业额度随归档失效，不自动转作新实验预算。失败不通过放慢送音、丢帧或选择性重跑处理。

固定FDB30报告完整率、退出码、三轴状态、在线WER及覆盖、词级时间分布、尾部缺失和资源。接话无参考文本的10条不计WER；单次30条只给描述性结论。调研可得出继续教师替换、需要进一步协议适配或训练、保留独立正文方案，或证据不足，不能预设X2一定改善或一定不兼容。
