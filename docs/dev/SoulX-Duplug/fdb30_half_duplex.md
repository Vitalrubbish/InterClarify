## 范围与行为

固定输入 manifest SHA256 为 `403be34448e0b011fa0b6a26216c0390ea3ed46ce77335e4bbe7a20cde4f3c07`。沿用原生 SoulX、并行 X2、160ms 联合发布、完整预热、随机种子 42 和原有输入增益，不读标注触发动作。普通 LLM 在已发布的有效 complete 且有新正文时启动；空正文不启动，服务等待兜底不额外启动。有效 nonidle 取消生成及播放。其他状态继续观察。LLM 不是双工 token 模型，不训练。

正式 r1 在接话39因控制积压触及4MiB临时PCM分配保护，前三条与失败现场保留。为完成完整输出链路的固定分母评测，新批次显式使用16MiB PCM上限，保留逐次分配前检查、总作业主存和磁盘限制；不是取消保护或降低供音速度。原前端默认仍为4MiB，历史轨迹不回填。修正后所有30条重新运行，不拼接不同配置的分数。
