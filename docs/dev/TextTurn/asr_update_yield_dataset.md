# TT-010 数据版本合同

2026-10-25，按用户启动指令实施。旧TT-001和测试证据保持原版本；本项只交付CPU合成文本轨迹，不运行模型。

完成输入采用普通JSON事件`kind: finish`，不注册专用token、不扩展embedding。专用token可缩短编码，但会引入词表和候选兼容成本；现有结构化状态足以明确完成原因。动作仍使用既有三个token，所有输入及正文位置均为-100，仅当前合法动作参与损失；unknown全部屏蔽。

从旧冻结清单按固定哈希顺序取24个train、12个dev来源，保持原切分及近重复组；不使用test来源、FDB或重测内容。规模小于原上限，不复制快照补数。同一来源上的多种事件是对照机会，统计同时给出来源数、机会数和窗口数，不宣称为独立对话。新增用户补充、纠正、提问、改请求及停止要求为显式标记的合成标注；不宣称真实Nemotron噪声或语音覆盖。

每窗480ms，用户按固定种子随机1—2个token切片，助手8个token。对每个当前可见前缀单独保存语义标注：词内片段及有歧义前缀unknown；短附和可判定时keep；补充、纠正或请求可判定时stop。标注规则仅供离线构造，模型输入不带类别、标注理由、未来文本或完成时间。Listen中途前缀保守保留unknown，完整来源请求后的合成空窗才标start，不用未来文字倒推中间窗口。

唯一模拟执行点接受start后分配output_id，同刻记录模拟开播。生成和播放游标分离，播放滞后一窗；生成完成后额外保留960ms尾窗。stop请求与80ms后的模拟停播确认分别落盘，确认后才进入Listen；终态记stop一次。finish仅在生成结束、游标已播放到末尾、尾窗耗尽后产生。事件含单调event_seq、发生／发布时间，完成输入在下一控制窗记录消费时间，最近终态持续可见。延迟是构造值，不是性能成绩。

重复版本、文本不变、旧版本和旧轮更新不算新输入；不支持ASR回写，非追加修订直接拒绝。单一执行点按输入事件顺序处理同刻事件，finish先到则随后用户文本在Listen；用户先到则可stop，迟到播放回调记stale，不产生第二终态。open／truncated及异常取消单列，不伪造完成。中断保留已生成和已播放事实，用户已听部分不撤销。

覆盖普通无停止词更新、显式停止、词内unknown、附和转接管、生成结束后的打断、首次正文前打断、正常finish后下一轮、多次输出、重复输入、迟到回调和截断。无更新及附和对照使用相同来源历史。完整逐事件轨迹保留；正式快照每个机会最多保留两个keep和两个unknown，加全部start/stop，不依靠冗长keep填预算。超过2048 token的窗口保留在审核记录中，正式集排除。

构造使用已有本地conda环境，单进程、线程1、地址空间2GiB、超时600秒、新增数据≤512MiB；无集群测试或新预算。交付清单记录输入／输出摘要、来源切分、标注前缀、完整轨迹、损失屏蔽及闭环核查。实际模型stop率、附和误stop率和真实停播时延须后续授权训练与独立验证；本次只统计监督合同。
