# TT-010 数据版本合同

2026-10-25，按用户启动指令实施。旧TT-001和测试证据保持原版本；本项只交付CPU合成文本轨迹，不运行模型。

按用户本次明确修订，v2将歧义前缀监督为keep，保持当前Listen／Speak；不新增unknown动作或token。完成输入注册拼写为`<finish>`的专用special token，追加唯一ID且保持四个既有ID不变。它随`kind: finish`事件仅在首次消费时出现，仍为外部输入，不进入动作候选；所有输入位置屏蔽损失，最后一个keep/start/stop动作ID参与监督。v1的unknown屏蔽及普通JSON完成事件保留为旧版本，不覆盖。

从旧冻结清单按固定哈希顺序取24个train、12个dev来源，保持原切分及近重复组；不使用test来源、FDB或重测内容。规模小于原上限，不复制快照补数。同一来源上的多种事件是对照机会，统计同时给出来源数、机会数和窗口数，不宣称为独立对话。新增用户补充、纠正、提问、改请求及停止要求为显式标记的合成标注；不宣称真实Nemotron噪声或语音覆盖。

每窗480ms，用户按固定种子随机1—2个token切片，助手8个token。对每个当前可见前缀单独保存语义标注：词内片段及有歧义前缀keep；短附和可判定时keep；补充、纠正或请求可判定时stop。审核元数据可记录语义尚不确定及fallback_keep，不能进入模型输入。Listen中的未决前缀及stop后的继续输入也监督keep，完整来源请求后的合成空窗才标start，不用未来文字倒推中间窗口。手写语义边界及stop时机不因本次修订后移。

唯一模拟执行点接受start后分配output_id，同刻记录模拟开播。生成和播放游标分离，播放滞后一窗；生成完成后额外保留960ms尾窗。stop请求与80ms后的模拟停播确认分别落盘，确认后才进入Listen；终态记stop一次。finish仅在生成结束、游标已播放到末尾、尾窗耗尽后产生。事件含单调event_seq、发生／发布时间，完成输入在下一控制窗记录消费时间，最近终态持续可见。延迟是构造值，不是性能成绩。

重复版本、文本不变、旧版本和旧轮更新不算新输入；不支持ASR回写，非追加修订直接拒绝。单一执行点按输入事件顺序处理同刻事件，finish先到则随后用户文本在Listen；用户先到则可stop，迟到播放回调记stale，不产生第二终态。open／truncated及异常取消单列，不伪造完成。中断保留已生成和已播放事实，用户已听部分不撤销。

覆盖普通无停止词更新、显式停止、词内歧义keep、附和转接管、生成结束后的打断、首次正文前打断、正常finish后下一轮、多次输出、重复输入、迟到回调和截断。无更新及附和对照使用相同来源历史。完整逐事件轨迹保留；正式快照每个机会最多保留两个普通keep和两个原未决前缀keep，加全部start/stop，维持原采样覆盖。超过2048 token的窗口保留在审核记录中，正式集排除。

tokenizer.json及tokenizer_config.json共同保存全部新增ID，离线重载须将`<finish>`编码为同一个单元素ID列表。当前仅注册并验证tokenizer，不修改旧候选权重；后续获授权训练时必须按新词表检查embedding容量、初始化并学习新增输入行，保存并重载核对。finish输入被屏蔽损失并不阻止其embedding经动作预测获得梯度，但不将finish作为动作目标。本次不启动模型训练。

构造使用已有本地conda环境，单进程、线程1、地址空间2GiB、超时600秒、新增数据≤512MiB；无集群测试或新预算。交付清单记录输入／输出摘要、来源切分、标注前缀、完整轨迹、损失屏蔽及闭环核查。实际模型stop率、附和误stop率和真实停播时延须后续授权训练与独立验证；本次只统计监督合同。
