# TextTurn训练修复方案与执行入口

更新：2026-10-29。本文将重复的早期建议收敛为问题、修复和证据入口。原方案由2026-10-26四臂诊断产生，后续配置已确认并实现；完整参数统一见[修复合同](dataset_repair_recommendation.md)，逐项选择见[讨论历史](dataset_repair_configuration.md)。沿用TT-010，不新增工作单或启动作业。

## 问题与修复

[四臂诊断](../../../reports/textturn/20261026-training-diagnostics/README.md)均未得到可放行模型；正例分组单独裁剪与仅keep更新结构需要修正。[管线审计](dataset_pipeline_review.md)另发现预设分支进入模型输入、模板不可达、打断后无重新接话和句式／历史位置混杂。这些是已观察事实，不证明每个问题单独造成了多少错误。

| 方面 | 已确认修复 |
| --- | --- |
| 在线输入 | 采用因果输入映射，移除来源、预设分支、输出ID及原始时间戳字面量；训练与回放共用 |
| 动作闭环 | 补打断后完整新请求的再次接话、附和转接管及正常finish；单纯附和和明确停止不生成新回复 |
| 普通start | 当前句末标点作弱完成代理，首个合格空观察接话，不强插句末空拍；接受句末仍可能续说的噪声 |
| 发布与播放 | 160ms观察、连续发字段和变长空串，生成／播放独立时钟，准备阶段也可取消 |
| 优化 | 同来源同句式完整轨迹组成逻辑组；三类加权平均CE各占1/3，全部反传后统一clip1及一次AdamW |
| 规模 | train／pilot窗口上限100000／10000替代旧10000／2000；完整来源组选取，不删拍或伪造finish |

保留固定Qwen3-0.6B、LoRA rank16／alpha32、完整词表CE与学习率1e-4等设置，按真实逻辑更新数重算日程；其他训练参数和资源以完整修复合同及冻结配置为准。CoT、ASR和表达模型不参与本次训练。
