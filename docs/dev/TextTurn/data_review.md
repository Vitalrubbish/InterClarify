## 需要优先修改的构造

1. **时序捷径明显。** 只按Listen/Speak、no-voice、少量问句开头和固定停止词判断的无模型规则，在pilot符合1994/2000标签（99.7%），full符合9946/10000（99.46%），全部start和stop均命中。该诊断只衡量现有标签可被简单规则解释的程度，不证明训练模型一定使用了这条捷径。
2. **停顿覆盖过窄。** 显式停顿全部位于问句开头。full里Listen、非空当前文字、no-voice、keep共373窗，其中319窗仅是这类开头，另54窗多由单独句读归一化为空观察产生；没有系统覆盖句中词后停顿、ASR词内分片、完整子句后的歧义停顿。
3. **标签依据有待补审。** 130/160个陈述来源包含多句，当前构造给所有到达过程统一keep，到整轮结束才start。部分空观察时当前句已完整，标注理由仍写“新增输入仍在到达”。不能仅因源文本后面还有一句就给keep，也不能仅因当前句完整就给start；应依据当前语义、持轮信号和可观察让轮条件分别标keep/start/unknown。
4. **词汇和事件顺序单一。** 附和只有5种、打断4种，160条轨迹的阶段顺序全部相同。缺少相同短回应在不同上下文中的意义对照；“Please”等前缀要保持未知或keep，明确停止依据才stop。
5. **播放尾窗缺少打断对照。** 正常播放尾窗有160个机会，但正式训练plan没有把打断放在尾窗之后、播放完成之前。需要补齐“同样生成已完成，用户附和keep／明确打断stop／自然播放完成无stop”的对照，保持单一播放所有权。

## 配比调整建议

需要调整，但应先补标签和场景，再改采样。增加现有keep或把三种动作机械配成1:1:1均无充分依据；后者还会抬高主动动作先验。

下一批可采用以下**待开发集验证的窗口预算起点**，合计仍不超过10000窗：普通接话30%、停顿20%、附和20%、打断20%、正常生命周期10%。先按来源和独立机会分层，再限制每个机会的重复keep数量；每个来源保留有因果历史的完整轨迹，训练只采必要决策窗。目标是降低无信息keep重复、增加有语义对照的边界窗口，不强行固定动作先验。

这些是候选预算，不是已证实最优比例，也不能由现有160来源通过复制窗口填满。若合格独立机会不足，应如实记录缺口，留空或缩小批次，不能强行填标签。新增来源仍遵守1000对话和10000快照上限，并按源／近重复组隔离。

时序保持480ms控制窗、User名义1—2 token与Assistant 8 token约定；先补齐该约定内的因果停顿与语义边界。真实Nemotron的空窗／突发分布应从训练来源或开发来源采集，若据此改变User分布，先明确更新方案，不悄悄替换用户确认的设置。不增加VAD、固定等待或ASR延迟补偿。

本次测试已用于问题分析，今后可作回归材料；不能用其正文训练、反复用其成绩挑配比。后续候选只由训练及开发集决定，最终泛化仍需未被用于调整的新来源。新数据构造实施前需先补齐因果标签规则，现有评分器的unknown不能靠重新训练消除。
