# ASR 主线选择与接话模型适配

日期：2026-10-16。依据 [实测报告](../reports/asr_selection/20261016-results/summary.md)，结合用户提出的无标点接话训练方向，选择 **Nemotron Speech Streaming EN 0.6B、160ms 分块作为后续英文 MVP 的主线 ASR**。Kyutai 1B 保留为固定官方 DuplexCascade 权重的接话对照。该决策确定后续开发目标，不宣称当前组合已通过产品验收，也不改写原始实验报告。

## 1. 选择依据与限制

- Nemotron EN 160ms 的本轮 WER 为 7.68%，估计逐词交付中位数 414ms；Kyutai 为 21.97% 和 713ms。
- 英语版 560ms 的 WER 为 7.59%，仅改善 0.09 个百分点，中位数增加约 169ms，因此优先 160ms。
- 原始可见文本均未发现回写。当前主线限英文，未据此决定中文选型。
- 官方权重下五例接话，EN 160ms 仅 1/5，Kyutai 为 5/5。这说明 EN 尚不能直接作为已验收的替换；它需要 Layer 1 兼容性验证。
- 原始长尾和一次预热失败仍未归因，短配对诊断未证明日志是原因。典型延迟优势不能替代稳定性门槛；日期、时间等实体正确率也需独立验证。

更准确的转写前缀是后续语义分析的基础，因此主线采用 EN，接话适配在 Layer 1 上验证；不单为保持当前控制权重的输入习惯而固定较高 WER 的 ASR。

## 2. 无标点训练的可检验假设

用户建议通过去标点训练，让模型更多依据语义决定接话。本轮 Kyutai 在相同五例中由原样 5/5 降为去标点 2/5，支持开展鲁棒性实验，但不能证明标点是不同 ASR 之间差异的唯一原因。识别错误、增量分组、到达时刻和模型生成历史同样需要控制。

目标是**降低对句读形式的依赖，提升真实 ASR 前缀下的接话能力**，不是保证只靠文字语义就能唯一判断话轮结束。同一前缀可能对应句中停顿或已经说完；保留已有 micro-turn 时序和 no-voice 空窗，不能训练成“出现一个空窗就回答”。不增加新的 VAD、结束规则或仲裁器。

## 3. 最小训练对照

训练对象为现有 Layer 1 控制模型。先从官方 checkpoint 继续训练现有 q/v LoRA，冻结基础模型、已有 embedding/lm_head、ASR 和 TTS；五类控制 token、ChatML、assistant token ID 历史及播放所有权保持一致。是否能在单卡 24GB 内运行须由远端短跑验证，不提前承诺吞吐或收敛。

保留未经训练的官方权重，并以相同数据、步数和初始化比较三种小规模继续训练：

| 条件 | 用户输入处理 | 用途 |
| --- | --- | --- |
| 原样继续训练 | 保留真实 ASR 输出 | 控制新数据和继续训练本身的影响 |
| 去句读标点 | 删除用户侧明确句读符号 | 检查无标点输入的接话能力 |
| 混合增强 | 原样与去标点版本混合 | 检查对两种文本形式的鲁棒性 |

增强只作用于用户侧普通句读，不删除控制 token、消息边界或 assistant 的标点。不破坏撇号、连字符、数字小数点和时间格式；预处理只根据当时可见的内容，不借未来词判断符号性质。不确定的数字符号保留原样，也不修改线上已经释放的前缀。

## 4. 数据与评价

先盘点可获得、有使用许可的对话音频和边界标注，再冻结数据划分。主训练数据应记录 Nemotron EN 160ms 的真实增量及到达时间，按现有窗口构造 micro-turn；不能把完整人工转写切块冒充在线 ASR。原样／去标点／混合条件共用同一基础轨迹，分别生成和监督其控制历史。

控制监督来自对话／边界标注和可见前缀审查，不把现有模型的持续等待直接当成正确标签；完整录音只能帮助离线标注，不能进入输入。训练时保留目标 assistant token IDs 的协议结构，评测时各条件生成自己的历史，防止强塞另一条件的模型输出。

覆盖说完需回复、句中停顿、继续补充、自我修正、用户附和和有效插话，避免只训练“尽快回答”的正例。按说话人及原始对话划分；同一录音的增强版本只进入一个集合。已有 FLEURS 100 条和 FDB 五例保留为诊断／回归，不进入训练；最终判断使用未参与方案选择的新测试集。

主要观察：新回复覆盖率、正文启动延迟、过早接话、停顿误抢话、用户附和误打断、有效插话停旧回答及回答内容退化。未回复保留分母，提前正文和旧正文续写单列。文本控制验证通过后，再使用相同 ASR/TTS 做完整 FDB 与真实音频回归，不将文本启动等同有声响应。

## 5. 当前状态与实施边界

本轮完成主线决策和实验设计，尚未启动训练、改变部署配置或切换现役 ASR。下一阶段先做训练数据盘点和资源短跑，再执行上述小规模对照；达到回归要求后才冻结新的 ASR + Layer 1 组合。Kyutai 保留作对照，不删除既有模型和失败证据。

这是建立参考底座的兼容性实验，不新增论文贡献、任务域或 Layer 2 功能，不启动大规模训练。已有唯一协议执行者、跨层边界和唯一 TTS 播放所有者保持不变。
