2026-10-31 当前选型：用户已授权按[工程同步方案](dev/SoulX-Duplug/nemotron_teacher_forcing.md)将 **Nemotron ASR 作为 SoulX-Duplug 的 Teacher Forcing ASR**。前端位于 Layer 0–Layer 2 输入侧；Nemotron 提供唯一转写，SoulX 保留音频路径并在每步教师文字注入后预测五状态，两者以逐步屏障推进。初版替换消除了旧独立组合的门控消费滞后和 SenseVoice 滑窗差分问题；2026-10-31 按NTF-004恢复官方控制格式与文字门控，正文仍逐步发布，单独审计门控引入的消费滞后；质量由 FDB 三轴固定小样本验证，不预先宣称改善。模型权重固定，不训练，尚未切换现役下游 Agent。SenseVoice 保留为历史基线。

NTF-004官方格式与门控对照已交付：预检3/3通过，正式25/30完整、5条积压触限，状态指标未整体改善；共享正文与控制文字消费分别审计，未切换下游Agent，见[对照报告](../reports/soulx/20261031-nemotron-teacher-gate/README.md)。

前端包含 ASR 调用、文本整理、SoulX 音频编码和用户状态预测，每处理一个 160ms 音频块，将最新话轮全文和本块五类状态之一原子写入共享 Context；修订直接覆盖旧正文，不保留历史正文版本，也不等待 `user_complete`。2026-10-30 按用户决定以此替代版本化转写和 320ms 正文周期建议，原因是简化存储与读取；当前值接口继续用于新的 Nemotron 教师文字前端，进展见[接口合同](dev/SoulX-Duplug/shared_context_interface.md)。Layer 0 系统附和时机、Layer 1 表达和 Layer 2 思考位于 Context 下游。该职责分层允许前端持续接收音频、表达与思考并发执行；后续 CoT 从 Context 反馈至前端，当前不实现条件化扩展。

用户进一步确认：保留 CoT 条件下的主动澄清与话轮决策目标，后续让 SoulX-Duplug 联合读取音频 token、转写文本 token 和 Layer 2 已发布的 CoT token；当前不实现这项扩展。当前保留原生五类用户状态 token，全部送入 Layer 1，由 LLM 决定自身行为；普通正式回答在当前 turn 看到对应的 `user_complete` 后开始生成，看到之前不生成正文。后续 CoT 阶段是否扩展控制器输出另行设计，见[架构第 2.5 节](research_design/architecture.md#25-soulx-的-cot-条件化控制)。

研究任务与单一仲裁执行点、单一 TTS 播放所有权及已听内容不可撤销的边界保持。仅有效用户打断额外进入输出运行时：活动输出期间 `user_nonidle` 立即触发停止，涵盖准备与播放。其他状态不进入输出运行时，不映射成 start 或 keep；`user_complete` 不额外发起 LLM 回答调用，`user_backchannel` 由 LLM 读取并决定表达行为。具体路径见[架构第 2.2 节](research_design/architecture.md#22-前端状态与系统附和)。状态输入编码与 Layer 3 定位待后续讨论。TextTurn 专属协议不自动成为 SoulX 合同，旧作业不因本次选型恢复。

旧 TextTurn／VoxTurn／XTurnix 的数据、训练与测试修订已全部归档，入口见[历史路线归档](archive/dev/README.md)和对应报告；历史工作单在本地 `docs/issue/archive/`。保留历史合同，不继承为 SoulX 协议。

## 1. 研究背景

传统的“听完—思考—回答”流程把推理集中在话轮交接后的等待期。流式输入和流式语音输出提供了在倾听、表达期间继续计算的机会，但并行执行本身不能证明交互更好。我们研究：独立于表达的 thinking 流，能否将这些计算转化为更及时、可靠且有任务价值的语言行为？

研究主线从原先的主动澄清扩展为 thinking 流的收益。主动澄清保留为“边听边想”的核心任务，回答递进与自我修正作为“边说边想”的任务。原有介入合理性分析与共享前缀案例保留在倾听文档中；本次拆分不另行扩大应用范围。

thinking 流是与表达分工的内部任务分析过程。“独立”表示职责与调度分开，不要求不同模型权重。Layer 2 将 CoT（内部思维链）发布到共享上下文，供后续完成条件化训练的话轮控制器决策和 Layer 1 表达使用，不向用户公开或播放。边听边想处理持续到达的信息，边说边想在已经开始表达后继续完成任务分析。

## 2. 研究目的与工作内容

核心假设是：在相同信息条件和可比较的计算预算下，thinking 流能够改善在线行为的质量与时间之间的权衡。两个研究问题分别验证，允许优势只在部分任务或预算范围内成立。

| 研究问题 | 待检验优势 | 同时观察的代价 |
| --- | --- | --- |
| 边听边想 | 比延后启动思考更及时地覆盖必要澄清机会，并提出有依据的问题 | 误介入、遗漏、过期判断和计算开销 |
| 边说边想 | 比直接回答更充分地解决任务，比想完再说更早交付可靠有效内容 | 早期错误、前后冲突、修正延迟、冗余和计算开销 |

工作包含三个相互配合的部分：

1. **Agent 框架**：设计 thinking 流与表达流异步协作的语音 Agent，支持倾听期间更新判断、表达期间继续分析，以及思考结果的增量利用。
2. **两组 benchmark**：分别评价边听边想的主动介入，以及边说边想的回答递进与自我修正，通过基线、预算比较和消融验证收益。
3. **大规模对话数据与训练**：构造覆盖两种能力及其衔接的因果对话轨迹，训练思考调用、结果利用与在线表达，比较训练前后、单项与联合训练及数据规模的效果。

框架可运行、回答开头更快、答案更长或改口更多，都不足以单独支持研究结论。大规模数据训练是研究主体，不能仅用 prompt 演示替代。具体训练规模、模型和参数仍待试标及试验确定。

## 3. 研究范围与结论边界

倾听任务由模型自主发现影响任务的信息缺口、确定澄清目标，并权衡现在询问与继续等待。附和不等于主动澄清，用户让出话轮后的询问属于轮后介入。首版采用在线回放评价，不要求真人回答或用户模拟器，因此不直接宣称节省用户时间、改善真实任务结果或用户接受度。

表达任务由模型自主组织回答，先表达可靠且有用的部分，随进一步分析补充条件、推导或方案，必要时纠正自身表达。主测试在开口前提供完整用户任务，避免把开口后新增信息的收益混作持续推理收益。答案正确性和完整性可以评分，但不等同于真实用户完成任务的收益。

系统主动纠正用户、提醒遗漏、调整用户任务顺序，以及紧急提醒、闲聊插话和情绪支持留作后续扩展。系统自我修正属于表达任务，不能据此扩展为主动纠正用户。

两项任务采用同一 Agent。Layer 2 只发布 CoT，不提供话轮状态转移建议或候选表达文本，Layer 1 负责思考请求与语言表达。目标控制器 SoulX-Duplug 后续结合音频、转写和 CoT 共同判断等待与介入，保留主动澄清能力的研究目标；当前不实现 CoT 注入或相应训练，普通状态预测不等于已经具备该能力。CoT 的序列组织、边界编码、缓存与训练方式待后续设计。Layer 3 定位待统一，本轮不新增实现。所有输出经单一仲裁器与单一 TTS 播放路径，已听内容不可撤销。具体合同统一写在架构文档，TextTurn 的动作与训练规则保留在历史记录和原工作单。

## 5. 参考文章

- [A Full-duplex Speech Dialogue Scheme Based On Large Language Models](https://arxiv.org/html/2405.19487v1)：涉及机器主动打断及其时机、合理性的评估，是后续比较定义与指标的直接相关工作。
- [Eliciting Spoken Interruptions to Inform Proactive Speech Agent Design](https://arxiv.org/abs/2106.02077)：讨论主动语音介入设计与时机权衡，可帮助梳理用户侧成本。
- [AdaptDuplex: From Static to Adaptive Full-Duplex Spoken Dialogue](https://arxiv.org/html/2609.29217v3#S2.SS2)：第 2.2 节与附录 C.4 描述异步外部请求和工具结果回写；附录 D.1、D.4 提供数据生成与监督范围参考。该文的层级命名与本项目不同，不能直接对应层号。
- [STITCH: Simultaneous Thinking and Talking with Chunked Reasoning for Spoken Language Models](https://arxiv.org/abs/2507.15375)：通过未发声推理与语音分块交替，在播放期间继续计算，是边说边想机制与质量、时延比较的直接相关工作。
- [Never Stop Thinking: Continuous-Time Language Agents](https://arxiv.org/abs/2609.17416)：讨论倾听与表达期间的连续思考及 ReactiveBench，并报告 judge 对可见推理的偏好风险；本项目需尽量采用可核验目标，独立审核开放式内容。

以上是当前参考线索，不构成完整综述或新颖性证明。
