# NTF-010：词级规范分词的教师文本追加与 FDB30 复测

日期：2026-11-01。状态：已收口。词级规范分词保留；尾词的“一次空步即提交”判据被 `r6` 证伪，已由 [NTF-011报告](../reports/soulx/20261101-ntf011-x2-probe/README.md)／[NTF-012报告](../reports/soulx/20261101-ntf012-x2-teacher-fdb30/README.md) 的 X2 组闭合机制取代。

## 背景与证据

NTF-009 的 FDB30 已完成 30/30、退出0，主块发布 P95 219.2ms、无800ms；但状态指标混合，未达到“对齐后应改善”的预期。复核发现顺序对齐并不等于 token 分布对齐：

| 路径 | 样本 | 实际注入 token | 规范分词 | 一致 |
| --- | --- | ---: | ---: | --- |
| NTF-004 门控教师 | 停顿ID127 | 31 | 31 | 是 |
| NTF-007/009 纯追加 | 接话ID102 | 41 | 21 | 否，首token即不同 |
| 词级试探 | 停顿ID127 | 31 | 31 | 是 |

NTF-007 把流式ASR每步新增的字符片段分别 tokenize，打断子词合并，注入约两倍的非规范 token。冻结0.6B训练时使用规范分词，因此状态头看到分布外输入。词级缓冲可在不重放历史的前提下恢复规范分词，代价是最后一个词延后到词边界或一次停顿。

## 范围

1. `TeacherTextBuffer` 改为词级：
   - 已完成词组成稳定文本；每步对稳定文本做一次规范分词，追加相对已注入token的新后缀。
   - 最后一个未完成词只重编码用于审计，不进入KV。
   - 词后出现空格时立即提交；连续一个空ASR增量后提交，避免最后一个词永远不注入。
   - 已注入token不可改写；若稳定文本的规范分词不再以已注入token为前缀，立即失败并保留证据。
2. 保留纯追加：不恢复 `_revise()`、KV检查点或全量输入账本。
3. 审计字段保留并明确语义：`text_commit_index`、`tail_reencode_count`、`tail_replace_tokens`、`text_injected_tokens`、`pending_text`、`pending_token_ids`。
4. 本地新增用例：词级规范分词与全前缀一致、历史token不变、跨步词片段只改尾部、停顿提交、越界报错、无重放属性。
5. 远端固定FDB30复测：同一清单、同卡、同一预热合同；报告完整性、延迟、token规范性和三轴状态指标。

## 验收标准

1. 所有帧的累计注入token等于当前已完成文本的规范分词；跨步词片段不再产生非规范子词。
2. 历史token逐字节不变；无 `_revise`、检查点或重放调用。
3. 本地全部测试通过。
4. 固定30条完整率、退出码、主块/完整观察发布延迟、800ms触发情况如实报告。
5. 三轴状态指标与 NTF-004/009 同口径并列；单次运行不做显著性结论。
6. `docs` 同路径说明更新。

## 资源与执行边界

单并发、1×4090、4CPU、32GiB、显存22GiB停止线、每作业1800秒、结果128MiB。沿用既有模型与conda，不训练、不改状态规则或阈值。

## 实施进度

## 收口结论（2026-11-01）

`r6`（run `ntf010-teacher-fdb30-20261101-r6`，源码 `836754e`）在固定 FDB30 上完成：

| 项 | `r6`（一次空步） | `r4`（两次空步） |
| --- | --- | --- |
| 完整率／退出码 | 30/30，0 | 30/30，0 |
| 帧数 | 3175 | 3175 |
| 主块发布 P50／P95 | 208.5／219.6ms | 205.8／221.7ms |
| 主块发布最大 | 405.3ms | — |
| 800ms 触发 | 0 | 0 |
| `buffer_overflow` | 0 | 0 |
| `post_pause_extension` | **17（13 条用例）** | 4 |
| 规范分词一致 | 见 `analysis/` | 26/30 |

结论：延迟与实时合同仍达标，但“一个空 ASR 增量即词完整”的判据不成立——17 次尾词在提交后又被同一词的后续字符扩展，说明空步只是“这一步没吐 token”，不能证明词边界。把门槛加严到两次空步能减少误提交，但只是把阈值往后挪，没有把判定权交给模型。

因此本单保留两项成果并停止继续调阈值：

1. 词级规范分词与历史前缀不变量（后续 X2 路径原样复用）；
2. “不重放、不改写已注入 token”的 append-only 纪律。

尾词判定改由 X2Streaming-ASR 的EOS闭合发射组承担，见 [NTF-011报告](../reports/soulx/20261101-ntf011-x2-probe/README.md) 与 [NTF-012报告](../reports/soulx/20261101-ntf012-x2-teacher-fdb30/README.md)。证据保留在 `artifacts/soulx/20261101-ntf010-teacher-fdb30-r6/` 与 `...-r4/`。
