# XTX-006：执行 100 条正式测试并归档报告

状态：待实施。依赖：[XTX-005](xtx_005_remote_smoke.md)；复用 XTX-001—004 的冻结产物。依据：[质量测试计划](../../dev/XTurnix/quality_test_on_fleurs.md)。

## 目标

在固定协议下完成 100 条独立录音的真实模型回放，报告控制增量延迟、覆盖和历史组合估计，保留全部失败与限制。

## 工作内容

- 核对冒烟已完成、正式输入与模型/配置锁一致，创建独立 formal run_id；100 条全部计划入账，每条新会话、batch=1，保留真实输入节奏和尾窗。
- 通过 XTX-005 作业入口远端串行回放；不在正式输入上调阈值，不注入参考文本、思考结果或人为结束标记。
- 停止推理服务后用 XTX-004 从原始 trace 独立评分，保留逐例 CSV、汇总 JSON、原始时间线和资源记录。
- 报告末端 start 命中数/100、锚点/完整窗口覆盖、提前 start、过期结果、未命中、未尝试及失败；零命中也给完整结果，不只统计成功样本。
- 同时报条件延迟均值、P50/P95、最大值及分母、辅助 WER，与 `413.582852ms+L_control` 的链路估计；明确只测到控制 start，不含表达/TTS。
- 记录历史与本轮模型/服务/硬件、轮询、共卡排队的差异，不将历史逐词 P50 当末词专项实测，不把 FLEURS 成绩写成 FDB TOR。
- 中断或重跑另留 run_id 和原因，不覆盖原始 trace、不挑选最佳运行冒充首轮。结束确认无遗留服务和作业。

## 交付

远端采用 `~/interclarify-xturnix-fleurs/<run_id>` 保存完整证据；Git 拟收 `reports/xturnix_fleurs_evaluation.md` 及 `reports/xturnix_fleurs_evaluation/<run_id>/` 下的小型表格/配置摘要，并更新 `reports/README.md`。不提交权重、音频或大日志。
