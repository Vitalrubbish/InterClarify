# XTX-005：编排远端预检、服务生命周期与冒烟

状态：待实施。依赖：[XTX-001](xtx_001_fleurs_data.md)、[XTX-002](xtx_002_component_deployment.md)、[XTX-003](xtx_003_streaming_replay.md)、[XTX-004](xtx_004_independent_metrics.md)。依据：[质量测试计划第 6 节](../../dev/XTurnix/quality_test_on_fleurs.md)。

## 目标

在正式 100 条回放前验证远端资源、两组件服务、在线采集、独立评分和退出清理，形成可复用的受限作业入口。

## 工作内容

- 预检固定输入、模型/环境锁、停顿及调度配置、独立输出目录与磁盘预算，不假定历史路径或模型仍存在。
- 编排现役 Nemotron 和独立 XTurnix conda 服务，串行预热、明确 readiness；仅在调度 GPU 上加载模型，不把启动成功当质量通过。
- 完成 dev 协议验证与 5 条冒烟，每条新会话，保存原始 trace、退出码、资源峰值和试评分。
- 冒烟只修复协议、资源及日志，不能按正式子集调整 start 阈值、改变抽样或挑选成绩；必要配置变更留版本和原因，正式运行前再次冻结。
- 覆盖服务超时、回放失败和资源触限的有序退出，停止服务后做 CPU 评分，结束核对无遗留服务或作业。
- 冒烟结果标为诊断，不并入正式成绩；正式测试仍对原 100 条重新独立回放。

## 交付

拟建 `scripts/remote/run_xturnix_fleurs_job.sh`，配套 `docs/scripts/remote/run_xturnix_fleurs_job.md` 说明阶段、参数、资源和清理。通过现有集群调度方式调用，不为本轮另建通用调度框架。远端保存 smoke 的配置、日志、trace 与验证摘要，Git 收简短冒烟记录。

## 验收

- [ ] 单个受限作业可完成预检、dev、5 条冒烟、退出清理及独立评分。
- [ ] 输入/权重/源码/配置版本、真实 readiness 和资源峰值可追溯。
- [ ] 服务失败、超时和资源触限不会误报成功，结束无遗留模型服务。
- [ ] 本地小型测试已通过，模拟、dev、smoke 与 formal 明确区分。
- [ ] 若有协议修正，已同步实现文档并重新冻结正式配置。

## 资源与边界

最多 1×24GiB GPU、8 CPU、32GiB RAM、batch=1，仅 1 个推理作业和 1 条活动录音、单作业≤4 小时；下载并发≤2、评分 worker≤2。新增资产累计≤10GiB、trace/结果≤2GiB、启动可用盘≥30GiB；不自动加卡，不覆盖现役环境。不运行 Layer 1/2、TTS、FDB 或训练。
