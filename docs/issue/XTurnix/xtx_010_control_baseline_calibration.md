# XTX-010：建立未训练基线、开发集校准与评分入口

状态：条件性后续，等待 XTX-007 分析结论与用户讨论。前置：[XTX-007](xtx_007_training_feasibility.md)明确同意进入后续范围；依赖：[XTX-008](xtx_008_vad_input_contract.md)、[XTX-009](xtx_009_training_data_freeze.md)。依据：[训练可行性方案第 5、7 节](../../dev/XTurnix/training_feasibility.md)，共同资源与范围见[工作单入口](README.md#训练阶段共同边界)。

## 目标

分清对话上下文、VAD 新观测、触发协议和阈值对效果的贡献，并冻结后续训练前后都采用的评价方法。

## 工作内容

- 在冻结开发集上分别运行单句 PT 默认决策、真实多轮 PT 默认决策、多轮 PT 校准，以及采用 XTX-008 扩展输入与触发规则的未训练 PT；官方与扩展基线不混计。
- 保存每次请求的输入、版本、状态、动作、合法动作对分数及发送/返回时间；FP32/BF16 差异另作核对，主比较使用同一精度。
- 为 Listen/start 和 Speak/stop 分别建立分数分布、PR 曲线与校准工作点，说明误抢话、误停预算及分母，明确数值和可接受回归幅度并在独立测试前冻结；不以提高整体 start 比例选优。
- 实现四类混淆矩阵、分句型/来源/长度/ASR 误差切片、事件级命中和错误归并、条件延迟与完整失败分母。配对区间按原对话或场景计算，不把快照当成独立样本。
- 定义独立影子回放协议：固定输入时钟、状态来源、触发和事件窗口；Listen/Speak 来自可追溯录制时间线或固定状态脚本，不由被测动作反推。未发生真实播放时，不声称是闭环交互或实际停播延迟。
- 记录默认决策、校准及新增输入分别改善和仍无法区分的错误，为试训确定目标。音频模型对照仅作后续有需要时的诊断，不成为本工作单必选部署项。

## 交付

拟新增 `scripts/remote/evaluate_xturnix_control.py` 及 `docs/scripts/remote/evaluate_xturnix_control.md`，同时保存评分协议、冻结校准配置、开发集基线报告和可复算原始记录。只编写验证分母、事件归并和关键时间边界的少量测试，并配套说明。

## 验收

- [ ] 文本与扩展输入基线均有结果或清楚的失败原因，输入和精度差异可追溯。
- [ ] 只使用开发集选择阈值与工作点，独立测试不参与调参。
- [ ] 误抢话、误停和延迟预算及事件分母已写明并冻结。
- [ ] 四类动作和困难负例未因只统计成功 start 而消失。
- [ ] 评分可从 trace 重算；重叠窗口与事件未重复计数，null 未填成零。
- [ ] 基线及评价合同能够用于训练前后公平比较，交付完成后立即归档。

## 边界

不更新模型权重，不使用 FLEURS 或 FDB 选择阈值，不提前反复查看独立测试。新增输入不被原模型理解属于需要如实记录的基线现象；不能通过改写测试提示词消除它。
