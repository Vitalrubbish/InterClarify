## 训练阶段共同边界

以下为 XTX-008—013 的候选实施边界，仅在明确进入对应范围后适用。本次授权的首轮审核只进行了受限文本/元数据采集与辅助审查，未创建环境、编写训练实现、批量准备训练数据、更新参数或启动 GPU；资源探针中的微量优化仍属于尚未放行的后续实施。规模与超参数并非可行性已成立的承诺。

- 保留 Nemotron EN160 与冻结 PT 底座，VAD 只提供真实发声和时间观测；XTurnix 判断 Listen 下 keep/start、Speak 下 keep/stop，输出运行时仍是唯一执行点。不把发声自动映射为 stop，也不把静音自动映射为 start。
- 扩展输入、触发方式、因果 VAD 参数与缺失值在后续 XTX-008 冻结；不拼接句末合成 pause，不使用 EOF、文件长度或事后末词补点。单会话最多 1 个在途控制请求、1 个待处理最新观察，状态和输入版本可追溯。
- 普通控制先于 CoT 条件化训练。新工作单不训练 Layer 0/1/2、Nemotron 或 CoT，不部署完整播放链、不切换现役控制器；现役 DuplexCascade 只作保留基线，不与新路径同时执行。系统附和仍属于 Layer 0。
- 试标约 200 个独立对话/场景；训练快照≤2,000 条，开发和独立测试分别争取≥100 个独立对话/场景。数量不足报告缺口，窗口与重复样本不增加独立分母。FLEURS 与 FDB 评测资料不用于训练、教师生成、阈值或检查点选择。
- 主比较为相同输入、触发、精度与校准规则下的未训练和训练模型；官方文本基线另报。误抢话、误停、延迟预算和回归容限由后续 XTX-010 明确并在独立测试前冻结。四类动作、条件延迟、覆盖、失败和 null 全部保留。
- 本地与远端均使用 conda；真实模型训练和集群验证只在远端调度作业执行。最多 1×24 GiB GPU、8 CPU、32 GiB RAM、micro-batch=1、1 个活动作业，数据/评分 worker≤2、下载并发≤2；训练与同卡推理串行，拟定 GPU 停止线 22 GiB。
- 单 GPU 作业≤4 小时，试训最多 2 次，采用同一个配置的不同种子；第二次须有首次开发集正向证据。阶段累计 GPU 时间≤8 小时，包含基线、机制探针和验证，不能给每次作业重新分配一份总预算。
- 启动可用盘≥30 GiB，新增环境、缓存、数据和检查点累计≤10 GiB，其中 trace/报告≤2 GiB。每次试训最多保留最佳与最终两个 adapter，不复制底座。下载、解压及保存前核对峰值空间，触限停止并记录，不自动加卡、加内存或扩盘。
- 每项代码/配置/测试同步维护 `docs` 下对应路径的中文说明，测试保持少量且验证关键契约。所有运行保留独立 run_id、版本、哈希、配置、资源和退出证据，不覆盖旧 run，也不提前标记完成。

- 固定 100 test＋1 dev；正式采用 Nemotron EN160＋XTurnix-PT、80ms 音频传输、Listen 条件影子决策、5 秒在线静音尾窗及独立 EOF 排空。

- 报告全部计划分母、失败与 null；历史 413.582852ms 仅作 ASR 典型开销估计，不冒充实测末词延迟、整体 P95、FDB TOR 或可听回复延迟。
- 本轮不运行 Layer 1/2、TTS、播放器或训练，不恢复已取消的 FDB 测试；不改现役模型环境和单一播放所有权。
