# XTX-011：执行受限 LoRA 试训并冻结候选模型

状态：待实施。依赖：[XTX-010](xtx_010_lora_resource_probe.md)，复用 [XTX-008 数据](xtx_008_training_data_freeze.md)及 [XTX-009 评分合同](xtx_009_control_baseline_calibration.md)。共同资源与范围见[工作单入口](README.md#训练阶段共同边界)。

## 目标

以有限数据和一个起始配置验证 XTurnix 领域适配，获得可独立评价的候选或清楚的失败证据。

## 工作内容

- 使用 XTX-010 的入口，重新预检数据、底座、扩展输入、训练配置、资源估算及剩余累计预算；训练快照≤2,000 条，真实与合成来源分别计数。
- 首次只运行一个配置和种子，最多 2 epoch 或 200 个优化步，先到者停止。跟踪四类训练采样，避免同一事件的密集 keep 前缀占据训练信号。
- 只用训练和开发集检查优化、过拟合、陈述句接话、句内等待及用户打断回归；按 XTX-009 相同规则校准训练后模型，不读取独立测试选检查点。
- 每次最多保留最佳和最终两个 adapter 检查点，保留完整配置、样本顺序、随机种子、有效步数、状态和资源记录；不重复保存完整底座。
- 首次在开发集出现符合冻结误触发预算的正向证据后，才用同一配置和另一种子复核。最多两次试训；无正向证据时不自动追加配置、epoch 或样本。
- 重载检查点，冻结候选、开发集选择依据、阈值和输入版本。候选不可用或停止复核时保留失败原因、计划分母与未尝试项。

## 交付

复用 XTX-010 的脚本及配套说明。远端保留独立 run_id 下的 adapter、训练/开发记录、哈希和资源；Git 收训练报告与候选清单摘要，不提交权重、大训练日志或数据。

## 验收

- [ ] 计划试训、完成/失败/未尝试与停止原因全部入账，未超单作业和累计限额。
- [ ] 检查点与阈值完全由训练/开发选择，独立测试保持未参与调参。
- [ ] 四类动作及过拟合、回归有记录，首轮结果不佳未被隐藏。
- [ ] 第二种子已执行或具有未执行原因，未变成自动超参数搜索。
- [ ] 候选可重载且版本、输入、数据、精度和分数规则可追溯；若无可用候选，结论明确记为失败或证据不足。
- [ ] 试训与退出清理报告齐备，完成约定试验后立即归档；试验完成不等于模型有效。

## 边界

不因开发集结果好看而宣称已经改善真实对话；不在独立测试结果出来后回头选择种子或检查点。不扩大到 CoT 训练，不接入 Layer 1/2 或播放。
