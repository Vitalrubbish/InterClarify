# NTF-025：固定 FDB30 复核与教师路线决策

日期：2026-11-02。状态：待调研。依赖：[NTF-023](NTF-023.md)正确性／实时预检通过、[NTF-024](NTF-024.md)完成归因。本轮仅建单。

## 目标

在原固定FDB30复核原生SenseVoice与最小X2教师差异，结合词级时间证据给出后续路线建议。工程规范性、实时性和状态质量分别验收，不以单项通过代替整体收益。

## 工作范围

1. 沿用原三轴各10条清单，执行前核验全部摘要。正式矩阵至少保留原生SenseVoice和最小X2教师两臂；最多增加一条由NTF-024证据支持的消融臂，事先冻结配置、顺序、一次运行和总预算，不按正式结果择优追加。
2. 使用相同完整预热合同、随机种子、PCM、资源、原生规则和reset策略；适配不可避免差异单列，记录源码／模型／环境摘要、退出码、全部失败及未覆盖样本。
3. 统一报告三轴状态、nonidle检出与共同检出子集、原始／规则complete、主块／完整观察／实际返回坐标及边界敏感事件。提前计数不自动等于语义错误，原始预测不能用发布延迟修饰。
4. 报告20条有参考文本样本的在线WER及词级匹配覆盖，分停顿／打断子集；接话10条不计WER。EOF诊断、未发射词与未处理真实采样分别报告，不回填在线结果。
5. 汇总首词／末词和共同词的ASR可用时差、实际教师消费时差、空步间隔、修订／reset分布、P50／P95／max延迟、积压曲线及资源峰值，与小样本归因是否一致。

## 交付与验收

- 每臂完整率、退出码与失败保留；30/30完整、退出0、无过载且输入／因果审计通过才达到实时完整性门槛。
- 原生SenseVoice不作为标签真值，依据标注与事件核查评价；单次30条只作描述性比较，不宣称显著优越或普遍不兼容。
- 一份中文路线决策报告，分别列出已证实原因、剩余混杂和证据缺口，建议继续教师替换、进一步协议适配／训练、保留独立正文，或暂不决策。
- 同步研究方案、工程入口与工作单；原NTF-015—020不自动恢复。完成即归档，部署、下游接口和训练另行建单。

## 执行边界

真实模型在远端既有conda，遵守[统一资源边界](../dev/SoulX-Duplug/asr_teacher_diagnosis.md#5-执行与资源边界)。正式作业数及总GPU／结果预算在本单实施前冻结，按预检估算合理分批；旧工作单预算不转用。本轮只建单，不训练、不接LLM／CoT／TTS、不切换运行底座。
