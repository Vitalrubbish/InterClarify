# Issue 074：将训练集扩充至3k独立对话并补足多样性

状态：待执行，2026-10-21。073审计已交付；本单尚未启动，后续交付数据，不启动模型训练。

## 目标与固定边界

将train从1,000扩充至3,000条独立来源对话，不把micro-turn、序列窗口或句读增强视图计作新样本。默认保留原1k train，并新增2k；dev 200、test 300保留原来源身份与内容，合计3,500条对话。新增对话不得与既有train/dev/test、外部排除集或FDB发生泄漏。FDB只用于后续冻结评测，不按FDB逐例文本挑样本或生成训练内容。

扩充先沿用已冻结UltraChat来源revision和英文范围；如审计发现来源无法补足目标覆盖，先记录缺口与替代来源方案，不静默引入新来源。保留当前数值表面处理、五类控制token、下一no-voice拍启动、系统backchannel关闭及现有Layer动作边界，不纳入思考请求token或主动澄清专项训练。

2026-10-21用户进一步明确训练文本尽量模仿ASR：保留话中可识别句读，重点适配缺少句末点号的形式。073先核验真实EN160轨迹；本单不再把完全去句读T2默认为最终3k视图，待审计后冻结新的用户文本规则，并独立记录与1k基线的组成/视图差异。

[073结果](../../reports/layer1_training/issue073-surface-audit-20261021-r2/README.md)已确认：train原样2949/3828个用户长轮含内部句读，T2全部删除；ASR 122/200次含内部句读、在线末尾点号仅1/200。新视图应保留内部句读并适配长轮末尾点号，先处理完整用户轮再分拍。只删点号仍有70.04%的train长轮以`?!`结束；须补核疑问/感叹ASR场景，再冻结这些符号及内部稀有标点的处理，不凭以朗读为主的100条录音认定它们永不输出。无新增GPU探针或数据视图已经执行。

073完成60条代理局部语义阅读，人工签署仍pending；关键词列举/修正候选误报较多，应检查停顿附近而非全长轮是否含关键词，单列经复核的列表、口语自我修正及无句末符号续说覆盖。本次样例不替代本单的数据人审。

## 数据调整

1. 依据073形成明确的分层表：主题/任务类型、用户轮长度、对话轮数、回答长度、问句/陈述/多句/列举/自我修正，以及轮内停顿和句子完整仍续说的覆盖。交付旧1k、新增2k、合并3k的对照分布；语义标签说明来源和抽检误差，不能把表面长度当成语义多样性。
2. 构建前冻结各层数量或范围、短中长划分阈值、抽样种子与候选预算，保证短问答、多轮交流和长表达均有覆盖，避免单一主题或长篇书面内容占据新增集。原候选预算仅6,000条；按去重后有效候选与分层缺口决定是否扩大有界抽样，不改为无上限全库扫描。补不足时明确失败并报告。
3. 把原1k及dev/test作为固定集合，新增候选先对固定集合和外部排除集检查，再分层补足2k；不能仅把`splits.train`改成3000后重新顺序切分而使旧dev/test进入train。精确/近重复检查覆盖原文、数值规范化文本与用户/assistant轮，报告拒绝原因、来源位置和摘要。
4. 根据073补足自然句读与停顿覆盖，明确随机停顿和语义边界样例各自来源。若需要调整生成规则，先更新设计说明并保留旧版，不改写1k基线。任何新增边界标签只能用于审计和监督构建，不能作为运行时可见的未来提示。
5. 保留可追溯的事件计划和监督位置；新ASR表面视图作为拟训练输入，原样/T2用于差距检查，不自动增加训练实验。视图规则冻结后更新构建、审计、索引、协议及镜像文档，不能只改训练器标签。对3k重新生成2048窗口完整索引、有效监督token和控制类别计数，重算单epoch步数、warmup与保存点，不沿用1235步或简单乘三。
