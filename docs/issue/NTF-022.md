# NTF-022：同音频的 SenseVoice 与 X2 词级时间轴对照

日期：2026-11-02。状态：待调研。依赖：[NTF-021](NTF-021.md)冻结输入与时间定义。本轮仅建单。

## 目标

比较完全相同音频中的词在两种ASR下何时首次出现、修订或闭合，区分识别交付节奏与计算等待。不能用相同文本的不同录音代替同音频，也不能把历史X2相对Nemotron的时差当作相对SenseVoice的结果。

## 工作范围

1. 使用[调研方案](../dev/SoulX-Duplug/asr_teacher_diagnosis.md)固定6条音频，记录文件及实际PCM摘要，两种ASR逐臂串行运行。SenseVoice按冻结的原生窗口构造查询、每160ms观察一次；该独立ASR测量不调用控制器门控，明确不是原生完整控制轨迹。X2保持80ms原生协议。
2. 保存SenseVoice每窗原始／清理后假设、修订、空输出及实际输入范围；X2保存WORD／WAIT、真实EOS闭合组、组内token及完整组文本。多词组共用实际闭合时刻，不伪造词间时间。
3. 记录音频处理截止、实际观察上界、计算开始／结束、返回时刻、排队与积压；保留首词、末词、停顿前后及EOF未处理／未发射尾部。在线结果与离线drain分开。
4. 按词序列对齐共同词，处理重复、替换和撤回，报告匹配覆盖、遗漏与歧义。对关键事件人工核查词尾，离线强制对齐如可复用则记录方法与置信度，仅作评分参考。
5. 生成每样本时间轴及词表，比较首次出现和最终保留词的提交时差分布、组大小、有字／空步间隔、识别质量与计算耗时；事后最后修订不得冒充在线已知的稳定时刻。

## 交付与验收

- 两臂6/6完成及逐词匹配覆盖、P50／P95／max、异常和失败记录，产物能回溯原始假设与真实采样范围。
- 清楚区分声学词尾到输出的延迟、两ASR相对时差和墙钟计算时间；缺少声学时标时不宣称绝对音文错位。
- 本单回答ASR交付节奏，控制器门控后的实际教师消费由[NTF-023](NTF-023.md)测量。
- 采集／分析脚本配套docs同路径中文说明，包含功能、类设计及核心方法。

## 执行边界

真实推理在远端既有conda，执行[统一资源边界](../dev/SoulX-Duplug/asr_teacher_diagnosis.md#5-执行与资源边界)。作业矩阵和总预算先由NTF-021冻结；本轮不提交作业。不更换权重、不调状态阈值、不为ASR差异修改控制器。
