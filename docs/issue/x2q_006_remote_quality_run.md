## 目标

在远端执行主配置 tau=480 ms 的真实流式测试，完整交付两类指标与错误分析。本次规划不表示此工作单已执行。

## 执行单元

1. 预检 manifest、已冻结参考、实际 delay、环境、可用 GPU 与磁盘。
2. 主子集各 5 例、user_backchannel 5 场景成对输入，共预期 30 次冒烟；只修传输/格式，不据分数调参。
3. 正式预期 672+198=870 次输入，按真实总时长拆分单会话作业，失败/缺失逐条留账。
4. 运行冻结评分，复核代表性错误，核对资源峰值与退出码，结束服务。

## 交付与验收

远端保留配置、环境、输入/参考哈希、原始 trace、评分和失败清单；Git 收 `reports/x2_turn_fdb_quality.md` 中文报告与产物定位。报告分别给出语料 WER、末端延迟/句尾覆盖和状态匹配/标注覆盖，不把独立前端成绩当作官方 FDB 全链路结果。不自动扩大数据/消融范围，完成后归档。
