# X2Q-014：远端冒烟、正式测试与报告

状态：待执行。依赖：X2Q-009—013 全部完成。依据：[测试计划](../dev/X2-Turn/complete_test_on_fleurs.md)。

## 目标与执行步骤

在同一冻结配置、同一批 100 条输入上取得真实 ASR 与 complete 结果。

1. 核对输入/模型/源码/环境锁、有效 delay=480 ms、空闲磁盘和已有作业，登记预算。
2. vc 单 GPU 作业先独立 dev 预热，再固定 5 条 test 冒烟；只排查协议、时钟、格式和资源，不据分数调参。
3. 正式串行回放全部 100 条 test，逐例保留原始输入、5 秒尾窗与 EOF 排空；预热和冒烟不并入正式分母。
4. 同批 trace 分别运行 ASR 和 complete 评分，核对总数、失败和 null，停止服务，保存退出码与资源峰值。
5. 完成中文报告、逐例结果与远端产物定位，完成后归档工作单。

## 交付

- 远端独立 run_id：配置/环境/模型/源码/数据锁、manifest、原始 trace、逐例评分、汇总、失败列表、资源记录与退出码。
- `reports/x2_turn_fleurs_evaluation.md`：语料级 WER 及 S/D/I、平均末端文本延迟、complete 输出率与首次延迟，以及各项覆盖分母。
- 对提前 complete、EOF 后补字/补状态、未命中和运行失败分别说明，不合并成一个准确率。

## 验收与资源

- [ ] 远端 conda，最多 1×24 GiB GPU、8 CPU、32 GiB RAM，单作业 4 小时、单会话；登录节点不运行 GPU 模型。
- [ ] 整轮资产≤70 GiB、结果≤5 GiB，启动空闲盘≥100 GiB，不自动加卡/增加并发。
- [ ] 100 条逐例记录齐全，失败与未命中可区分，全部指标可由冻结 trace 重算。
- [ ] 正式分数来自真实远端模型，提交、预热或模拟通过不代替实测。
- [ ] 未运行 LLM/TTS/Judger 或 FDB 测试，大日志/音频不入 Git，结束无遗留本作业服务。
