## FDB 跨数据集测试共同约定

按用户最新纠正，FDB不适用下文训练／旧验收的模拟回答生命周期：只保留真实ASR、控制动作和动作驱动的状态，start切Speak、stop回Listen、keep维持；没有自动回答完成或计时复位。480ms与160ms统一此口径，旧带模拟回答的运行撤回保留。

- 依据[两臂各50条计划](../../dev/TextTurn/fdb_cross_dataset_plan.md)，TT-005／006按能力结果拆分，共用清单、回放／评分入口和一份中文联合报告，100条在一次远端作业内串行执行。抽样、规则冻结、必要适配和少量边界测试随结果交付，不另设工程确认工作单。两项工作交付完成不等于模型质量达标，也不自动完成 TT-004。
- 固定 `tt-002-20261025-r1/best`，adapter SHA256 为 `32f5493835a1b21294a3b862e38da85f7d052bbc93dbf12a81c42436e14b5d17`；固定种子20261025，以 `SHA256(seed|subset|sample_id)` 排序抽样，先固定样本及评分规则，再看模型结果。真实 Nemotron 输入、Listen/Speak 动作状态与影子动作，不生成回答或播放音频，不新增 VAD、固定等待或延迟补偿。
- FDB 历史已被项目使用，逐条披露已知历史使用或未知；不称项目级全新盲测。不把本轮音频、正文、标注或 ASR trace 用于训练，不用这100条选检查点、调阈值或训练配比。
- 使用远端调度和已有 conda 环境；合计最多1×24GiB GPU、8 CPU、32GiB RAM、worker≤2、一个活动作业，显存22GiB停止线，本次作业最多2小时。启动前核对本轮累计8 GPU小时的实际剩余额度，不足则缩短作业上限或不启动，不重新分配预算。新增资产≤10GiB、报告≤2GiB、启动可用盘≥30GiB，尽量引用已有资产，触限停止并保留结果。
- 失败逐例落盘、不删除或换样补位。修复运行错误后需保留原记录、说明修复并单独编号；服务停止后离线评分。候选不足、预算不足或其他阻塞如实记录，不将未实施写成完成。

## 共同约定

- 无新增 ASR 文本直接作为带延迟静音，输入 `no-voice`；不新增 VAD、词稳定等待或延迟补偿。控制窗480ms，聚合三个Nemotron名义160ms解码完成步骤；ASR转写仍及时写Context，聚合等待单列。Assistant每窗8 token模拟生成，生成完成后仍可处于Speak，播放完成才转Listen。
- stop 仅用于用户打断系统，正常回答完成由生成及播放生命周期处理。只训练当前合法动作，不训练表达正文、ASR、Layer 0/1/2 或 CoT。
- 仅接入影子控制与 Context，下游使用只读消费者核验；不更换现役播放器、不叠加另一套执行控制，不恢复旧 SoulX/XTurnix 或已取消评测作业。
- 模型运行与训练使用远端 conda，最多 1×24GiB GPU、8 CPU、32GiB RAM、单活动作业、worker≤2，显存停止线 22GiB；单作业≤4h，本轮累计≤8 GPU 小时。新增资产≤10GiB、报告≤2GiB、启动可用盘≥30GiB，沿用训练方案预算，不按工作单重新分配。
- 每项代码、配置和必要测试同步维护 `docs` 下对应路径中文说明。报告保留失败和实际分母；测试不佳不自动扩大数据、模型或超参数搜索。
- 一项交付满足本项验收后立即归档到 `docs/issue/archive/TextTurn/`，同步本页及[全局入口](../README.md)。工作交付完成与模型质量达标分别记录，不能因门槛未达而隐去结果，也不能把未完成测试写成通过。
