## 共同约定

- 无新增 ASR 文本直接作为带延迟静音，输入 `no-voice`；不新增 VAD、词稳定等待或延迟补偿。控制窗480ms，聚合三个Nemotron名义160ms解码完成步骤；ASR转写仍及时写Context，聚合等待单列。Assistant每窗8 token模拟生成，生成完成后仍可处于Speak，播放完成才转Listen。
- stop 仅用于用户打断系统，正常回答完成由生成及播放生命周期处理。只训练当前合法动作，不训练表达正文、ASR、Layer 0/1/2 或 CoT。
- 仅接入影子控制与 Context，下游使用只读消费者核验；不更换现役播放器、不叠加另一套执行控制，不恢复旧 SoulX/XTurnix 或已取消评测作业。
- 模型运行与训练使用远端 conda，最多 1×24GiB GPU、8 CPU、32GiB RAM、单活动作业、worker≤2，显存停止线 22GiB；单作业≤4h，本轮累计≤8 GPU 小时。新增资产≤10GiB、报告≤2GiB、启动可用盘≥30GiB，沿用训练方案预算，不按工作单重新分配。
- 每项代码、配置和必要测试同步维护 `docs` 下对应路径中文说明。报告保留失败和实际分母；测试不佳不自动扩大数据、模型或超参数搜索。
- 一项交付满足本项验收后立即归档到 `docs/issue/archive/TextTurn/`，同步本页及[全局入口](../README.md)。工作交付完成与模型质量达标分别记录，不能因门槛未达而隐去结果，也不能把未完成测试写成通过。
