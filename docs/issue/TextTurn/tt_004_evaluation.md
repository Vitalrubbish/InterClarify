# TT-004：完成四类质量与延迟验收

状态：待实施。依赖：[TT-001](tt_001_dataset.md)、[TT-002](tt_002_training.md)、[TT-003](tt_003_streaming_context.md)。依据：[训练方案第 4 节](../../dev/TextTurn/training_plan.md#4-通过门槛)。

## 目标

用独立数据给出候选是否达到第一阶段门槛的结论，直接交付逐例结果和中文报告。

## 工作

1. 固定唯一候选、独立测试数据和评分规则，先回放文本事件，再使用对应测试场景可取得的语音运行 Nemotron＋控制器影子回放；保留两种输入结果，不用干净参考文本替换在线 ASR。
2. 语音优先复用可追溯资产；不足时可按已有测试事件离线合成并明确标注来源，不从 FDB/FLEURS/Easy Turn 测试内容生成训练资料。不具备语音或独立场景数量时报告缺口，不把文本成绩写成在线通过。
3. 按独立机会评分四类能力、陈述句和控制延迟，同次验证 Context 转写交付。失败和未命中留在计划分母，样本数量、语音来源及模拟播放限制写清楚。

## 通过门槛

| 项目 | 首轮门槛 |
| --- | --- |
| 正常接话及陈述句接话 | 允许动作依据可见后 1,000ms 内的 start 覆盖分别≥80% |
| 用户打断 | 同口径及时 stop 覆盖≥80%；自然说完不计入 |
| 停顿误抢话／用户附和误停 | 分别≤15%，按发生过错误的机会计数 |
| 控制耗时 | 输入就绪至动作返回 P95≤500ms，包含排队、调度与传输 |
| Context／运行 | 非重复版本写入及读取一致；运行成功率≥95%，无无界积压 |

## 交付与验收

- 评分入口及对应说明、逐例 CSV、汇总 JSON 和一份中文结论：通过、未通过或证据不足；四类和陈述句分别列实际分母及 95% 区间。
- 记录480ms聚合等待、合并观察、ASR开销和所有null；及时性仍从动作依据首次可见计时，不后移到窗关闭。ASR 延迟接受且不补偿，控制延迟不冒称实际开口／停播延迟。
- 成绩不佳也交付完整结果，不在独立测试上调参或再选检查点。工作单完成表示验收工作已交付，不代表模型必然通过。

本项不强制追加 617 条 Easy Turn 或完整 FDB，不恢复已取消作业、不训练 CoT、不部署现役替换；可选外部诊断不阻塞本项交付。
