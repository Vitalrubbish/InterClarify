# TT-006：统计 FDB 50 条录音在ASR停止更新前连续至少3周期Speak的比例

状态：待实施。依赖：[TT-002](../archive/TextTurn/tt_002_training.md)、[TT-003](../archive/TextTurn/tt_003_streaming_context.md)。依据：[FDB 跨数据集计划](../../dev/TextTurn/fdb_cross_dataset_plan.md)。

## 目标

直接交付50条真实录音中，在ASR转写不再更新前，系统出现过连续3个周期及以上处于模拟Speak状态的样本比例。主指标统计持续Speak行为，不以停顿区间内单次start替代。

## 工作

1. 按计划的固定种子和排序规则，从 `candor_pause_handling` 取50条有效且音频不重复的录音，保存资产摘要、全部候选、排除理由及已知历史使用。保留全部pause区间供辅助解释；候选不足时交付原因，不换来源或缩小分母。
2. 使用与 [TT-005](tt_005_fdb_turn_taking.md) 相同的固定候选、真实ASR、80ms音频包和480ms完整控制周期，每条从Listen开始执行模拟状态转移；start进入Speak，stop或模拟播放完成后返回Listen，不再固定Listen。
3. **关闭末尾静音拼接**，只发送原始录音。原音频结束即结束输入，不追加5秒静音，也不补额外no-voice或凑满周期的观察；原始录音内部的停顿及其正常no-voice输入保持不变。EOF排空不产生新的评分周期。
4. 按计划确定在线转写最后一次实际变化并发布的 `t_last_asr_update`，统计严格早于该时刻的完整控制周期，记录动作应用后的模拟状态、最长连续Speak周期数及命中序列起止时刻。结合ASR前缀、空窗及FDB标注解释持续Speak行为，不改候选或主指标。

## 交付与完成条件

- 50条冻结清单、ASR／控制／模拟状态trace、逐录音CSV、汇总JSON及中文结果，FDB逐区间证据仅作辅助。
- **ASR停止更新前连续至少3周期Speak样本比例**：最后更新之前出现过连续3个及以上完整控制周期均为Speak的录音数／50。同一录音多次命中只计一次，连续1或2周期不命中；跨越最后更新时刻的后续周期不能补足3周期。
- Listen状态或不可恢复的观察缺口中断连续计数；合并窗不能拆成多个已观察周期，EOF残窗不计完整周期。只统计原始录音的在线观察，不使用拼接静音或额外no-voice。
- 无有效ASR转写、运行失败及关键trace缺失单列未知，不能算正确保持。报告命中、已确认未命中、未知及50条计划分母上的保守上下界；可判定比例列分子／分母及Wilson95%区间。
- 语义归因不改变主指标，连续Speak不直接等于语义错误；单列控制耗时P95、观察覆盖、合并及EOF状态，不给出实际音频输出TOR或闭环对话结论。
- 结果好坏均可完成本项；不改阈值、不重训、不换样本补失败，也不由本项宣称用户打断、附和或 system backchannel 已通过。

与 TT-005 共用一次远端串行作业及一份联合报告，两项没有先后完成依赖。资源合计受[共同约定](README.md#fdb-跨数据集测试共同约定)约束；完成各自结果即可分别归档，不要求另一项先完成。
