# NTF-024：空步规则与教师提交时序的单因素归因

日期：2026-11-02。状态：待调研。依赖：[NTF-022](NTF-022.md)、[NTF-023](NTF-023.md)的有效轨迹及预检。本轮仅建单。

## 目标

区分空增量规则的直接／历史反馈效应与文字提交时序的影响。SenseVoice也会触发空步规则，不能把规则存在本身当成X2退化的原因。

## 工作范围

1. 固定前序6条、权重、波形、原生reset与适配代码，在每种ASR内分别开／关“空增量nonidle达到计数后强制二选一”分支，形成ASR×规则的2×2对照；nonidle→idle的另一规则保持。比较各ASR内的规则效应，再比较效应差异。
2. 从同一份因果可用X2闭合组序列重放，只将文字可用时刻额外延后160ms，对比0ms；内容、顺序、词组和其余策略不变，保留实际门控与完整状态反馈。两臂均用相同重放器，先核对0ms重放与捕获轨迹的一致性；差异未解释前不作因果结论。
3. 不把最终全文、未来词或离线词尾对齐结果送入早期输入。延迟导致EOF尾部未消费时单列内容覆盖差异，在共同覆盖区域解释纯时序效应。
4. 对ID3／136／20／9的提前complete建立完整事件链，区分当前原始预测、当前规则改写和先前改写经反馈影响后续预测；不能事后删掉规则帧代替重新推理。
5. 若证据指向门控、修订或reset，再提出一次只改一项的后续实验设计与预算；本单不自动展开所有组合，不直接把固定延后160ms当成修复。

## 交付与验收

- 执行前冻结有限矩阵、复用哪些基线、各臂唯一变量、次数与总预算；相同配置的前序有效结果可复用，差异须说明。
- 完整重放各臂状态反馈，按相同样本并列检出覆盖、提前complete、停顿误完成及结束后complete，报告首个分歧与失败。
- 以标注和关键事件核查解释改善／退化，明确哪些只是相关、哪些受控实验支持因果；小样本不分配未经支持的因果百分比。
- 归因报告及所需重放／分析实现有docs同路径说明；不预设去规则或延时一定更好。

## 执行边界

执行[统一资源边界](../dev/SoulX-Duplug/asr_teacher_diagnosis.md#5-执行与资源边界)，真实推理在远端conda；离线因果重放与实时回放分开标记。本轮不执行作业；不训练、不调整其他阈值。结论用于冻结[NTF-025](NTF-025.md)正式复核臂。
