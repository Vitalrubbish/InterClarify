# TT-002：训练 Qwen3-0.6B 控制器

状态：已完成并归档（2026-10-25核查）。依赖：[TT-001](tt_001_dataset.md)。依据：[训练方案](../../../dev/TextTurn/training_plan.md)。

训练run `tt-002-20261025-r1`退出码0，pilot及full各两轮完成，按开发集选择full第2轮。候选adapter已保存，新增token行更新及重载动作分数一致均通过。训练耗时约1小时56分，未用独立测试选模型。开发集正常接话91.75%、陈述86%、打断100%，停顿／附和错误均0。详见[结果核查](../../../../reports/textturn/20261025-tt-004-results/README.md)。本项训练交付完成不代表语音验收通过。

## 目标

交付一个可重新加载、只输出 keep/start/stop 的候选模型，并用开发集判断专项训练是否值得继续。

## 工作

1. 在远端隔离 conda 环境加载 `Qwen/Qwen3-0.6B`，关闭 thinking；冻结模型、tokenizer 与配置。准备环境和小批次学习／保存重载检查直接并入训练入口。
2. 使用 LoRA rank=16、alpha=32，训练新增动作的嵌入与输出参数及 `no-voice` 输入嵌入；只监督动作。初始学习率 `1e-4`、warmup 5%、最多 2 epoch、长度 2,048、micro-batch=1、累积 16、BF16。
3. 先跑不超过 2,000 快照的受限试训，同输入在开发集比较未专项训练模型与训练候选。无开发集收益或误抢话／误停明显回归时，交付原因与停止结论，不直接扩大训练。
4. 有正向证据且预算允许时，使用 TT-001 完整训练候选继续完成首轮训练。只依据开发集固定一个最终候选，保存最佳和最终 adapter，不在独立测试上选模型。

## 交付与验收

- 可运行的训练与动作推理入口、固定配置、adapter、对应中文说明及一份简短开发集结果。
- 已核验新增 token 随 adapter 保存重载，Listen 仅选 keep/start、Speak 仅选 keep/stop，不生成回答、解释或 CoT。
- 分开报告训练 loss 和四类开发集机会指标；完成训练不等于质量通过。若止于试训，明确未进入完整候选及 TT-003/004 的原因。

本项共用组内单卡、单作业和累计 8 GPU 小时预算，训练与评分串行。不另建资源探针、训练机制确认或多模型搜索任务。
