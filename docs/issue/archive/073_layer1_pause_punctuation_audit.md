# Issue 073：现有1k训练数据的句读与句内停顿审计

状态：已完成并归档，2026-10-21。全量数据机器审计及200份历史ASR轨迹统计退出0，60条代理语义阅读已交付；人工签署仍pending并交074跟踪。本单未修改训练数据、未启动训练。

用户补充：当前ASR能输出话中句读，主要缺少句末点号，训练文本应尽量模仿真实ASR输出。本单因此增加现役Nemotron EN160已存真实录音轨迹的只读统计，分别统计内部句读、在线末尾与EOF后末尾，检查问号/感叹号，避免继续把“无句末点号”实现为“所有标点删除”。不重新运行ASR模型，不修改现有训练数据；074据实采用更贴近ASR的用户文本视图。

## 背景与已知事实

当前候选为T2_R3_delayed_start，从DuplexCascade完整官方权重初始化后适配既有LoRA，使用1,000条train。[完整FDB结果](../../../reports/fdb/20261021-full-two-axes-r4/README.md)为Smooth TOR 59/119（49.58%）、User Interruption TOR 160/200（80.00%）；两轴有效接话平均延迟分别1.023秒、1.183秒，GPT相关性仍待补。不能据此认定漏接话由句读或数据量单独造成。

“话中的句读”同时检查以下两层，避免把去标点与无停顿混为一谈：

- 文本句读：原样视图保留用户句读，当前正式T2读取去句读视图；assistant正文保留。数值规范化、撇号/连字符和特殊token保护按现有规则追溯。
- 轮内停顿：生成器在非末用户分片边界按0.10概率插入1–5个no-voice/talking拍，即合成0.6–3秒停顿；[040a报告](../../../reports/layer1_training/issue040-delayed-start-data-20261020/README.md)记录train共12,826拍。该数是拍数，不是停顿次数或对话数，也不是实测音频静音。

随机分片和随机停顿不保证落在自然语义边界。前缀看似完整但随后继续补充的负例覆盖仍未完成核查；no-voice只表示本拍没有新增识别文本，不自动证明用户让出话轮。

## 工作与交付

1. 核对当前数据manifest、审计、训练索引与实际T2视图身份；以当前040a远端数据为准，不用旧r5替代。检查原文、规范化文本、原样/去句读视图及最终训练序列中的句读是否一致可追溯，列出删除与保护的字符类别和实例。
2. 分train/dev/test统计停顿触发次数、拍数、时长、覆盖对话数、相邻文本与标点位置；区分句内、句间仍续说、真正轮末、用户插话和回答后thinking，不将它们合并统计。
3. 固定种子分层导出不少于60个不同用户轮供语义复核，覆盖语法未完、句子完整仍续说、列举/自我修正、真正轮末，以及有/无句读视图；报告各类实际数量。缺失类别记为覆盖缺口，不能由随机停顿数量推断已经覆盖。
4. 检查轮内停顿保持talking且无回答正文、真正轮末下一no-voice拍才finish并启动回答、插话消费与单片段插话边界；检查三视图共用计划和监督mask，不重复监督、不引入未来文本。
5. 产出`reports/layer1_training/<run_id>/README.md`和紧凑统计/样例索引，明确机器检查、语义复核、未核查项及074需要补足的覆盖。原始全文与事件留远端。
6. 对已存EN160轨迹按独立音频及重复运行分别报告句读分布、增量与累计文本差异；比较当前T2、原样和候选“保留内部句读、移除长轮末尾点号”文本的适配差距。候选规则不能逐micro-turn删尾部标点，不能人工给ASR补点，不能把书面原文删尾点等同真实ASR复现。

本单先审计；需要改变数据生成行为时，先在074中记录规则及原因，再修改实现与对应`docs/scripts/training/`说明。自动导出不等于人工复核通过，历史人审例外不自动继承。

## 完成结果

[最终报告](../../../reports/layer1_training/issue073-surface-audit-20261021-r2/README.md)及摘要已回收校验。原train有2949/3828个用户长轮含内部句读，当前T2全部删除；实际EN160有122/200次在线文本含内部句读，只有1/200以末尾点号结束。train随机停顿4318次/12826拍，其中161次在句末符号后仍续说，119次在分句符号后，175次为词内分片。

60个不同用户轮完成代理局部阅读，四层各15条：完整句后续说候选14/15成立，1条为缩写；列举/修正候选仅3/15局部可确认顺序或列表，本批未确认口语自我修正。人工签署不冒称通过。074接收ASR视图建议、轮末问号/感叹号待核项和新增语义覆盖要求。

本地/远端各4项回归通过。r1因将仅EOF后出文本的有效轨迹误作异常退出1，保留失败记录；修复后独立r2全量重跑退出0，约86.3秒、RSS峰值511.7MiB、输出约197KiB。源数据及1k训练索引身份不变；审计完成不等于数据训练放行或FDB能力提升已验证。
