## 目标

在独立数据及相同输入协议下判断训练是否有收益，重点检验陈述句接话与误抢话、误停、延迟之间的权衡。

## 工作内容

- 在候选、工作点和评分协议冻结后评测独立测试，比较官方文本基线、扩展输入的未训练 PT 及同协议下的训练候选；各自保留默认决策和开发集校准结果，避免混淆输入、触发与训练收益。
- 按 XTX-010 合同执行离线快照与真实时钟的因果影子回放：只输入当时可见 ASR、VAD 与外部状态，固定并记录状态来源，动作不切断后续录音或实际执行播放。
- 分别报告完整陈述、问题/请求、上下文回答、句内停顿和继续列举、用户附和及真实打断；同时给四类动作、计划分母、失败、未尝试、覆盖与条件延迟 P50/P95。
- 按事件归并提前、有效、迟到和未触发；按原对话/场景配对比较并给置信区间，不用重复快照制造显著性。训练前后延迟采用相同硬件、精度和调度条件；共卡时记录排队。
- 在已冻结误抢话、误停及延迟预算下给出改善、回归或证据不足的判断。只提高 start 比例、只在参考转写改善或样本不足不算有效。
- 若无可用候选，独立测试不得充作新的开发集；保留可执行基线及候选未尝试原因，写明无法判断训练收益。若有声学歧义证据，可提出是否需要音频底座诊断的结论，但不自动启动替换、部署或新训练。

## 验收

- [ ] 基线、候选和校准工作点固定，独立测试未被用于再次调参或重选种子。
- [ ] 训练收益与新增观测、触发、精度及硬件差异分别说明。
- [ ] 四类动作、关键负例、全部分母、失败及 null 完整保留，原始记录可重算。
- [ ] 独立数据效果与不确定性如实报告，控制动作延迟不冒充可听接话或停播延迟。
- [ ] 报告明确继续 XTurnix 适配、补充证据或停止扩大训练的理由；前序失败也有完整结论。
- [ ] 结果与清理证据齐备，立即归档本工作单并同步组内、全局入口状态。
