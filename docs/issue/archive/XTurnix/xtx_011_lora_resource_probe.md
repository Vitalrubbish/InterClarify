# XTX-011：实现 LoRA 训练入口并完成单卡资源探针

## 目标

确认动作监督、梯度、保存重载及资源边界实际可用，为受限试训提供可运行的远端入口。

## 工作内容

- 基于冻结 PT 与 XTX-008 扩展输入实现 LoRA SFT，冻结底座，只在当前动作 token 位置计算下一 token 词表交叉熵；历史、外部观测、模板、padding 均屏蔽损失，不训练回答正文。
- 核验训练和推理前缀、目标 token 位置、causal shift、合法动作 ID 及实际可训练参数；用可人工检查的少量样本确认梯度进入 LoRA，避免通用 SFT 默认监督全部历史助手消息。
- 起点沿用方案中的一个配置：r=16、alpha=32、dropout=0.05，注意力 q/k/v/o 投影，学习率 5e-5、micro-batch=1、梯度累积 16；核验后使用 BF16、梯度检查点并关闭训练 KV cache。不自动搜索超参数。
- 在远端单 GPU 调度作业内逐步测量 512、1,024、2,048 token 的峰值 allocated/reserved、GPU 总占用、RSS、步耗时和保存成本；用训练集极少量明确样本检查损失及目标分数变化。
- 实现启动预检、超时、磁盘与资源停止、独立 run_id、退出码和自建进程清理；只清理本次作业的服务，不停止其他现役作业。训练不与同卡 ASR/基线推理并行。
- 保存 adapter、底座引用、完整配置与必要状态，完成一次重载和动作分数核对；实测后估算完整试训耗时及空间，超预算停止并记录。

## 交付

拟新增 `scripts/remote/train_xturnix_control.py`、`scripts/remote/run_xturnix_training_job.sh`、`scripts/remote/submit_xturnix_training_job.sh`，分别在 `docs/scripts/remote/` 提供同名中文说明。产出训练机制核对、资源探针、重载一致性与启动/失败路径报告。

必要测试聚焦目标损失掩码、前缀一致性和有界失败路径；不大量编写镜像实现的测试，每个测试文件配套同路径中文说明。

## 验收

- [ ] 唯一监督位置、动作 ID 与因果移位正确，底座冻结且 LoRA 梯度非空。
- [ ] 少量明确样本能够优化，且没有把机制检查冒充泛化成绩。
- [ ] 实测达到计划最大长度或明确停止原因，无静默截断与自动扩容。
- [ ] 保存与重载后动作分数一致性达到预先说明的数值容差。
- [ ] 资源上限和失败路径可执行，完整试训估算未超累计预算。
- [ ] 入口、配置、必要测试及对应说明齐备，验收后立即归档。
