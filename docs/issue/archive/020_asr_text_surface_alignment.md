# Issue 020：用户微轮与 Nemotron 文本表面形式对齐

状态：完成（核验结束；数据修订由021继续跟踪）。父任务：[004](../004_training_data_and_annotation.md)。用户已审阅 r4 前32条、未发现明显事件错误，要求进一步确认缩写跨拍、大小写及数字/时间/日期写法是否与当前 ASR 一致；这些问题核实前不把 004 记为最终人工通过。

## 只读发现

DuplexCascade 论文只公开“用户片段随机 1–7 token”，没有公开完整生成器或说明是否保护缩写内部边界。本项目使用发布的 Qwen tokenizer 字符 offset 直接切分：`don't` 为 `don` 与 `'t` 两个 token，随机边界可能落在中间；r4 全量1500条计划中4185个英文缩写跨度有996个被切开。不能称这种处理已与作者逐样本一致。

当前 Nemotron EN160 服务把发布 decoder 的文本原样提交，未统一小写或执行 ITN。远端冻结的100条 FLEURS 录音、两次重复共200条最终轨迹：200/200含大写字母，0/200含阿拉伯数字，58/200含常见英文数词；5424次词内逐步增量，所检缩写撇号后缀跨 ASR 更新为0次。具体录音中参考文本 `2002` 输出 `two thousand two`，`06:30`/`07:30` 输出 `six thirty`/`seven thirty`。r4 有82503个有来源用户片段，其中3432个含数字；5655个原用户长轮中534个含数字，2548个数字跨度中894个被跨拍切开。模型词表仍含0–9，故上述小样本不能证明所有数字场景都输出英文单词。完整统计与样本路径另记报告。
