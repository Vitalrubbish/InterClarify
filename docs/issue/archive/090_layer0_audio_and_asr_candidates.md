# 090：Layer 0 音频模型与 ASR 标点依赖调研

状态：已完成并归档，2026-10-22。

## 用户指令与目标

用户指出文本话轮预测可能依赖转写标点及其出现时刻，要求查找直接由音频产生状态的 ASR/预测器，以及采用其他 ASR 转写的文本预测器。核查作者论文、权重与推理代码，区分已证实事实、候选能力和待实验假设。

## 工作与交付

- 核查 SoulX-Duplug、X2-Turn、Easy Turn 等音频输入候选的状态输出、参数规模、流式时序与文本依赖。
- 核查 FireRedChat 等文本预测器的上游 ASR 和标点处理，不把换 ASR 自动视为消除依赖。
- 更新工程计划及 084 的候选优先级、原生状态协议和标点敏感性对照设计。

## 验收边界

本单只调研和调整计划，不下载完整权重、不执行推理或集群测试。候选原生状态可由唯一仲裁器直接解释；不为 token 拼写差异强制训练。研究边界与已听内容不可撤销原则保持。

## 完成结果

已核查 X2-Turn 的并行 ASR/状态头与延迟口径、SoulX 的外部 SenseVoice/Paraformer 指导及去标点代码、Easy Turn 音频转写后生成状态的分段方案、TEN + Paraformer 的公开评测和 FireRedChat + FireRedASR 的系统协议。补充记录 XTurnix 已有末尾去标点处理，未将用户的影响幅度假设写成实测结论。
