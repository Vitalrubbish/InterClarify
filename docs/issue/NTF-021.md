# NTF-021：原生教师协议、训练时标与对照合同核查

日期：2026-11-02。状态：待调研。依赖：无。本轮仅按用户指令建单。

## 目标

从重新克隆的官方源码核查SenseVoice教师的完整职责，区分ASR替换与控制器协议改造，冻结后续可复现对照。范围见[调研方案](../dev/SoulX-Duplug/asr_teacher_diagnosis.md)，前序工作见[归档记录](../reports/soulx/20261102-frontend-plan-archive/README.md)。

## 工作范围

1. 固定官方子模块`a0b9063843df69619b087b95b74597b2176910b8`、核心文件摘要、SoulX／SenseVoice权重、英文配置与conda版本；X2沿用[锁定配置](../../configs/x2_streaming_probe.json)。重新clone不作为行为修复证据。
2. 沿`infer`、`_asr`、`_state_predict`、服务完成分支和`reset`列出调用顺序，核查文字门控、窗口输入、归一化、差分、检查点修订、空步规则、状态反馈、整轮识别和缓存生命周期。
3. 核对官方论文、公开训练／数据处理代码的音频—文字—状态分块合同，尤其词的归块与英文声学对齐。逐项区分公开事实、源码推断、现有实验和缺失资料；未公开的细节保留未知。
4. 冻结原FDB30文件摘要与方案列出的6条小样本、波形转换、增益／量化、padding、时钟、预热、EOF及评分定义；r6与原生SenseVoice均不作为状态或语义对齐真值。
5. 定义只读采集点与插桩等价性检查，冻结NTF-022／023的有限实验矩阵、作业数及总资源预算，列出最小教师适配的待定职责。

## 交付与验收

- 一份中文协议对照表，注明源码位置、官方来源、历史改动和证据缺口。
- 可执行的输入／采集／评价合同；词声学位置、ASR输出、教师消费、实际返回与原始／改写状态有独立字段定义。
- 后续能判断一次改动是否涉及门控、修订或reset，而非只按ASR名称分类。
- 未取得训练时标合同也可完成调研，但必须明确其对结论的限制，不伪造对齐要求。

## 执行边界

本单为源码与资料核查，不启动GPU、不修改模型或原生推理行为。若新增采集实现，另随对应实施工作单同步docs同路径说明。本单完成后立即归档，再进入[NTF-022](NTF-022.md)。
