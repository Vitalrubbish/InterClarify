## 目标

训练模型适应无标点及真实流式 ASR，同时保留等待、附和与打断能力。数据必须区分“完整文字的合成 micro-turn”与“真实 Nemotron 在线轨迹”，不将前者冒充后者。

- [ ] 先交付最小审计集供 005 短跑，再按预登记规模扩充。通用对话覆盖基础控制，日程日期/时间样本补足目标域，防止只会确认时间。
- [ ] 按原始对话与说话人划分 train/dev/test，记录清单和哈希；同录音、同模板近重复及增强版本保持同组。完整 FDB、已有五例、FLEURS 100 条不得用于训练或 checkpoint 选择。
- [ ] 保存来源、音频、真实增量与到达时刻、micro-turn 可见前缀、控制目标、assistant 正文/IDs、边界不确定区间及审查状态。
