# NTF-017：正文与状态独立更新的 SharedContext

日期：2026-11-02。状态：待实施。依赖：[NTF-015](NTF-015.md)、[NTF-016](NTF-016.md)。

## 目标与合同变更

以两路各自就绪的时刻更新Context，替代历史“对应音频块配齐后联合发布”。保留单份当前全文／状态和原子读取，不恢复正文历史、patch、版本查询或complete锁存。字段及边界见[设计第3／4节](../dev/SoulX-Duplug/independent_streaming_frontend.md)。

## 工作范围

1. 为正文和状态提供独立字段更新入口，在锁内读取最新记录并只合并本路字段，避免旧快照覆盖另一路新结果；推理、网络和落盘不持锁。
2. 分别保存正文与状态的真实观察上界、实际可用时间和发布时间。旧processed_until若保留，只指SoulX主块截止，正文更新不要求它增长。
3. 保留稳定session_id／turn_id与单一Nemotron正文来源；状态尚未到达可为未初始化，正文尚未到达可为空，不能伪造配齐。
4. SoulX内部reset只更新控制代次，不清空正文、不创建新逻辑话轮。显式关闭后拒绝迟到结果，EOF和drain文字单列诊断。
5. 有效nonidle仍直接走唯一停止钩子；普通正式回答仍由Layer 1实际读到当前turn有效complete后生成，本单不接下游模型或增加尾词等待门。

## 验收标准

- 必要检查覆盖正文先到、状态先到、状态连续变化但无新字、文字更新时状态不变，以及两线程交错写入无丢失更新。
- 每组时间／采样位置只由所属路推进；原子快照允许两路进度不同，不冒充同块对齐或尾词完整。
- 空结果、识别异常和reset不意外清空正文；关闭后两路回调均不能重开或修改话轮。
- 读取返回副本；同一话轮仍只有一份当前值，覆盖不重复触发直接停止，不增加历史事件投递承诺。
- 同步更新SharedContext实现、受影响调用方、必要测试的docs同路径说明，以及[接口合同](../dev/SoulX-Duplug/shared_context_interface.md)的实现状态。
- 同步架构图前端部分及绘图说明，明确内部SenseVoice教师和外部Nemotron正文的独立用途；保留下游模块分工。

## 执行边界

本地conda运行有针对性的并发／生命周期契约检查；不启动GPU作业。当前值容量沿用既有限额，不通过无界快照队列解决并发。
