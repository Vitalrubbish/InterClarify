# NTF-007：Nemotron 教师文本路径的 append-only 化

日期：2026-11-01。状态：本地实现完成，远端单例验证待执行。

工作单元：把教师文本路径从“每步重分词整段前缀 + KV 检查点重放”改为“片段直提 + 尾部重编码”，删除门控与修订机制，使文本序列严格单调追加。本单不涉及音频缓冲、序列排列、发布路径与训练。

## 背景与证据

`reports/soulx/20261031-nemotron-teacher-gate/README.md`（NTF-004）：

- 25/30 完整，5 条触及 800ms 音频积压线，退出码 1；
- 785/2706 帧开门（29.0%），716 帧存在“已产生但未消费”的新增或修订文本；
- 完整样本实际触发 50 次最近片段检查点重算，累计 947 token、约 1.96 秒，单次中位 37.6ms、P95 46.4ms；
- EOF 仍有 6/25 条存在未消费尾部，最长已等待 14.64 秒、连续 92 帧。

`reports/soulx/20261031-dual-asr-publication/README.md`（NTF-005）的分段耗时说明这些等待不是 ASR 算力：

| 环节 | 中位 | P95 | 最大 |
| --- | ---: | ---: | ---: |
| Nemotron 单步计算 | 23.8ms | 73.1ms | 615.4ms |
| SenseVoice 单次调用 | 33.6ms | 131.7ms | 1303.3ms |
| SoulX 整步计算 | 56.5ms | 174.4ms | 1361.0ms |

Nemotron 解码单调，不回头改写已发出的词。NTF-004 实现中的“修订”来自两个工程选择：每步对整个规范化控制前缀重新分词，以及门控关门后前缀被重新归一化。RNNT 词内片段合并只影响最后一个未完成词。因此修订范围可以收窄到尾部，历史 token 不需要重放。

## 范围

### 本单包含

1. 删除 `scripts/runtime/nemotron_teacher_frontend.py` 的 `_revise()`、KV 深拷贝检查点、有界输入 embedding 账本，以及累计序列 8192／修订 128 次／累计重放 65536 token 三项上限。
2. 文本编码改为增量：维护稳定边界游标，只对最后一个未完成词重编码；已写入的 token 不可变。
3. 删除门控：教师文本到达即注入，不再由模型 `argmax != EOS` 决定是否开门。
4. 新增审计字段：`text_commit_index`、`tail_reencode_count`、`tail_replace_tokens`、`text_injected_tokens`。
5. 保留：真实音频覆盖配对（本单起作为正式配对规则，不再仅作审计）、首块 92.5ms 单独释放、空增量规则、`observe_state` 状态规则层、`_reset_controller`、音频回看与 40ms 前瞻。
6. 本地回归与远端单例验证。

### 本单不包含

- 单块音频缓冲、序列排列与发布路径改造（NTF-008）。
- 调度与分卡（用户已确认只测同卡）。
- `max_wait_num`、`max_mistake_num`、`far_field_threshold` 的数值调整。
- `_reset_controller()` 的 buffer 保留策略与输入增益。
- 任何训练、权重更新或数据构造。

## 接口与数据合同

- 文本注入是纯追加：同一 token 位置一旦写入 KV 不再改写。
- 跨步词片段按新增字符增量编码；同一词分多步到达时的token序列可能不等于整词一次性分词，这是避免重放的已知代价。
- `text_commit_index` 单调递增，不允许回退。
- `tail_replace_tokens` 只统计本步追加在序列末尾、属于未完成尾词的token；范围不落在末尾即为实现错误，不回写历史位置。
- 文本来源仍为 Nemotron，正文仍发布到 SharedContext；本单不改变正文语义。
- 门控删除后，教师文本注入率应接近 100%，但空文本块仍保持为空，不插入占位文字。

## 验收标准

1. 现有本地测试全部通过。
2. 新增用例覆盖：词内片段合并只改尾部、历史 token 逐字节不变、全程无 KV 重放调用、`tail_replace_tokens` 越界报错。
3. 远端单例回放中，提交文本序列与 Nemotron 原始增量逐词一致，无跳词、无重复。
4. 非空文本块的教师注入率为 100%。
5. 单步失败保留原始证据，不静默丢弃。
6. `docs/scripts/runtime/nemotron_teacher_frontend.md` 与 `docs/dev/SoulX-Duplug/nemotron_teacher_forcing.md` 已同步改写。
