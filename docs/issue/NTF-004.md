## 实现范围

| 部分 | 本对照约定 |
| --- | --- |
| ASR | Nemotron 为唯一权威来源，保留原生RNNT缓存；不加载SenseVoice，不做3.2秒音频滑窗重识别或完成时整段重识别 |
| 音频 | 保留SoulX 160ms主块、原生回看及40ms前瞻；沿用NTF-003启动块和真实覆盖配对，不回退为相同步号配对 |
| 控制文字 | 按冻结官方函数恢复去标点、文本归一化、英文分隔及去前导附和处理；仅作用于0.6B输入，不修改SharedContext正文，不额外添加自定义清洗 |
| 文字门控 | 先以历史状态和当前音频前向，argmax为ASR结束符时关闭文字消费，否则开启；门控预测的普通文字token只作判断，不写KV、不继续自由生成 |
| 状态输入 | 开门时注入当前可用教师文字的待消费部分，再输入官方ASR结束符预测状态；关门时不消费教师正文，仍输入结束符预测状态。任务提示、结构token和状态token顺序按官方核查 |
| SharedContext | 每步联合覆盖Nemotron原始累计正文及本块状态，不等门控开启才更新正文，不用归一化控制文字覆盖原始正文 |

正常顺序：本步Nemotron真正完成 → SoulX音频及门控前向 → 必要的教师缓存修订／文字输入 → ASR结束符与状态预测 → 联合发布 → 释放下一步解码。音频接收持续进行，不引入推测执行。

取消官方随ASR滑窗移走旧词的文本裁剪。控制文字按当前controller generation教师片段维护，旧内容保留在已消费KV中，不能每步重新追加全话轮前缀。原始字符只追加，也可能因归一化和分词改变末尾token，原始字符游标不能代替控制token游标。

## 门控、缓存与 reset 边界

1. 门控关闭时，教师新增及修订保留为待消费，下一次开启时按当时已完成的Nemotron前缀处理，不丢弃、不重复注入。未完成、已完成无新字、门控未消费分别审计。
2. 修订已消费控制token时，从最早不同位置前的有效KV检查点重算受影响序列，不能只替换字符串。优先复用官方上一片段修订顺序，超出范围需有界重建并说明差异；检查点不能只是会被后续前向原地修改的缓存引用。
3. 历史已发布状态作为实际输入历史保留，重算不重新发布旧状态、不追溯执行控制或撤销已听内容；新状态只由当前步产生。
4. 为分离变量，沿用`98f347e`的soft reset：保留本逻辑话轮KV和教师进度，只重置既定计数及发声标志，不同时改成官方硬reset。本单的“恢复官方”限于控制格式、门控及相关输入顺序，不宣称完整官方运行时等价；硬reset对照另行设计。
5. 连续空增量nonidle规则、nonidle→idle规则、阈值、远场过滤及有效状态反馈保持。空增量计数使用本步实际控制delta；门控可能改变触发分布，需原样报告。状态位置的普通文字／未知token仍无效，不自由生成凑状态。

SharedContext正文允许领先控制器实际消费正文。审计同时保存原始教师截止、规范化控制文字、已消费／待消费token范围和门控结果，不能把最新SharedContext全文当作本步输入。EOF仍有待消费文字时如实报告，不强开门控、补静音、额外前向或回填；在线／排空分离。沿用8192序列token上限，缓存重建设明确上限，触限失败，不临时扩容。
