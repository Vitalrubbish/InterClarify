## 后续与管理约定

Layer 1／2 接入、SoulX 结果条件化控制、详细训练和 benchmark 继续按用户后续明确指令推进，不把已有设计记作实现完成。

所有工作单仅由来自用户的明确指令建立，按工作单元拆分，交付满足验收后立即归档并更新索引。真实模型训练和集群测试使用远端 conda 调度作业，明确并发、内存、磁盘及时限；代码同步维护 `docs` 下同路径中文说明。

本地归档不纳入 Git，不创建指向不存在归档文件的公开链接。
