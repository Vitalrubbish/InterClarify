# Issue 006：执行三组有限话轮控制适配

状态：待办。优先级：P0。依赖：002、004、005；配置与评价门槛须先冻结。

## 实验目标

检验从官方权重继续训练能否改善 Nemotron EN 160ms 下的接话，并保留停顿等待、用户附和、有效插话及回答能力。降低句读依赖是待验证假设，不把模型训练成遇到空窗就回答。

| 条件 | 输入 | 作用 |
| --- | --- | --- |
| B0 | 未训练的完整官方权重 | 固定基线 |
| T1 | 原样继续训练 | 控制继续训练/新数据影响 |
| T2 | 用户侧去普通句读 | 检查无标点适配 |
| T3 | 原样和去句读混合增强 | 检查两类输入的鲁棒性 |

## 工作项

- [ ] 三训练组共用完整官方初始化、原始数据切分、监督目标、优化器设置和可比预算；记录有效 tokens 与采样差异，混合增强不能无说明地翻倍训练量。
- [ ] 首轮冻结 ASR/TTS、基础模型、embedding/head，只更新现有 q/v LoRA；不新增控制 token 或系统附和标签。
- [ ] 使用真实在线轨迹与经标记的合成样本；增强只改用户普通句读，不删除时间/小数、词内字符或 assistant 标点。
- [ ] 定期仅在 dev 上观察控制和质量指标，checkpoint 选择依据预登记综合约束，不能只用最低训练 loss 或最高接话覆盖。
- [ ] 远端作业按调度配额分片，记录种子、预算、step、有效 tokens、峰值资源、退出码、checkpoint 摘要和异常；不人为占用 GPU 规避调度回收。
- [ ] 第一轮结果后只允许一次有误差证据的调整，最多两轮。任何解冻 embedding/head 或调整交付契约都须先更新文档，并作为新条件而非悄悄替换原对照。

## 测试与完成条件

- [ ] B0/T1/T2/T3 的 dev 自由回放与原样/无标点条件齐全，所有模型生成自己的历史。
- [ ] 接话改善同时满足 007 的误抢话、附和误停、有效插话、内容质量和协议门槛；报告失败与权衡。
- [ ] 两轮均无稳定收益时停止扩训，交付原因分析和 revise/stop 决策，不擅自换 ASR、重训基础模型或进入 Layer 2。
