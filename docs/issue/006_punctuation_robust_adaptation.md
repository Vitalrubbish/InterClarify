## 实验目标

检验从官方权重继续训练能否改善 Nemotron EN 160ms 下的接话，并保留停顿等待、用户附和、有效插话及回答能力。降低句读依赖是待验证假设，不把模型训练成遇到空窗就回答。

| 条件 | 输入 | 作用 |
| --- | --- | --- |
| B0 | 未训练的完整官方权重 | 固定基线 |
| T1 | 原样继续训练 | 控制继续训练/新数据影响 |
| T2 | 用户侧去普通句读 | 检查无标点适配 |
| T3 | 原样和去句读混合增强 | 检查两类输入的鲁棒性 |

## 首轮执行设置

所有训练臂必须从完整官方 DuplexCascade checkpoint 出发，在 004 自行实现的管线所生成的 UltraChat micro-turn 上继续训练，不增加从 Qwen2 原始模型重训的实验臂。T3 是用户提出的主候选：按原始对话每个 epoch 固定种子平衡分配 50% 保留用户普通句读、50% 去句读，assistant 及控制监督保持完整。同一基础事件轨迹的 T1/T2/T3 只改变用户句读视图，先固定事件与分拍，再增强。

r5共同前处理：用户长轮的数字、日期、时间、金额等先转换为确定性英文读法并保留映射，再分拍及增强；T1原样指该共同规范化之后保留句读的版本。三臂使用同一前处理，不将数字形式变化混入句读对照。对歧义或暂不支持的数值上下文按004预登记规则排除，保留计数。assistant正文不变。用户明确免除r5人工复审，004关闭以全量机器验收和显式豁免记录为准；005/007不随之自动放行。

首轮使用004的1,000条训练对话、1epoch。005已冻结单张4090、训练窗口512、batch1/累积2；按既定事件计划重分窗后三臂各11,526序列、1,193,875监督token、5,763步。监督目标不减少，历史可见范围缩短，需在dev评估影响，不把短跑协议通过当质量通过。训练循环估计0.93GPU小时/臂，保留8小时上限；正式优化器/scheduler及保存频率仍需开训前登记。

后续[026持续测试](../../reports/layer1_training/issue026-2048-20261020/README.md)已在单张4090、2048窗口、batch1/累积2完成100步/200序列且未OOM，含183个≥2000和4个满2048序列。2048具备实测可训练性，005的512是保守选择，不能当单卡硬上限。当前仍保留512登记；若正式切换2048，先更新三臂完整索引、实际步数与预算，再训练，不沿用512的5,763步。

32/100条是管线和资源短跑候选池，有限步实际曝光数另见005报告。首轮不需要等待ASR适配器完成；候选只有通过002提供的真实Nemotron轨迹评测后才可通过007。若有稳定收益且补充数据有明确用途，第二轮可扩至最多3,000条；约2.84GPU小时/臂为密度估算，数据及精确步数未冻结，保留16小时上限，不无依据扩大至论文50k。
