# NTF-016：同源音频分发与独立原生流式转写

日期：2026-11-02。状态：待实施。依赖：[NTF-015](NTF-015.md)的控制输入合同。

## 目标

同一持续音频分别驱动SoulX原生控制和Nemotron原生流式解码。Nemotron仅提供SharedContext正文，不受SoulX的文字门控、complete或reset影响。合同见[独立流式前端](../dev/SoulX-Duplug/independent_streaming_frontend.md)。

## 工作范围

1. 建立16kHz单声道PCM统一采样账本和两路有界输入，各路串行消费；冻结转换、增益、传输包与实际模型窗口边界。一路未就绪不阻塞另一路的正常计算。
2. 复用已锁定Nemotron EN0.6B revision、FP32、lookahead 1、160ms新增音频与原生缓存；核验模型和依赖，不下载新候选或恢复comparison旧入口。
3. 持续交付原始累计正文与结果实际可用时间、真实音频观察范围，保留词内增量，不自行插空格或等待整词／标点／整轮。已解码但无新增文字与尚未完成解码分别记录。
4. 输入EOF、关闭、取消与SoulX内部reset分别管理。complete不结束ASR，不触发额外整段正文识别；不将无新增token解释为静音或尾词已齐。
5. 任一路出错或触及有界输入上限时显式停止样本并保存两路进度，不静默丢帧、切换正文来源或降低真实送音速度。

## 交付与验收

- 提供音频分发／独立ASR适配与本地必要契约检查，docs按实现路径配套说明。
- 检查两路收到的真实PCM摘要与采样区间一致，回看、前瞻和合成padding可区分，不按相同步号假定观察相同。
- 检查两路先后完成、词内增量、空增量、reset后正文连续、取消清理和迟到回调；无跨路计算屏障，无跨路逐块发布配对器。
- ASR有结果时无需等待SoulX即可交付；对外可见的原子更新由[NTF-017](NTF-017.md)完成。尾词信号不明确时标记unknown，不保证转写无错。

## 执行边界

本地使用conda，仅运行轻量契约检查。真实解码、资源和实时性验证统一纳入NTF-018／019，不在本单独立启动远端实验。保持每路未读PCM≤800ms及总PCM≤4MiB，具体停止线按设计执行。
