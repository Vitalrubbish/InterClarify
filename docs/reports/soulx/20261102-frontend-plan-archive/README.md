## 为什么先调研

此前教师实验同时改变文字门控、修订、提交节奏和reset，主要对照是X2与Nemotron r6，没有同条件SenseVoice基线。最终转写准确率、规范分词和音频覆盖审计不足以单独证明冻结状态模型对新输入轨迹兼容。空步规则也在SenseVoice路径实际触发，不能直接认定它是X2相对SenseVoice退化的主因，详见[归因记录](../20261101-ntf012-x2-teacher-fdb30/regression_analysis.md)。

新建[NTF-021—025](../../../issue/README.md)，依次完成原生协议／训练时标核查、同音频词级时间轴、最小教师替换、单因素归因和固定FDB30复核。调研合同见[方案](../../../dev/SoulX-Duplug/asr_teacher_diagnosis.md)。
