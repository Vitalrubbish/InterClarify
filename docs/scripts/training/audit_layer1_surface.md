# 训练数据句读、停顿与ASR表面审计

`scripts/training/audit_layer1_surface.py`为Issue 073只读审计入口，无业务类。它不改数据、tokenizer或模型，不生成训练授权。

`audit_dataset`先复用现有完整机器审计，重新验证原始对话、事件、三视图序列、mask与无重复监督；再逐产物核对摘要，按split统计原样与T2用户长轮的内部/末尾句读、停顿次数/拍数/时长和上下文边界，核验当前训练索引的train身份、序列数与有效token。`boundary_kind`仅用字符位置区分句末符号、分句符号、词内分片及其他位置，不判断真实语义完成。

`select_cards`固定种子分层选取60个不同用户轮，覆盖词内边界、句末符号后仍续说、列举/修正线索及真正轮末，保存原样/T2前缀、后续文本和事件身份。类别均为启发式候选，实际语义需要阅读复核；人工状态始终独立，不自动填通过。

`audit_asr`只读取明确指定目录内的历史EN160轨迹，区分EOF前最后累计文本、EOF后文本与每次增量，按重复运行和独立音频分别统计各类内部/末尾标点；摘要记录每个输入文件SHA256及失败/覆盖数。它不运行模型，不估计新的流式时延，也不把重复录音计作新的独立样本。

输出包括`summary.json`、`machine_audit.json`、`input_files.json`和`review_cards.json`。`main`拒绝已有输出目录，核对既有审计与manifest摘要，执行中检查输出2GiB/空闲盘10GiB上限，异常非零退出并保留失败状态。候选文本比较仅为统计，不写回数据。资源限制与远端任务入口见[任务说明](../remote/run_layer1_surface_audit.md)。
