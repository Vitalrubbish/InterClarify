# TextTurn因果输入映射

`textturn_input.py`提供新版`model_visible`和`render_prompt`纯函数，无类。只投影历史角色和文本、当前用户前缀／增量、真实更新类型、Listen／Speak、准备／播放阶段、生成／播放前缀、生成完成、实际空观察数、关闭类型和因果顺序。运行时输出ID、版本和时间戳不进入模型。旧合同维持原有编码，新合同显式选择`textturn-causal-v2`，训练和控制服务共用同一映射。

用户末尾句读在映射中去除，原始发布类型在去句读前确定，因此纯标点更新仍是text-update。关闭事件保留finish专用输入标记，不预测finish。映射不推断未来完成、计划阶段或语义弱标签。
