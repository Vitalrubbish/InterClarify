# 第二轮FDB结果汇总

`scripts/training/summarize_layer1_fdb.py`只读汇总037现有驱动产物，不调用模型、ASR或评分器。无类；`collect`核验25份报告、原始标注及候选健康身份，读取timeline中的控制与最后模型前缀，按response ID关联的现有客户端标注后播放时延统计新响应。`main`输出逐例JSON、子集计数及与034旧T2的同口径比较。

失败、静默、缺失报告和协议错误均保留；原窗口与5秒诊断尾窗分开。正文与音频路径仅供人工复核，不自动判断相关性。复用`diagnose_layer1_fdb`的词对齐及聚合方法，20例参考词差异和5例无参考状态分别报告。官方输出对齐/评分及人工检查仍pending。

验证时先用首轮真实T2结果重算，与034冻结的子集计数、控制总量、词编辑数逐项核对；这检验汇总口径，不额外运行GPU测试。远端只读分析使用单CPU、2GiB地址空间上限及120秒超时，输出拒绝覆盖，大音频仍留远端。

finish无正文按控制出现后、下一请求首token之前是否出现正文TTS追加事件统计；不把控制解析事件自身的空text当作空回答。该指标表示该片段未交付正文，不代替回答内容人工判断。

最终ASR取timeline最后的partial/final事件；FDB流式会话的顶层`asr_final`可为空，不把该空值误当识别失败。
