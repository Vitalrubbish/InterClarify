# 用户数值英文读法

`scripts/training/number_surface.py` 用标准库将完整用户长轮的书面数值转换为英文读法，不处理assistant正文。`normalize_user_text`返回原文、转换文本、版本和逐段原始/规范化跨度；`validate_surface`核验替换映射连续可重建且无残留阿拉伯数字。无业务类。

核心方法`cardinal`、`ordinal`、`year_words`分别生成基数、序数和上下文年份；日期用datetime校验、时间用合法范围校验，金额保留币种和分位，小数保留每位数字，电话/前导零按位。优先识别完整日期、时刻和电话，再处理普通数字。无法判别月日顺序的斜杠日期以及带数值的URL/代码/科学计数法/版本/标识触发ValueError，由来源过滤记录原因并排除整条对话。

这些规则为可追溯的合成数据近似，不保证复现每个说话人的读法或每次ASR输出；原始数字和替换跨度始终保留。规则变更必须改变版本并重建冻结数据。

数值区间仅在pages/from/between或明确时间/数量单位上下文转换为to；可能是减法的裸连字符表达式、分数和未支持公式排除，避免改变问题含义。
