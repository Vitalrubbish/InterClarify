# 串行训练短跑调度

`scripts/training/run_layer1_probe.py`在单个已分配GPU作业内串行启动独立Python进程。无类，`main`依次执行训练契约测试、32条连续/中断/恢复及严格比较，再执行100条五档窗口资源测试。每段由`timeout`限时；`run`通过wait4记录当前子进程RSS、CPU时间、墙钟和退出码，写phases.json。不得同时提交多份本任务。

32条任一失败立即停止；资源档仅对明确CUDA OOM继续下一档，其他失败停止并保留证据。资源报告在至少2GiB显存余量的成功档中选择最大窗口，再只读索引完整1,000条、三臂训练序列，冻结精确步数；按实测步耗时估计训练GPU小时。3,000条尚未构建，只有密度估算，不能当实际交付。以上结果不自动放行006。

余量使用GPU预检查得到的实际`total_memory`减去2GiB，不能假设标称24GB全部可用。r1冻结脚本原先用22GiB阈值，复核最终结果时须按实际容量重算；如窗口选择受影响，仅重做所选窗口全量索引，无需重复有效的训练测量。
