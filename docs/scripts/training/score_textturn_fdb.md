# FDB ASR更新边界离线评分

对应 `scripts/training/score_textturn_fdb.py`，仅依赖标准库，不加载模型。服务停止后执行，固定正式50＋50分母；缺失trace仍输出全部100条。

模块无类。`score_case`按Shared Context最后一次实际非空转写变化确定边界，重复文本和EOF转写不移动边界。Speak按完整控制周期的动作应用后状态时刻归属；start按HTTP完整返回时刻归属。前者可以命中而后者未命中。

接话分别统计更新后的Speak和start；首次后置start等待拍数为与最后更新的真实时差除480ms，只对命中且计时有效的录音求均值，没有有效样本为null。停顿统计严格早于边界的连续至少3个Speak周期；Listen、观察缺口和合并前缺失的周期中断序列，合并请求只贡献一个实际观察，EOF残窗不计完整周期。

`proportion`保留命中、已确认未命中和未知，输出50条计划分母的保守上下界，以及可判定分母上的Wilson95%区间。无有效ASR、运行失败和关键trace缺失为未知；不填正常未命中。

`interval_evidence`保留全部Pause标注区间的名义音频观察覆盖、ASR前缀及动作供辅助解释，不自动标成语义错误。`run`输出逐录音CSV、汇总JSON、逐区间JSON及中文说明。汇总包含控制就绪至返回P95、聚合等待；逐例保留合并、状态转移和EOF情况。不称实际开口延迟或官方TOR。

TT-007由清单`control_ms`选择160ms或默认480ms：完整周期分别需要1或3个真实步骤，覆盖核对和合并缺口按相应单位计数。`score_case`同时保存`start_wait_ms`和对应拍数，summary列控制周期、3周期名义时长、等待毫秒均值与拍数均值；检测case_start周期不一致时标未知。160ms下3周期是480ms，不能与480ms基线的1440ms门槛视为等时长。旧trace缺周期字段时仅按默认480ms解释。
