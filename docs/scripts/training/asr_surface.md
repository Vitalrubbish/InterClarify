# 延后句读ASR视图

`scripts/training/asr_surface.py`提供无模型的流式视图构造与独立来源审计，无业务类。`apply_asr_surface`顺序扫描源事件，暂存句读及尾随符号，在后续正文可见时释放，生成`user_asr`、源事件字符区间及对话末残留；不改控制/assistant目标，不插入事件。跨用户长轮必要分隔空格明确标为合成字符。

`audit_asr_surface`独立按源字符顺序核验交付/残留守恒、来源不晚于交付拍、文本与映射一致、no-voice不交付暂存句读，检查每拍可见前缀没有提前获得未到达正文才能释放的标点。规则为600ms合成近似，真实ASR精确延迟仍未知。

只有待交付句读或非词字符的源拍可能暂时没有可见文本，单列`sourced_no_voice_events`；若该拍含字母/数字却全不可见则失败。该例外只适用于ASR视图，不放宽原样/去句读检查。
