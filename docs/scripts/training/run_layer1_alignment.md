# 对齐配置的远端验证

`scripts/training/run_layer1_alignment.py`只在远端调度单GPU中串行执行契约测试、真实官方模型连续短跑、独立进程中断/恢复对照及干净进程推理资产重载。无类；`main`负责有界阶段调度、资源记录及汇总，`verify_probe`只核验短跑产物，不能将其升级为正式候选。输出必须新建，逐阶段保存退出码/墙钟/RSS，原始权重和日志留远端。

短跑先连续8步、独立4步后恢复至8步，使用完整T2索引和2048窗口；另运行100步检查warmup期间稳定性。每个训练进程最长900秒、整体3600秒，1×4090/8CPU/32GiB、并发1、worker0。磁盘总上限16GiB、保留15GiB；最终checkpoint及最近恢复状态均保留。报告不宣称FDB能力改善，不提交037正式训练。
