# TextTurn有限pilot训练

`train_textturn_pilot.py`复用固定Qwen3-0.6B加载、LoRA rank16／alpha32、AdamW和完整词表CE。`logical_groups`按同来源同句式合并完整轨迹，每组必须含keep／start／stop；每类先取基础权重加权平均，再各1/3相加。`train_arm`逐快照独立前向及反传，组内不更新，全部反传后统一clip1一次并执行一次AdamW；调度器按真实逻辑组数重算。

先旧pilot优化对照两轮，再新pilot五轮，分别从同基模初始化，每臂最多5轮；不自动full或外部测试。每轮保存与开发评估，记录三类召回、相对keep的margin、有效损失、裁剪前范数和系数。保存重载必须一致。开发按机会给出分子／分母及Wilson95%区间，正例及时覆盖≥80%、负例误动作≤15%、每类≥30机会，控制P95≤500ms；同规则、未见句式与真实回复背景单列。证据不足不放行，1%只作诊断，不创建现役候选。

旧pilot开发诊断使用固定seed选择20个原dev来源，保留其全部窗口；新版开发逐轮覆盖全部200来源，不以抽样探针冒充机会验收。两臂开发规模不同，不称严格单因素比较。
