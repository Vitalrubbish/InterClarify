# TextTurn 独立测试语音素材

对应 `scripts/remote/prepare_textturn_audio.py`，属于TT-004。只读取已冻结test来源及事件计划，使用现有固定Kokoro资产和af_heart离线合成；不从评测内容反向生成训练资料。所有语音明确记为合成，真实人类交互结论不在本轮范围。

`prepare`按source构建三个输入：带不完整前缀停顿的完整问句、完整陈述、短附和、明确打断。问句前缀与后文分别合成，拼接480—1440ms静音；保留原文本、音频摘要、片段边界及原始来源。短模板与前缀音频以文本摘要缓存复用，不增加独立场景数。输出16kHz单声道PCM WAV及manifest，超过资产预算或非空输出明确失败。

语音时序采用实际合成时长，不冒称与1—2 token/窗训练时序相同。来源独立但模板集合与训练相同，报告必须保留此限制。暂停评分只看当时可见的不完整ASR文字，完成锚点由事后参考对齐校验，不能把EOF当完成金标。
