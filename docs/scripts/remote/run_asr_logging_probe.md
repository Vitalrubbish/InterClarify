# run_asr_logging_probe.sh

对首轮异常停顿做配对诊断，不是新的准确率排名。固定七个观察到长停顿的 FLEURS 音频，再按原 manifest 顺序补足十条；保存选择原因与独立 manifest。由同一独占 GPU、同一模型配置依次跑同步日志和解码后写盘两模式，均保留原始事件和预热证据。

`ASR_LOGGING_CANDIDATE`／`ASR_LOGGING_CHUNK` 指定候选；两模式使用相同权重、精度和输入节奏。每次写盘耗时可直接核查，若异常未复现，不能宣称已证明由日志造成。原五分片快照和异常样本原始结果均保留。失败模式仍保存 exit code 并继续另一模式，不能从分母或证据中消失。
