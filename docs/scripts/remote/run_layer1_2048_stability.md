# 2048窗口持续训练入口

`scripts/remote/run_layer1_2048_stability.sh`无类，仅用于026，复用现有训练器和005配置。要求冻结源码、唯一新输出、独立training conda、调度器JobID及一张BF16可用的24GiB4090。保存设备、环境、源码摘要，运行100条池/2048窗口/100步，并记录退出码、时间及子进程RSS。输出不覆盖，TERM/INT保留失败退出，外层限1800秒。

默认allocator不变，先验证当前实现是否持续OOM；batch1、累积2、梯度检查点不变。输出checkpoint留远端，仅回收小型报告。单个100条池共有245个2048窗口，本次最多消费200个，报告实际曝光及近最大长度覆盖，不宣称完成epoch或通过正式质量验收。
