# Nemotron 文本表面形式探针

`scripts/remote/probe_asr_text_surface.py` 在远端分配的单 GPU 作业中加载当前 EN160 模型一次，按文件名顺序读取少量16kHz单声道 PCM16 WAV，并复用 `NativeNemotron` 的原生解码路径。主函数逐条记录音频 SHA256、输出文本及增量、推理秒数、模型目录与处理器设置；探针不修改模型、ASR 服务、训练数据或人审记录。

输入音频须在任务单中记录合成脚本文本或真实来源，输出只用于检查大小写、缩写和数字/时间/日期的转写表面形式。`AudioBuffer` 限每条音频最多30秒；调度命令另限制单 GPU、CPU/内存和总墙钟。若识别错误，应同时保留输入脚本与原始输出，不把预期文字伪装成 ASR 结果。
