# run_asr_selection_job.sh

远端单 GPU 作业入口，无类。先校验评测脚本和 manifest 摘要，记录 GPU、环境和源码版本，随后按重复轮次轮换五个配置的顺序串行运行，避免模型竞争。每个配置独立进程释放显存；单配置失败保留日志并继续其他配置，最终汇总时保留失败状态。

作业使用共享盘的三个独立 conda 环境和预下载模型，不在 GPU 作业中安装依赖。所有产物写入带 UTC 标识的目录；若只执行小规模排错，单独使用 smoke 标识，不能混入正式结果。

五配置为英语版 160/560ms、多语言版 320/560ms、Kyutai 500ms。多语言 160ms 已在探针中被实际发布 processor 拒绝，详见任务单，不能直接篡改支持列表。

正式执行前必须通过相邻的 `<source-directory>.sha256` 校验；缺失或不匹配立即退出。单配置默认 3600 秒超时，`ASR_SELECTION_TIMEOUT_SECONDS` 可显式调整；超时保留 exit code 与已有日志。
