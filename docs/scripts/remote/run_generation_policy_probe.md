# run_generation_policy_probe.sh

对061新策略执行受限单卡真实模型验证。脚本使用独立源码快照与现役训练conda，核对新增源文件摘要，复核当前候选，启动模型服务并读取health，然后重放049同一108对prompt，自动检查每个响应的generation_policy，输出探针原文和简明summary。旧trace仅提供输入，服务的新输出另存，历史结果不覆盖。

无类。cleanup关闭模型进程组并写退出码；summary提取一致数、实际策略、原分歧150-token请求的结果和资源身份。作业需1×4090/8CPU/32GiB、1小时、单并发，输出1GiB与15GiB空闲盘；没有常驻服务部署或登录节点模型启动。
