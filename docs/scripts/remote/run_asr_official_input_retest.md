# 官方输入对齐的远端作业

`scripts/remote/run_asr_official_input_retest.sh` 在单张独占 4090 上运行一个格式条件的 50 条回放。无类。入口校验新输出目录和官方源码哈希，使用冻结脚本、同一份已有 ASR manifest/轨迹、原权重与隔离 conda 环境。legacy 服务副本仅恢复旧 user 文本编码，其余审计与推理保持一致。

节点运行单元测试、准备服务、等待权重 health、记录 GPU 与源码；用审计回放器执行完整矩阵，退出时清理本作业服务进程组并保留退出码。两臂使用独立输出目录和模型服务端口，不更新旧部署或历史运行目录。`ASR_ALIGNMENT_ROOT` 指定独立任务根，`ASR_ALIGNMENT_ARM` 指定 legacy/official。

首轮两项长作业各完成 15 条后从调度器消失，没有退出码或模型异常，精确调度原因未取得；中断时刻与已知低 GPU 利用率策略相近，不能直接判为模型失败。后续通过 `ASR_ALIGNMENT_CONFIG` 每作业限定一个 ASR 配置（原始/去标点共 10 条），输出仍固定 12s 观察窗，使用新的冻结目录。完整矩阵由五个配置分片汇总，首轮部分结果单独保留，不混入最终分母。
