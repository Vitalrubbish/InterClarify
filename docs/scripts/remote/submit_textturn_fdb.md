# FDB单作业提交与预算核查

对应 `scripts/remote/submit_textturn_fdb.sh`。用户已授权启动TT-005／006，两项共用一次远端串行调度；提交前清单必须已冻结100条。

脚本无类。先取得提交锁，核对无活动作业，再读取近3日全部TextTurn调度记录，对每项调用`vc info`核对实际StartTime／EndTime和GPU数。必须包含TT-002训练及TT-004评估，不用训练内部计时替代实际占卡时长。缺少时刻、存在未终止作业或预算耗尽则停止。

输出预算JSON，保留原调度证据和累计占卡秒数。新作业上限取剩余额度减60秒清理预留与2小时两者的较小值，不重新分配8小时预算。同一run已有预算文件或输出目录时拒绝重复提交。后续恢复或重试须独立编号，并纳入调度累计记录。

使用现有conda CPU环境执行预检；`vc submit`申请1张4090、8CPU、32GiB，外层timeout及30秒强制清理。设置`TEXTTURN_RUN_ID`与`TEXTTURN_FDB_MANIFEST`后在冻结源码worktree执行；不在远端脏主仓库覆盖源码。

提交前额外核对摘要格式、TT-002原始candidate.json与adapter实际SHA256三者一致，避免申请GPU后才发现文档摘要抄写错误。运行节点仍再次核查。首个r1因文档多余字符在推理前退出，记录保留，后续重提需单独编号且累计该次占卡时长。
