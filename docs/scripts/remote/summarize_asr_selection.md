# summarize_asr_selection.py

`--sharded` 从 `shard-*/repeat-N/<config>/` 收集并行结果，要求每个配置每轮恰好一个结果目录，重复也记不完整。`collect_process` 同时保留每个结果对应的 GPU 信息文件路径，防止把卡间差异混成未记录变量。

汇总一个 ASR 选型作业的原始 report，不加载模型。无类。`main` 按固定五配置及预期重复数检查完整性，缺失配置保留状态，不能当作零错误或从表中删除。

WER 按总词数加权；逐词延迟以全部可测正确词计算 P50/P95，同时显示可测词／全部参考词。标点保留 precision/recall/F1 和原始计数，首文本延迟与逐词声学估计分列。输出中文 Markdown 和 JSON；重复样本不视为独立新录音，汇总不给伪造置信区间。

固定配置包含 Nemotron EN 160/560、多语言版 320/560、Kyutai 500；多语言低延迟档依据实际 processor 的支持范围修订。

主表句末列检查在线累计文本末尾为 .!?，避免把内部逗号当作满足句末标点需求；EOF 才补齐的情况在 JSON 单列，出现率不代表标点正确率。
