# TextTurn 串行评估作业

对应 `scripts/remote/run_textturn_evaluation.sh`，属于TT-003/004。训练成功且开发集gate放行后，由独立冻结源码在同一资源预算内运行：独立完整文本评估、固定Kokoro测试语音准备、Nemotron＋控制器影子服务、少量真实链路冒烟、300来源正式回放。

真实冒烟只按步骤、Context及运行契约放行，不按测试模型质量挑候选；不通过就停止并保留失败。正式测试不调参、不重训。作业1 GPU/8 CPU/32GiB，最多4h；ASR与动作服务共卡，TTS准备在它们启动前串行完成。显存22GiB、资产10GiB、报告2GiB触限终止全部进程组，不留下后台服务。

本轮训练及评估累计≤8GPU小时。输出包含源码、依赖、候选身份、逐例结果和中文结论；合成语音及模拟播放的限制持续保留，作业成功不代表质量达标。
