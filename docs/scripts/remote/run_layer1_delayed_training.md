# 延后启动正式训练任务单

078允许通过`LAYER1_TRAIN_ARM/CONFIG/PROTOCOL/DATA`选择独立ASR条件，默认仍是旧040 T2。启动前按选定协议核验步数/资产/证据，空闲盘取配置值（ASR为20GiB）；训练后调用当前`run_layer1_alignment.py`直接参数入口，移除已不存在的`verify`子命令。ASR只使用单卡、冻结单epoch配置，不绕过协议校验；回归增加因果句读与新授权契约检查。

`scripts/remote/run_layer1_delayed_training.sh` 在远端单4090调度任务内执行配置核验、加权loss与数据回归、1235步全量T2训练及干净进程候选重载。无类；复用既有训练器和候选验证，不启动ASR/TTS。必须使用新输出目录、现役conda、调度GPU与冻结源码。

输入固定040a数据，资源1GPU/8CPU/32GiB、worker0、并发1，整体最长28800秒；训练最多27900秒，重载最多900秒（整体超时优先）。训练目录5GiB、整个输出6GiB、空闲盘至少5GiB；所有保存点保留，不删历史资产。记录源码摘要、环境、GPU、每步普通/加权loss与五类诊断、资源和退出码。直接开训不运行模型短跑；只执行轻量逻辑/梯度回归。单epoch最后一个序列单独消费，禁止重复补齐。
