# TT-011 单项远端测试入口

对应 `scripts/remote/run_textturn_external.sh`。入口以`TEXTTURN_EXTERNAL_DIR`读取冻结清单与候选身份，`TEXTTURN_EXTERNAL_PHASE`选择UltraChat或FDB，`TEXTTURN_RUN_ID`创建独立输出。训练、数据和配置路径由候选身份参数化；复用现有conda，不复制权重。

脚本在调度节点启动单个控制服务；FDB额外启动真实Nemotron服务，单录音流、一个控制worker；没有助手TTS。控制服务启动后核验五token、权重身份及合法动作接口，再用正式分母之外的短输入核查finish闭合、重复回调与HTTP输入。FDB另用历史冻结的非正式两条录音冒烟。

UltraChat仅160ms／每周期3 token，执行150例，分开生成历史行为诊断与新语义评分。FDB保留action_only与原100条录音，执行既有评分及补充stop／严格大于960ms持续Speak统计。两项输出相互独立；输入分布和实际模型效果不在入口中调整。

每10秒采样GPU、资产、报告和可用盘：显存22GiB、资产10GiB、报告2GiB、可用盘30GiB停止线。外层7200秒包含清理，运行阶段预留60秒。服务与步骤使用独立进程组，退出时清理并保存退出码、包版本、源码提交与逐文件摘要；接口或正式运行失败不会被当成成功。

运行阶段达到7140秒时主动结束，给外层7200秒保留清理时间；资源采样命令失败也终止父入口，不让监控静默消失后继续推理。
