# X2 同卡FDB回放与归因

`scripts/remote/x2_teacher_fdb.py`独立于冻结Nemotron入口，复用其模型加载、SoulX六段合成音／教师文本预热、RPC和三轴`analyze()`评分，不复制状态预测逻辑。

`run_case()`实时按80ms推PCM，同时保留SoulX所需历史／当前／前瞻音频。每160ms按固定2:1对应接收一教师步骤，验证步序、覆盖边界和200样本ASR前瞻；不再使用窗口牵引配对器。先编码音频，再等X2真实解码完成，再提交文本与状态并发布，最后确认屏障。队列和墙钟积压超过800ms直接失败，保留已写帧与traceback。

EOF保留最后在线Context，未满足原生观察窗口的尾部单列；随后允许X2完成剩余真实音频的诊断，不把后得文字写回Context。`run()`按同一30条冻结清单逐条校验文件摘要、重采样与增益；输出完整率、真实退出结果和token规范性。

`analyze()`先调用基线三轴分析，再生成`x2_audit.json`：主块／完整观察延迟、RTF、规范分词分子／分母、闭合组与实际规则改写数。r6的RMS按同一原始音频、增益及PCM16量化重建；RMS<0.001记静音，仅用于归因，状态规则不变。WER与接话／停顿／打断指标保留基线口径和真实分母。
