# FDB 子集评分与诊断汇总

`scripts/remote/fdb_subset_report.py` 在独立评分进程中复用 `full_fdb_two_axes.score`，把两轴预期数量设为 5，保持官方转写、时序规则与 GPT 暂缓语义；报告明确标注这是子集，不是完整语料。

## 核心方法

- `score_subset`：复用完整评分模块，仅覆盖两轴预期数量；结束后恢复完整模块常量，避免影响同进程后续评分。
- `summarize`：读取 25 例回放报告，按子集统计执行、协议、原窗播放和尾窗播放，以及注释锚点后的新回复 PCM/播放延迟。PCM 开始不等于官方词级语音开始，与官方 TOR/Latency 分别呈现。
- 音频检查逐文件核对 `input.wav` 与 `output.wav` 时长，拒绝诊断尾窗混入官方输出；使用客户端环境已有的 `soundfile` 读取 IEEE 浮点 WAV，不转换音频、不修改等长容差。

## 边界

入口只读已有回放和原始注释，不使用 FDB 标签决定运行时动作，不替代人工相关性与音频自然度检查。数值输出保留每例身份、原窗时长、响应计时和原始负值。
