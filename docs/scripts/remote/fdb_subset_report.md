# FDB子集评分与诊断汇总

`scripts/remote/fdb_subset_report.py`不创建产品类。`score_subset`在独立评分进程复用`full_fdb_two_axes.score`，仅将两轴预期数量设为5，保持官方转写/时序规则与GPT暂缓语义；明确报告这是子集，不是完整语料。

`summarize`读取25例的A4报告，按子集统计执行、协议、原窗播放和尾窗才播放，以及注释锚点后的新回复PCM/播放延迟。PCM开始不等于官方词级语音开始，和官方TOR/Latency分别呈现；暂停/附和不在本单新增未经验证的官方指标。

汇总逐文件核对input.wav和output.wav时长，拒绝诊断尾窗混入官方输出，记录25例覆盖。子集评分临时设置覆盖数后恢复完整模块常量，避免影响同进程后续完整评分。

082修复：FDB部分input.wav为IEEE浮点格式，Python3.10标准wave模块不支持；`summarize`改用客户端环境已有soundfile读取音频元数据，不转换音频、不修改等长容差。正常推理入口和独立评分恢复入口均使用客户端conda执行诊断。

入口只读已有回放和原注释，不使用FDB标签决定运行时动作，不替代人工相关性与音频自然度检查。数值输出保留每例身份、原窗时长、响应计时和原始负值。
