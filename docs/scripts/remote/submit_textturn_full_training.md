# 完整轨迹训练提交

`scripts/remote/submit_textturn_full_training.sh`取得共用提交锁，核对无活动作业、run未存在，audit通过并绑定当前manifest、训练配置及当前损失helper摘要，再提交既有镜像上的单任务：1张24GiB GPU、8CPU、32GiB RAM。stdout保留调度回执，不把排队写成已经训练。

2026-10-26用户授权重训并取消训练任务时间上限，外层14400秒timeout移除，直接运行独立源码中的训练入口；不向调度器主动传入时长限制。实际平台是否有额外策略以调度器信息为准，不把应用层取消时限等同于修改集群管理策略。

环境变量TEXTTURN_RUN_ID指定独立run，数据为tt-010-fulltraj-r1。已有conda的轻量提交前检查仍有30秒命令超时，防止登录节点检查挂起；这不是训练时限。显存、内存、磁盘、并发和质量门槛全部保留。实际提交后记录job ID和稳定运行证据。

TEXTTURN_AUDIT可指定独立本轮审核文件，默认仍使用数据目录audit.json；重训通过该变量使用新配置的审核结果，并保留旧远端审核文件。
