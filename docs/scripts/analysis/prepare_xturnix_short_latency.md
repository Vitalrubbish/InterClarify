# 短延迟对照输入准备

`scripts/analysis/prepare_xturnix_short_latency.py` 固定上一轮已标注的 45 个完整陈述式信息回答，关联同版本原音频和历史，生成真实回放所需清单。它不读取模型分数或据结果选择话轮。

模块使用函数。`read_bounded` 对每次网络读取限制字节数与超时；`prepare` 校验冻结 dev/源元数据哈希，重新读取官方音频地址并逐行确认元数据未变，然后按会话固定分组。启用 `--download-audio` 时串行下载并保留源哈希，检查音频时长和有限值，转为 16kHz 单声道 PCM16，保留归一化文件哈希。

`main` 接收冻结输入、类别清单、配置和独立输出目录。没有下载音频的 manifest 只能用于核查，真实回放必须拒绝。完整正文和音频留忽略目录或远端，Git 只保留无正文的清单摘要。

下载元数据每页≤8MiB、音频每条≤64MiB、累计≤配置上限，worker=1；不下载模型。准备阶段任何哈希、版本、时长或容量不符立即失败，不以其他样本补足。
