# 修复数据独立完整性核查

`audit_textturn_repair.py`流式核查冻结文件摘要、来源分组隔离和来源数／窗口预算，逐窗重算弱动作、输入投影和损失掩码，按来源验证完整逻辑组。`audit`同时读取完整事件及输出，核对160ms逐拍、单输出所有权、生成／播放独立游标、每拍播放≤1 token、准备阶段stop、stop80ms确认、start与唯一终态配对、finish时播放排空、实际模板可达性及来源／句式／历史交叉表。无类；`check_trace`处理一条轨迹，`check_rows`处理单个压缩切分，避免一次加载全量数据。通过结果绑定manifest、训练配置和实现摘要。失败时不得提交训练。
