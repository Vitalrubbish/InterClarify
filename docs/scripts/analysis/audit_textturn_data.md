# TextTurn 构造与配比审计

对应 `scripts/analysis/audit_textturn_data.py`，复用TT-004用户授权的评分修复后数据检查，不新建issue、不改冻结数据。

`audit_split`流式读取train/pilot，按场景、动作、Listen/Speak、空窗／有字统计实际训练暴露，检查动作损失mask、来源数和陈述start比例。`shortcut`是只看状态、空窗、不完整问句开头和固定停止词的无模型诊断，用于发现标签可被时序规则解释的程度；不代表真实语义正确或线上基线。按当前标签统计的错误保留。

检查每类负例是否包含ASR式话中空窗、完整子句后续说、词内突发、播放尾窗打断，以及短模板数量和相同可见输入标签冲突。按pilot两轮加full两轮计算模型实际动作暴露，不把2次集合读取当新对话。只读取训练来源，不使用测试正文或trace生成训练材料。

输出可复现计数、构建器摘要与中文审核结论的依据；配比建议单独标为待开发集验证的候选，不能根据已观察的测试成绩搜索最优比例。
