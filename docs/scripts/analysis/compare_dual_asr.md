# 双ASR审计与历史对照

对应`scripts/analysis/compare_dual_asr.py`。`audit_case()`将已发布帧与独立state/source及native审计逐条核对，验证首次充分覆盖步骤、冻结正文、状态不重新预测、音频顺序和两路完成先于发布。未配齐状态单列，不将EOF尾部补入历史帧。

`summarize()`分列全固定清单的完成/失败、产生状态与发布状态、主块与完整观察发布延迟、两路计算/输入等待/排队、队列和PCM峰值及直接停止时刻。`compare()`只在双方共同完整样本中比较，另按双方共同音频覆盖截断，调用已有三轴事件与WER口径；完整样本不能与失败的部分轨迹拼接成成功批次。新EOF无合成静音，其正文与历史排空正文保留不同语义标签。

命令参数`--run`指向新run根目录（含probe），`--baseline`指向历史NTF-004根目录，`--output`保存JSON分析。输入摘要必须一致；脚本只读结果，不启动模型、不修改原始产物。
