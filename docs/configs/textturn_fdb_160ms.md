# TT-007固定160ms对照协议

对应 `configs/textturn_fdb_160ms.json`，由用户明确授权的TT-007使用。模块为纯配置，无类。

除控制周期160ms及显式标识实验、模拟生成480ms、播放尾960ms外，其余协议与480ms FDB配置相同。真实Nemotron每次解码完成形成一个控制周期，80ms音频包不变；助手生成每480ms发布8 token，保持原实际速度，不随控制请求加速。

正式50＋50、冒烟两条、候选摘要、助手文本、初始历史、静音配置与预算均沿用原清单。使用冻结器的`--baseline-manifest`派生清单，保存基线摘要，不重新排序或抽样。提交和运行阶段均核对本文件与清单摘要一致。

评分一拍160ms，并报告等待毫秒；3周期名义覆盖480ms。不能直接把本实验的拍数或3周期比例与480ms基线按等时长比较。单次最多2小时、累计8GPU小时仍为原预算，不增加额度。
