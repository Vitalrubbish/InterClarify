# X2 探针冻结配置

`configs/x2_streaming_probe.json`记录模型revision、权重SHA256、官方推理源码revision及实际导入文件的摘要。依赖文件不匹配立即失败，禁止运行时联网升级。

采用官方固定的自适应80ms协议，等待32、发射33、EOS2，发射组以EOS闭合。基础配置的6帧delay只作为来源信息保留，不用于时延扣减。首块2600样本，经封装后272mel帧（256左填充＋16输入），后续1680样本／8mel帧，真实音频每1280样本前进，STFT观察前瞻200样本。

`limits`保留NTF-011阈值：RTF0.6、积压P95 320ms、60s首尾积压绝对漂移160ms、显存12288MiB。`stop_gpu_mib=22528`为独立资源停止线，不代替12GiB验收门槛。最大DECODE64token，超限失败，不截断成伪造的闭合组。
