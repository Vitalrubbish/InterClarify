# 第二轮对齐协议

`configs/layer1_alignment_protocol.yaml`以摘要引用首轮协议、完整索引、独立训练配置和固定资产，不复制或重写首轮登记。无类或方法。正式入口仅允许T2、1,000条、完整单epoch和冻结条件名。`training_released`及本轮资源/恢复/推理报告共同控制037放行；本轮短跑可在未放行时执行，最多100步，并在manifest明确标为不可服务的诊断产物。

2026-10-20用户明确取消短跑并要求直接正式训练。`release_policy=user_waived_alignment_probe`只豁免本轮真实模型资源/恢复/推理短跑，不将未执行项标为通过；配置、完整数据索引、官方资产、白名单、单epoch及资源上限仍强制校验。`training_released=true`据此放行037；最终候选完整重载仍在正式训练后核验。
