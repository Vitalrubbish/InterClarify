# Layer 1 适配协议登记

`configs/layer1_adaptation_protocol.yaml` 是 Issue 001 的首版实验登记配置，不是产品启动配置。无类或方法。`runtime` 固定组件、五类 wire token、600ms 时钟、BF16 和 64-token 贪心；`assets` 将历史 revision 线索与实际核验分开；`data` 固定来源路线和切分；`training` 限定更新参数及两轮预算；`diagnostic` 固定参考对照范围和容忍；`acceptance` 登记候选结果前的数值门槛；`gates` 保留未完成证据。

null 表示尚未核验，不能自行推断 BOS 为不存在。`training_released: false` 不是自动执行的权限检查，目前尚无训练消费者；正式训练入口必须检查所有前置证据。001 完成不要求 B0 达到接话门槛，但要求输入与运行时差异得到解释。

预算是本项目的保守起始上限：每组首轮 8、第二轮 16 GPU 小时，三组最多 72 GPU 小时，最多各一 epoch；005 根据短跑同时满足时间、数据曝光和资源上限后冻结实际步数与长度。预算耗尽是停止条件，不能减少应报告的失败。诊断起步 4 GPU 小时单独计，不计为训练。参数变更须在候选结果前登记，结果后变更建立新条件。

独立真实 dev 每行为至少 30 例，test 每行为至少 100 例且总计至少 20 位说话人，dev/test 说话人不交叉。分别检查接话、停顿、自行补充改口、附和和有效插话；不得把同一录音变体当独立样本。点估计达到配置门槛后，仍需报告按说话人分组 95% bootstrap 区间；区间不足以支持判断则补充独立样本并保留旧结果，不放松门槛。004/007 在看候选结果前交付具体来源、样本 ID、排除规则和清单哈希；当前清单缺失仍阻断正式训练。

质量由盲标签审查判断回复是否相关、正确理解指令并能完成当前请求，报告合格比例及相对 B0 的下降百分点；日期时间或否定理解发生关键错误时不放行。音频指标归 008，简单问题亚秒覆盖首版下限为 90%，全部问题保留漏答分母；1.5 秒是均值上限，不是每例最大值。以上数值是首版工程决策，不是已有实验结论。

相同资产同 prompt 要求生成 IDs 一致；logits 容忍只解释数值差异，不允许改变控制选择。1ms 容忍用于离散逻辑事件归属核对，不用于宣称物理实时调度满足 1ms。物理迟到、排队和耗时独立报告。raw/完整词与两种起拍分别比较，不把条件之间本来就存在的输入差异当成实现错误。
