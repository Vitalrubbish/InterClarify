# 第二轮对齐训练配置

`configs/layer1_alignment_training.yaml`登记`T2_R2_paper_aligned`，无类或方法。沿用官方初始化、112个既有q/v LoRA、2e-5、1,000条T2、2048、batch1/累积2、1,214步和每203步保存。控制权重1/10/5/2/1，warmup改122步，随后沿用线性衰减。正文/EOS权重1，交叉熵按64位置分块重计算；该值属于工程选择。

单run输出上限5GiB、空闲保留5GiB，正式最长8小时；短跑合计输出上限16GiB、空闲保留15GiB、最长1小时、1×4090/8CPU/32GiB、单作业无数据worker。须由本轮实测核验后才能放行正式训练，失败保留证据。首轮文件不修改。
