# 160ms双工数据配置

`configs/textturn_duplex_dataset.json`冻结TT-010重建数据的时钟、来源文字发布速率、随机插入及资源上限。控制窗160ms；用户名义480ms发布1—2 token，助手按3／3／2 token循环发布，避免缩短控制窗后提高三倍语速。

句中停顿在每个非末尾用户文字块后以0.20概率触发，长度随机1—5窗，即160—800ms；不在最后块后用未来续说伪装句中停顿。Speak期间可用窗以0.01独立概率插入短用户附和，措辞来自配置集合；附和替换空观察，不增加单独控制拍。原文中的普通片段、短附和与无更新均可keep，非附和首个可判定前缀才stop。

播放尾窗960ms、模拟停播确认80ms，均非模型实测延迟。固定seed20261025、最大2048 token、训练不超过10000快照，构造单线程／2GiB／600秒／512MiB。`max_length`和文字发布速率变更会被拒绝，不能静默改合同。参考参数及适配理由见[重建合同](../dev/TextTurn/tt_010_rebuild.md)。
