# FDB 跨集测试固定协议

对应 `configs/textturn_fdb.json`，由 TT-005／006 共用。在抽样与模型推理前冻结，清单保存配置文件SHA256；不根据结果调整。

固定种子20261025，每臂50条，候选adapter与TT-002一致。Turn Taking仅在输入构造阶段拼接一次5秒静音，Pause不拼接；80ms音频包，三个真实解码步骤形成480ms控制窗。

配置指定`controller_state_mode=action_only`。只监控真实ASR输入下的TextTurn动作与状态；从Listen开始，start切Speak、stop回Listen、keep维持，不生成助手正文、不模拟生成或播放、不计时自动复位。控制输入的助手正文为空、生成完成标志为null，历史固定为空列表。

配置不定义类。抽样器读取样本、静音和来源协议，回放器读取模拟生命周期，提交器读取单次2小时及累计8GPU小时上限。资源限制沿用工作单，不因拆单增加预算。

2026-10-25纠正历史文档摘要中的一处多余字符，以原始candidate.json及实际文件一致的64位SHA256为准；没有更换候选。

按用户最新纠正，旧助手文本、生成token数和播放尾窗配置已删除。新480ms及160ms均须使用action_only协议；旧模拟回答的清单和运行保留为撤回记录。
