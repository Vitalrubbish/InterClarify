# FDB 跨集测试固定协议

对应 `configs/textturn_fdb.json`，由 TT-005／006 共用。在抽样与模型推理前冻结，清单保存配置文件SHA256；不根据结果调整。

固定种子20261025，每臂50条，候选adapter与TT-002一致。Turn Taking仅在输入构造阶段拼接一次5秒静音，Pause不拼接；80ms音频包，三个真实解码步骤形成480ms控制窗。

模拟助手使用固定英文短文，与录音、参考转写和标注无关；每窗生成8 token，播放尾窗固定2窗。会话初始历史为空，从Listen开始；start开始生成，stop中止，生成结束后待尾窗完成返回Listen。它用于固定影子生命周期，不是回答质量测试，也不为连续3窗强制维持Speak。

配置不定义类。抽样器读取样本、静音和来源协议，回放器读取模拟生命周期，提交器读取单次2小时及累计8GPU小时上限。资源限制沿用工作单，不因拆单增加预算。
